# 前端架构概览

## 概述

前端基于 React 18 + TypeScript 5 + Ant Design 5，使用 Vite 构建，采用"配置式路由 + 懒加载页面 + 双层鉴权布局"的骨架。设计层面以 `styles/token.css` 的设计令牌系统承载深浅色双模式，功能型页面遵循统一的"容器 → 头部 → 表格 → 弹窗"管理页范式。业务通过 `utils/request.ts` 统一 API 封装，实时能力通过 `hooks/useWebSocket.ts` 提供。

## 技术栈与入口

| 项目 | 选型 |
| --- | --- |
| 框架 | React 18 |
| 语言 | TypeScript 5（严格模式） |
| 组件库 | Ant Design 5（zh_CN locale） |
| 构建 | Vite |
| 路由 | react-router-dom（createBrowserRouter） |
| 富文本 | Tiptap |

入口 `frontend/src/main.tsx`：`ThemeProvider` 包裹 `ConfigProvider`（`getAntdThemeConfig(isDark)` 动态生成 AntD 主题）+ `UserProvider`，随后挂载 `RouterProvider`，并全局引入 `styles/token.css`、`styles/typography.css`、`global.css`。

## 设计令牌系统

`frontend/src/styles/token.css` 是全局设计令牌的唯一来源，严格对应《项目基定/UI设计规范.md》：

- 浅色模式定义于 `:root`，深色模式通过 `:root[data-theme="dark"]` 选择器覆写，页面切换由 `contexts/ThemeContext.tsx` 维护 `data-theme` 属性。
- 核心令牌分组：品牌色（`--color-primary: #0066cc`）、底色（`--canvas` / `--canvas-parchment` / `--surface-tile-*`）、文本色（`--ink` / `--body` / `--text-primary` / `--text-secondary`）、扩展背景（`--bg-primary` / `--bg-secondary` / `--bg-tertiary`）、间距（`--spacing-xxs` 至 `--spacing-section`）、圆角（`--rounded-*`）、阴影（`--shadow-sm/md/lg`）、层级（`--z-*`）与组件级令牌（按钮、卡片、模态框、表格、表单、侧边栏等）。
- 所有 CSS Module 与组件内联样式统一引用 `var(--token-name)`，保证深浅色自动切换且无硬编码色值。

## 路由与懒加载

`frontend/src/router.tsx` 使用 `createBrowserRouter`：

- 公开路由：`/login`、`/welcome`（初始化）、`/test-mode`、`/stream/watch/:roomId`、`share/:code`、`forms/:id/fill`。
- 受保护路由树：外层 `AuthGuard`，内层 `MainLayout`，二者构成双层保护。
- 懒加载：所有业务页面用 `React.lazy(() => import(...))` 声明，配合 `LazyPage` 包装组件（`Suspense` + `Spin` 加载态）挂载。典型如 `const NoteManagement = lazy(() => import('@/pages/notes/NoteManagement'))`，路由内 `<LazyPage><NoteManagement /></LazyPage>`。
- 兜底：`*` 通配重定向到 `/404`。

## 鉴权与布局

路由级鉴权与全局布局分层承担：AuthGuard 把关访问资格，MainLayout 提供页面骨架并挂载全局能力。

### AuthGuard

`frontend/src/components/AuthGuard.tsx` 承担路由级鉴权：

- 初始化检查：请求 `/api/v1/auth/setup-status`，未初始化跳转 `/welcome`。
- 未登录：`isAuthenticated()` 为假时重定向 `/login`。
- 测试模式：`isTestModeEnabled()` 且非管理员时渲染 403 结果页。
- 通过后渲染 `<Outlet />` 进入 `MainLayout`。

### MainLayout

`frontend/src/layouts/MainLayout.tsx` 提供 Sider + Header + Content 三栏布局：

- 侧边栏菜单项由 `ICON_MAP`（`@ant-design/icons` 图标）与路由配置驱动，支持折叠与自定义颜色。
- Header 集成 `NotificationBell`（未读数角标）、用户下拉与个人化入口。
- 挂载 `useWebSocket`、`useIdleTimer`（5 分钟闲置登出）、`useCustomization`（主题色/暗色/侧边栏个性化）、`useResponsive`（断点适配）。
- 以 `TagProvider` 提供全局标签上下文。

## 用户自定义

- `hooks/useCustomization.ts`：读写主题色与暗色模式偏好，持久化于 `localStorage`。
- 配置页：`pages/settings/UserPersonalization.tsx`（个人偏好）、`pages/settings/CustomizationSettings.tsx`（站点级自定义）。
- `contexts/ThemeContext.tsx`：`useTheme()` 返回 `isDark`，驱动 token.css 的 `data-theme="dark"` 与 AntD ConfigProvider 主题。

## 标准管理页模式

功能型管理页统一遵循"容器 → 头部 → 表格 → 弹窗"范式：

```text
<div className={styles.container}>
  <div className={styles.header}>
    <Title level={4}>模块标题</Title>
    <Space>
      <Input.Search placeholder="搜索..." />   // 胶囊搜索框
      <Button type="primary" icon={<PlusOutlined />}>新建</Button>
      <Tooltip title="权限说明">...</Tooltip>
    </Space>
  </div>
  <Table ... pagination />   // 分页表格
  <Modal ... />              // 新建/编辑弹窗
</div>
```

该模式在 `pages/templates/TemplateManagement.tsx`、`pages/tasks/TaskManagement.tsx`、`pages/contacts/ContactManagement.tsx`、`pages/inventory/InventoryManagement.tsx` 等页面重复出现；搜索框统一使用 `.searchInput`（`max-width: 320px` + 胶囊圆角）与 `prefix={<SearchOutlined />}`。

除表格范式外还有两种布局变体：

- 卡片网格：`pages/servers/ServerManagement.tsx` 以 `Card` 网格展示服务器，配状态 Tag、搜索、状态筛选与分页。
- Tree 组件：`pages/notes/NoteManagement.tsx` 使用 Ant Design `Tree`（`draggable`、`showLine`）组织笔记层级，并支持树形/图形视图切换（`GraphView`）。

## API 封装

`frontend/src/utils/request.ts` 统一所有 REST 请求：

- `request<T>(endpoint, options)`：自动附加 `Authorization: Bearer <token>`，GET 请求附加防缓存头（`Cache-Control: no-cache` 等，规避 Safari/Edge 启发式缓存）。
- token 刷新：收到 401 时调用 `refreshAccessToken()`（`POST /auth/refresh`），成功则替换 token 并重放原请求；失败则清除令牌并跳转 `/login`。
- 错误归一：将 FastAPI 422 的 `detail` 数组格式化为 `loc: msg` 字符串，抛出 `HttpError`。
- `uploadWithProgress(url, file, onProgress, extraData)`：基于 XHR 实现带进度条的上传。
- 业务 API 按模块拆分于 `frontend/src/api/`（auth、users、secrets、servers、systems、notes、contents、forms、votes、topology 等）。

## 实时与通知

- `hooks/useWebSocket.ts`：连接 `/ws?token=...`，30 秒心跳，实时接收 notification / room_kicked 消息；15 秒轮询历史通知并去重合并；对外暴露 `notifications`、`unreadCount`、`markAsRead`、`markAllAsRead`。详见 [通知推送架构](./通知推送架构.md)。

## 安全约束

- 路由级鉴权由 `AuthGuard` 统一处理，页面组件不再重复实现登录校验。
- 全部图标使用 `@ant-design/icons` 或 SVG，禁止 Emoji 图标。
- 所有组件与页面样式引用设计令牌变量，保证深浅色模式全覆盖。
- token 存储与清除集中在 `utils/auth.ts`（`getToken` / `setTokens` / `clearTokens`），禁止页面直接操作存储。
