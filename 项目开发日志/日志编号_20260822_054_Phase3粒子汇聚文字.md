### 开发内容详述
从 Phase 2 丝绸粒子流代码（TestPageSmokeBand.tsx）复制为起点，整体重写为粒子汇聚文字动画：

1. **文字像素采样**：`sampleTextParticles()` 函数将 "UNIFIED\\nWORKBENCH" 渲染到 400×160 离屏 Canvas，逐像素扫描白色区域，转换为 clip space 坐标，随机采样 8000 个目标位置

2. **粒子系统**：8000 粒子，每个有独立的 targetX/targetY（从文字像素采样得到）、初始位置在目标周围随机偏移（1.0-2.5 距离）、速度、大小、亮度、闪烁相位

3. **汇聚逻辑**：
   - `CONVERGE_TIME = 0.5s` 后开始汇聚
   - `convergeWeight` 从 0 到 1 线性过渡（0.5s 过渡期）
   - 弹簧常数 3.0 将粒子拉向目标位置
   - 阻尼 0.92 防止振荡
   - 水平漂移（sin 波）保持粒子流动感
   - Noise 波浪（±0.02）赋予文字"呼吸"效果

4. **WebGL 渲染**：与 Phase 2 相同的 GL_POINTS 渲染管线，点精灵 + 高斯衰减

5. **鼠标交互**：保留鼠标扰流（径向推力 0.012，半径 0.2），可扰动已形成的文字粒子

### 遇到的问题与解决
- **TypeScript 编译错误**：未使用参数 `W`、`H` 被移除；`ctx.getContext('2d')` 可能为 null 需加 `if (!ctx) return`；`Uint8ClampedArray` 索引用 `!` 非空断言
- **粒子数选择**：8000 个粒子在文字像素采样后足够形成清晰文字，且性能开销在 WebGL 点精灵下可接受

### 后续迭代（v3 - 2026-08-22 重写三阶段流程）

**用户反馈**：汇聚过程杂乱无序，需要从 Phase 2 丝绸流状态华丽衔接到字母。

**重新设计的三阶段流程**：

| 阶段 | 时间 | 行为 |
|------|------|------|
| 🌀 丝绸流 | 0-0.5s | Phase 2 风格水平粒子流（65流×123粒子=7995） |
| 💫 发散 | 0.5-2.0s | 粒子从流线弧形扩散到屏幕 65% 范围（弧线路径+smoothstep缓动） |
| ✨ 分批汇聚 | 2.0s+ | 10 批依次沿弧线+螺旋路径汇聚到字母（每批 0.4s, 间隔 0.18s） |

**关键改动**：
1. **粒子数**：8000 → 7995（65流×123粒子，与 Phase 2 结构一致）
2. **初始状态**：不再是随机散落，而是 Phase 2 风格的丝绸流水平运动
3. **发散阶段**：粒子从流线位置沿 Bézier 弧线平滑扩散到 65% 屏幕半径的随机位置，使画面从"带状"变为"面状"
4. **分批汇聚**：粒子被随机分配到 10 个批次，逐批沿弧线路径+螺旋轨道飞向目标位置，形成有序的波浪式汇聚
5. **拖影**：发散和汇聚期间使用全屏渐隐四边形（alpha=0.05）产生运动拖影
6. **速度**：整体时间轴拉长（整个流程约 4s），比之前版本慢很多
7. **汇聚路径**：Bézier 弧线（上拱）+ 螺旋轨道（2.5 圈旋转，半径衰减到 0），形成华丽飞入效果

**数学公式**：
- 发散：`B(t) = (1-t)²P0 + 2(1-t)tP1 + t²P2`，控制点 P1 上移 0.05
- 汇聚：`B(t) = (1-t)²P0 + 2(1-t)tP1 + t²P2`，控制点 P1 上移 0.1-0.25
- 螺旋：`orbitRadius = (1-eased) * 0.03`, `orbitAngle = eased * π * 3 + twinkle`
- 缓动：`easeInOutCubic`（三次方缓入缓出）

**常量**：
```typescript

SPREAD_END = 2.0        // 发散结束
CONVERGE_DURATION = 0.4 // 每批汇聚时长
BATCH_INTERVAL = 0.18   // 批次间隔
BATCH_COUNT = 10        // 总批次数
```

### 后续迭代（v6 - 去除环形/螺旋，改用偏移扩散到75%）

**用户反馈**：不要环形扩散，不要螺旋轨道。粒子脱离轨道向上下左右扩散到75%页面占比，然后汇聚。

**改动**：
1. 移除 `spreadX/spreadY`（绝对位置圆盘采样），改为 `spreadOffsetX/spreadOffsetY`（从轨道位置偏移，方向随机，距离0.2-0.75）
2. 移除汇聚阶段的螺旋轨道（`orbitAngle`/`orbitRadius`）
3. 移除 Bézier 弧线路径，改用逐帧 lerp 逼近目标
4. 扩散阶段：`p.x += (spreadTX - p.x) * eased * 0.06`，目标位置 = 当前位置 + 偏移
5. 汇聚阶段：`p.x += (targetX - p.x) * eased * 0.04`，逐帧逼近目标
6. 移除 `vx` 字段（不再需要暂存起始位置），保留 `vy` 用于丝绸流弹簧物理

**常量**：

### 后续迭代（v7 - 减小扩散幅度，缓慢自然）

**用户反馈**：不超出屏幕，幅度不要大，往外缓慢发散，不刻意。

**改动**：
1. `spreadDist` 从 `0.2 + Math.random() * 0.55`（最大 0.75）→ `0.05 + Math.random() * 0.20`（最大 0.25）
2. 扩散幅度大幅减小，粒子仅从轨道缓慢漂移，不超出屏幕范围
3. 保持逐帧 lerp 速率，因距离变小，整体运动更柔和自然

**常量**：
```typescript

```
