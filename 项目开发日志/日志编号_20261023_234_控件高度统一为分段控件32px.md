### 开发目标
1. 核查三类控件默认高度
2. 以分段控件（32px）为基准统一离群值
3. 后续尺寸顺带对齐按钮与图标按钮

### 核查结论

以 `ThemeContext.getAntdThemeConfig` 的 `token.controlHeight = 32` 为准：

| 控件 | 默认高度 | 说明 |
|------|---------|------|
| 输入框 / 下拉 / 日期 | **32** | antd 走 controlHeight |
| 分段控件 Segmented | **32** | 轨道 = 内边距 2 + 选中块 28 + 2 |
| 按钮 Button（default） | **32** | antd 走 controlHeight |
| 开关 AppSwitch | **32** | 轨道 32 = 内缩 2 + 滑块 28 + 2 |
| 自绘输入框 token | **32** | `--input-height` / `--btn-height` = 32 |

结论：antd 默认档四者本来就一致（32）。不一致的是若干**自绘 36px 控件**，已在本次统一。

### 遇到的问题与解决
- **问题**：批量替换脚本里「3 行组合模式」在日历弹窗命中 2 次（输入框块与日期块结构相同），脚本按断言跳过，导致输入框仍是 36。
- **解决**：改用带唯一上下文的定点替换，命中数断言为 1 后写入。
- **问题**：想用登录页实测 antd 默认高度，但登录页是品牌页，用了 size="large"（输入 40 / 按钮 44），不能代表默认档。
- **解决**：以主题 token（controlHeight 32）为权威依据，并与自绘 token、开关实测（32）交叉验证。
