### 开发内容详述
**1. 列表展示与筛选**
- 采用卡片式列表（参考 `ProjectDocumentTab` 风格），行内展示：编号(number)、类型 Tag（会议纪要→blue / 沟通记录→green，自由类型回退 default 原样显示）、发言人(speaker)、参与人(participants 多选，按用户映射显示昵称)、时间(started_at)。
- 类型筛选用 `Segmented`（全部 / 会议纪要 / 沟通记录），筛选变化时重置页码与展开态；分页用 `Pagination`（page_size=10），数据来自 `listProjectMeetings`。

**2. 新建 / 编辑 Modal**
- 字段：类型（`AutoComplete`，预设 meeting/communication 且允许自由填写，必填）、标题（可选）、发言人（`AutoComplete`，从工作台用户列表选择或自由输入，必填）、参与人（`Select multiple`，存用户 id，可选）、内容（`TextArea` 必填）、时间（`DatePicker showTime`，必填）。
- **关键决策——标题字段**：后端 `ProjectMeeting` 无独立 `title` 字段（已在 `backend/app/schemas/project_meeting.py` 与前端 `types/project-meeting.ts` 确认）。为满足规格中"标题(可选)"字段且不臆造后端字段，采用约定：标题非空时按「标题\n\n正文」合并存入 `content`，展示时 `splitTitleContent` 拆回；编辑时回填拆分结果，提交时重新合并。列表标题列优先显示拆分出的 title，否则显示内容摘要（规格允许"标题或内容摘要"）。
- **编号生成**：后端 create 必填 `number`，格式按重做计划 `MTG-{项目编号}-{序号}`。前端在创建提交前调用 `listProjectMeetings({page:1,page_size:1})` 取项目内总数，序号 = total+1 并 `padStart(3,'0')`；项目编号取 `project.number`，为空时回退 `project.id` 前 8 位大写。

**3. 详情展开 + 追加备注**
- 点击行展开：完整内容（`white-space: pre-wrap`）、备注列表（notes JSONB 数组，安全解析 content/author/created_at，author 若为用户 id 映射为昵称）、追加备注输入区。
- **追加备注实现**：后端 `updateProjectMeeting` 的 `ProjectMeetingUpdate.notes` 字段受支持（schema 含 `notes: list[Any]`，service 中 `if field in data and data[field] is not None` 更新），故前端读取当前 notes 数组 → 末尾 push `{content, author, created_at}` → 整组 `notes` 提交 `updateProjectMeeting`。author 取当前登录用户 id（`getUserId()`）。

**4. 删除**
- `Modal.confirm` danger 风格确认后调 `deleteProjectMeeting`，成功后刷新列表。

**5. 权限**
- `canManage = isOwner || member_permissions['meetings'] !== 'readonly'`；owner（`project.owner_id === getUserId()`）全权限；其余成员按 "meetings" 分区判断，readonly 时：新建按钮、编辑/删除按钮（渲染为 disabled + Tooltip "只读权限"）、追加备注输入区均不可用。默认（无分区配置）允许增删改查，与重做计划"默认成员增删改查"一致。

**6. UI 规范**
- 全部使用全局 Design Token（`--spacing-*`、`--text-*`、`--rounded-*`、`--bg-*`、`--border-*`、`--color-*`、`--anim-*`），深浅色自适应（token 随 `[data-theme="dark"]` 切换）。
- 图标全部使用 `@ant-design/icons`（FileTextOutlined/EditOutlined/DeleteOutlined/PlusOutlined/UserOutlined/TeamOutlined/ClockCircleOutlined/ExclamationCircleOutlined），无 Emoji。
- 所有 CSS Module 类名引用带 `?? ''` 兜底。

### 遇到的问题与解决
- 问题 1：后端无 `title` 字段但规格要求"标题(可选)"。
  - 解决方案：不新增/不臆造后端字段，按「标题\n\n正文」约定并入 `content`，展示/编辑时拆分还原（详见开发内容详述）。
- 问题 2：eslint `react/no-array-index-key` 对备注列表 key 报错。
  - 解决方案：notes 元素无唯一 id，改用 `created_at-content` 组合作 key（放弃 index）。
- 问题 3：`userLabelMap[...] ?? author || '未知'` 触发 `??`/`||` 混用语法错误。
  - 解决方案：加括号 `(userLabelMap[n.author] ?? n.author) || '未知'`。
- 遗留问题：`npx tsc -b` 全量构建仍有 `ChangeRecordTab.tsx` 的 5 处类型错误——该文件由并行任务其他 agent 开发中（git status 显示 untracked、行号随时间变化），不在本任务 MUST NOT 修改范围内，MeetingRecordTab 自身零错误。
