### 开发内容详述

#### 后端
- **数据模型**：`ProjectProposalComment` 表含 id / proposal_id(FK) / creator_id(FK) / content(Text) / created_at(DateTime)，proposal_id 建索引
- **Schema**：`Create`（proposal_id + content）、`Response`（含 creator 嵌套信息）、`ListResponse`
- **Service 权限**：
  - `list`：`get_project_proposal` → `require_project_member`
  - `create`：`get_project_proposal` → `require_project_member` → `require_project_section_permission("proposals")`
  - `delete`：`require_project_member` → `require_project_section_permission("proposals")` → 仅创建人/全局 admin/项目 owner 可删除
- **API**：`GET /project-proposal-comments?proposal_id=`（分页）、`POST /project-proposal-comments`、`DELETE /project-proposal-comments/{comment_id}`
- **迁移**：038 创建 `project_proposal_comment` 表，接在 037 之后

#### 前端
- **提案详情页**（`/projects/:id/proposal/:proposalId`）：
  - **头部布局**：与 ProjectDetailPage 完全一致，`<Space>` + `<Button icon>`（返回）+ `<Title level={4}>`（编号+标题）+ `<Tag>`（状态），右侧操作按钮区
  - **`<Card>` 包裹 `<Tabs>`**：与 ProjectDetailPage 一致的结构
