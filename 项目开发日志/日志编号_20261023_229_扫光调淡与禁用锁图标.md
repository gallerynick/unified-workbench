### 开发内容详述

**1. 扫光调淡**

| 项 | 之前 | 现在 |
|----|------|------|
| 颜色（浅色） | var(--text-secondary) #8c8c8c | **var(--text-tertiary) #bfbfbf** |
| 不透明度（浅/深） | 0.55 / 0.7 | **0.32 / 0.4** |
| 带宽 | 0→100% 整幅 | **25%→75% 窄带** |
| 周期 | 1.2s | 1.4s |

三个维度同时削弱：更浅的色、更低的不透明度、更窄的带宽，观感由"明显扫光"变为"淡淡掠过"。

**2. 禁用态淡锁**

- 组件在 `disabled` 时于滑块内渲染 `<LockOutlined className={styles.lockIcon} />`
- 样式：12px、var(--ink-muted-48)、opacity 0.55；叠加禁用态整体 0.45 的不透明度后，实际呈现为很淡的锁
- 图标用 @ant-design/icons，未引入 Emoji

### 遇到的问题与解决
- 问题：首次替换 import 时按「移除 LoadingOutlined」的旧字符串匹配，但该 import 早已删除，替换静默失败，导致 JSX 引用了未定义的 LockOutlined（tsc 报 TS2304）。
- 解决：改为在文件首行显式补 `import { LockOutlined } from '@ant-design/icons';`，重新跑 tsc 与 eslint 通过。
