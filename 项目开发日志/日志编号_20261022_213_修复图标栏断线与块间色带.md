### 开发内容详述

**1. 现象**

用户截图显示：深色模式下侧边栏收起为图标栏后，右边缘的竖线在图标之间呈「断续」状态，
且每个图标所在区域呈现为略亮的横向色块。

**2. 根因（本次引入的回归）**

上一轮（日志 212）为了在图标栏加类别分隔，把业务区从「单个扁平 Menu」改为
「每类别一个 Menu + 外层 div」。由此产生两个副作用：

- `.categorySection { padding: 0 0 1px }`：每块比相邻块多 1px 高度，叠加处覆盖 Sider 右边缘
- antd 的 `.ant-menu` 自带背景色，而 Sider 深色背景是 `--canvas: #141414`、
  菜单区块背景偏向 `--bg-tertiary: #262626` 系，于是每块成为一条略亮的横带，
  块与块之间的缝隙把 Sider 的 border-right 盖住，形成断续竖线

浅色模式下 `#f5f5f5` 与 `#ffffff` 对比弱，几乎不可见；深色才暴露。

**3. 修复**

```css
.categorySection { padding: 0; }
.categorySection :global(.ant-menu) { background: transparent; }
.siderMenuRail :global(.ant-menu) { background: transparent; }
```

- 去掉 1px 下内边距，各块等高，不再遮挡边缘
- 业务区与图标栏的 Menu 背景统一透明，让 Sider 背景贯通，色带消失

图标栏的分块容器补上 `siderMenuRail` 类名以便命中选择器。

### 遇到的问题与解决

- 问题：一度怀疑是全局 `[data-theme="dark"] .ant-layout-sider` 的 border-right 与内联 style 重复。
- 核实：两者同值（`1px solid var(--border-secondary)`），不产生双线。真正原因是子元素背景遮挡，非边框叠加。

- 问题：本次修复前无法用浏览器复现深色效果。
- 处理：依据截图现象 + 样式层级推断定位；两类修复均为「透明化 / 去 padding」这类确定性改动，
  并在构建产物中确认选择器已生效。
