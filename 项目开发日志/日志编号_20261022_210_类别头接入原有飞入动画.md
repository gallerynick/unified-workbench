### 开发内容详述

**1. 根因**

原有侧栏进场动画只覆盖三类节点：

```css
:global(.sidebar-entered .ant-menu-item),
:global(.sidebar-entered .ant-menu-submenu-title),
:global(.sidebar-entered > div:first-child),   /* Logo */
:global(.sidebar-entered .sider-menu-scroll)   /* 滚动容器 */
```

新增的类别头是 `<button class={styles.categoryHeader}>`，**不在其中**。因此：
菜单项从 `opacity: 0 + translateX(-16px) + blur(6px)` 逐个飞入，而 5 个类别名早已满不透明就位——两者不同步，视觉上脱节。

**2. 处理原则**

严格按要求：`@keyframes menuItemFlyIn`、300ms、`ease-out`、40ms 步进**全部不动**，只把类别头接进同一条时间轴。

**3. 三处接线**

| 位置 | 改动 |
|------|------|
| 进场前静止态 | 把 `[data-cat-header]` 加入 `opacity: 0; translateX(-16px)` 规则组 |
| 进场动画 | 把 `[data-cat-header]` 加入 `animation: menuItemFlyIn 300ms ease-out forwards` 规则组 |
| 延迟分配 | `assignMenuAnimDelays` / `clearMenuAnimDelays` / 节点计数，统一改用 `MENU_ANIM_SELECTOR` 常量，其中追加 `[data-cat-header]` |

**4. 为什么用 data 属性而不是 class**

`styles.categoryHeader` 经 CSS Modules 哈希，`document.querySelectorAll('.categoryHeader')` 无法命中。改用稳定的 `data-cat-header` 属性：JS 查询与 CSS 属性选择器共用同一个钩子，不受哈希影响。

**5. 时间轴效果**

DOM 顺序天然是「类别头 → 该组菜单项 → 下一个类别头 …」，纳入同一序列后：

```
0ms    常用
40ms   首页
80ms   通知中心
...
200ms  协作办公
240ms  公告通知
...
```

类别名作为分组标题**先于**其成员出现，符合「先有容器再有内容」的阅读顺序。
