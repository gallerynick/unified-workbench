### 开发内容详述

#### 着色器改造（Task 1）
GRID_FS 新增 6 个 uniform：
| uniform | 类型 | 默认值 | 作用 |
|---------|------|--------|------|
| u_concavity | float | 1.0 | 凹面强度（k = 1.5 × u_concavity） |
| u_flowSpeed | float | 1.0 | 网格流动速度倍率 |
| u_bandDarken | float | 1.0 | 中间暗带强度（0=去除） |
| u_brightness | float | 1.0 | 全局亮度倍率 |
| u_white | float | 0.0 | 全白叠加量（0→1） |
| u_blur | float | 0.0 | 模糊强度 |

稳态默认值 = 原有硬编码值，确保渲染无回归。

#### 箭头交互改造（Task 2）
- CSS 去 `pointer-events: none`，加 `cursor: pointer`、hover/active 反馈
- 箭头 JSX 加 `onClick` 和键盘支持（`onKeyDown`）
- 点击执行 `handleArrowClick`：隐藏箭头 + 置 `transitionTriggeredRef` + 记录 `transitionStartRef`

#### 动画时间线（点击 t=0，总约 6s）

| 时间 | 阶段 | 效果 | 实现 |
|------|------|------|------|
| 0–0.8s | A 汇聚满额 | 粒子从 8000 平滑变为 22750 全部成型 | fadeOut 用 phaseA 平滑过渡，取消 i<8000 限制 |
| 0.8–2.4s | B 两侧吸走 | 粒子被吸向左右两侧 | 每粒子随机方向，弹簧力拉向 x=±1.6，竖直轻微收缩 |
| 1.8–3.0s | C 去暗带+提亮 | bandDarken 1→0，brightness 1→1.4 | smoothstep(1.8, 3.0) 插值 |
| 2.4–4.2s | D 指数加速 | flowSpeed 1→18 | exp(2.2·t) 归一化后乘 17 |
| 3.4–4.8s | E 曲面变平面 | concavity 1→0 | smoothstep(3.4, 4.8) 插值 |
| 4.2–5.4s | F 全白+模糊 | white 0→1，brightness 继续升到 2.0+ | smoothstep 插值 |
| 5.8s+ | G 转场 | 全白收尾进入主界面 | navigate('/') |

#### 全白转场
- 5.8s 触发 `navigate('/', { replace: true })`
- 使用 `navigatedRef` 防止重复触发
