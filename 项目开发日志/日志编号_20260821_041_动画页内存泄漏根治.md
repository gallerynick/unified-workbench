### 开发内容详述

**根因分析（多因素叠加）：**
1. **resize 取消 RAF 后不重启** — resize 事件取消动画帧后未重新调度，导致后续逻辑异常
2. **RAF 永不停止** — 标签页隐藏时动画仍在 60fps 运行，持续分配
3. **2000 粒子 × shadowBlur** — Canvas 2D shadow 操作每粒子每帧创建内部阴影缓冲区，2000×60=120,000 次/秒
4. **每帧字符串分配** — shadowColor 每粒子每帧拼接新字符串

**修复措施：**
1. **Particle count 2000→800** — 减少 60%，shadow 缓冲区分配从 120K/秒降至 48K/秒
2. **Page Visibility API** — 标签页隐藏时停止 RAF 循环，恢复时重启，彻底消除后台内存增长
3. **startLoop/stopLoop 分离** — 明确的启动/停止接口，resize 时 stop→reinit→start，杜绝 RAF 泄漏
4. **固定 TRAIL_ALPHA=0.42** — 移除每帧 maxSpeed 扫描（2000 次 Math.hypot），减少 CPU 和分配
5. **ctx 存入 ref** — 避免闭包中 ctx 可能为 null 的 TS 错误
6. **移除 shadowColor 字符串拼接** — 从 fillStyle 提取 RGB 值，减少字符串分配

### 遇到的问题与解决
- 问题：startLoop 闭包内 ctx 被 TS 判定为可能 null
- 解决：ctx 存入 ctxRef，startLoop 读取时非空断言；frame 内用 `const c = ctx!`
