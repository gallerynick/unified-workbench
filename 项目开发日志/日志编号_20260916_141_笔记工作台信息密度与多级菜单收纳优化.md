### 开发内容详述

**一、顶部工具条：5 个控件收敛为 2 内联 + 1 个下拉**

改造前一行内挤着 5 个控件：图谱范围 Segmented、视图 Segmented、折叠左侧、
折叠右侧、新建笔记。折叠开关是两个几乎一样的图标按钮，语义重叠且占宽。

改造后内联只保留三个：面板显示 Dropdown（LayoutOutlined）、视图 Segmented、
新建笔记。左侧与右侧面板的折叠收进同一个 Dropdown 的 Menu 里：

  - 选项一：笔记列表 —— 文案与图标随状态反转（收起笔记列表 / 展开笔记列表，
    MenuFoldOutlined / MenuUnfoldOutlined）
  - 分隔线
  - 选项二：右侧面板 —— 同样随状态反转；图谱视图下 disabled，因为该视图
    根本没有右侧面板

两个开关合成一个入口后，工具条从 5 项降到 3 项，而两个面板仍然一步可达。

**二、图谱范围从页面工具条移入画布**

全局/局部图谱的切换原先放在页面级工具条，但只有图谱视图用得到，位置错位，
工作台视图下它只是空白占位。改为放在 .graphWrap 内的绝对定位浮层
（新增 .graphControls，top/right 取 --spacing-xs，z-index 取 --z-dropdown），
画布自洽，工具条进一步变空。

**三、侧栏：3 行控件收敛为 2 行**

改造前列表上方竖排 3 行：搜索框、分类 Select + 标签 Select 并列、
仅置顶 Switch + 视图 Segmented。两个 Select 并排时每个都很窄，标签的
maxTagCount 挤成一片。

改造后：
  - 第一行保留搜索框不动（高频操作，必须 1 次点击可达）
  - 第二行只放两个：筛选 Dropdown + 视图 Segmented

分类、标签、仅置顶收进筛选 Dropdown 的多级 Menu：
  - 「分类」子菜单：全部分类 + 各分类；当前项前置 CheckOutlined
  - 「标签」子菜单：清除标签筛选 + 各标签（带计数）；已选项前置 CheckOutlined
  - 分隔线
  - 「仅显示置顶」/「显示全部笔记」，文案随状态反转
  - 存在激活筛选时追加：分隔线 + 清除全部筛选

三处状态提示保证收纳后不「隐形」：子菜单标题回显当前值（如「后端」而不是
「分类」）、按钮上的 .filterCount 徽标显示激活数量、勾选图标标记已选项。

同时删掉侧栏底部冗余的「新建笔记」按钮——顶部工具条的新建始终可见，
折叠后的 rail 上也有新建图标，同一操作原本有三处入口。

**四、补齐树形模式缺失的置顶与删除**

平铺模式每行一直有置顶/删除两个行内按钮，但树形模式的 titleRender 只画
图标、标题、分类标签，完全没有操作入口——只能切到平铺才能置顶或删除，
这是个实打实的功能缺口。

补法：树形节点 hover 时在行尾淡入一个 MoreOutlined 下拉按钮（.nodeMore，
opacity 0 → 1，transition 用 --anim-fast），菜单为置顶/取消置顶 + 删除
（danger）。按钮加 onMouseDown stopPropagation，避免点操作时误触发节点选中。
hover 才显示，不占默认视觉空间。

**五、元信息面板：加面板头，只读信息改为可折叠**

改造前 320px 宽的面板里竖排 11 项：两条 Divider 分节标题 + 5 个可编辑字段
+ 5 行只读信息 + footer，滚动很长，可编辑区和只读区混在一起。

改造后：
  - 新增 .panelHead：「笔记属性」小标题 + 可见性 Tag。可见性是这块最常被
    查看的状态，提到最前面，同时从只读信息里删掉重复的那一行
  - 5 个可编辑字段包进 .fields，字段间距由 --spacing-xxs 放宽到 --spacing-xs，
    面板自身 gap 由 --spacing-sm 放宽到 --spacing-md
  - 只读信息（所有者、字数、创建/更新时间、父笔记跳转）包进 Collapse
    （ghost + size=small + defaultActiveKey=['detail']），默认展开、
    随时可收起
  - 两条 Divider plain 分节标题删除，分节职责由面板头与 Collapse 标题承担

**六、编辑器置顶控件的状态歧义**

原实现用 Switch，且 checkedChildren 与 unCheckedChildren 都渲染 PushpinOutlined——
开与关长得一模一样，无法判断当前是否已置顶。

改为状态明确的图标按钮：type 随 isPinned 在 primary / text 之间切换，
并加 aria-pressed 供辅助技术读取。

**七、间距整体放宽一档**

  侧栏：controls gap 与 padding 由 --spacing-xs 放宽到 --spacing-sm；
        treeWrap / flatList padding 由 --spacing-xs 放宽到 --spacing-sm；
        flatItemBody padding 由 --spacing-xxs 放宽到 --spacing-xs
  编辑器：editor padding 横向由 --spacing-md 放宽到 --spacing-lg；
        header gap 与 padding-bottom 放宽；bodyWrap margin-top 与
        statusBar padding-top 均由 --spacing-sm/--spacing-xs 上移一档
  元信息：panel gap、field gap、infoGrid gap 各放宽一档

**收纳边界（刻意不做的事）**

  - 保存、置顶、新建笔记、视图切换、搜索框：全部保持 1 次点击，不进菜单
  - 任何操作最多 2 次点击（打开菜单 + 点一项），不存在三级以上的路径
  - 所有被收纳的状态都有提示：徽标数量、子菜单标题回显、勾选图标、
    文案反转，不做无提示的隐藏

### 遇到的问题与解决

- 问题：eslint react-hooks/rules-of-hooks 报 2 处「useCallback 被条件调用」
  原因：toggleTag 与 clearAllFilters 最初写在 if (collapsed) 早退之后，
  折叠态返回后这两个 hook 就不执行了，hook 顺序不稳定。
  解决：把这两个 useCallback 移到早退判断之前；紧随其后的 filterItems
  只是普通数组字面量，不是 hook，留在原地无碍。

- 问题：GraphView.module.css 的 .loadingOverlay 变成未使用类
  原因：上一轮删除 500ms 假加载时清掉了 JSX，CSS 留着。
  解决：删除该类，并跑一次「TSX 引用的 styles.X vs CSS 定义的类名」双向
  差集脚本确认模块内既无「引用未定义」也无「定义未引用」。
