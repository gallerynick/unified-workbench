## 开发内容详述

### 1. 自绘工具条替代内置 toolbar

- FullCalendar 设 headerToolbar={false}，并在 global.css 中防御性隐藏 .fc-toolbar
- 自绘结构：圆形导航组（上一周期 / 今天 / 下一周期）+ 大标题（heading-1）+ segmented 分段切换（月/周/日/列表）+ 胶囊形「新建事件」按钮 + 权限说明图标按钮
- 标题不再依赖 FullCalendar 的 title 文案，改由 datesSet / viewDidMount 回调取 ViewApi（currentStart / activeStart / activeEnd / type）自行用 dayjs 格式化
- 周起始日 firstDay={1}（周一），周/列表视图区间随之从周一起算

### 2. 列表视图

- 新增 @fullcalendar/list 插件，注册 listPlugin 与 listWeek 视图
- 列表视图锚定当周，按 7 天分组展示，日期头区分 today 用 color-info 强调

### 3. 网格与事件（Apple Calendar 语言）

- 边框统一 hairline（--border-secondary）；网格容器 rounded-md + overflow: clip（保留 sticky 表头，不用 hidden）
- 表头 bg-secondary 底 + caption-strong；日期数字默认 text-secondary，今天为行动蓝实心圆（白字 caption-strong）
- 事件颜色通过 eventDidMount 写入 DOM 自定义属性 --cal-event-color，由 CSS 用 color-mix() 派生：
  - 周/日视图与月视图非全天事件 = 16% 浅彩底 + 3px 左侧实色条 + ink 深字
  - 月视图全天事件 = 实色底 + 白字（.cal-event-all-day / .cal-event-timed 双类区分）
  - 深色模式浅彩底提至 28% 保证对比度
- 因 FullCalendar 以行内样式写入颜色，相关规则使用 !important 覆盖
- 时间轴 slot 高 44px、时间标签 tabular-nums、今天整列 color-info-bg
- 「+N 更多」改为 text-link（color-info 文字链接，去灰底）
- 事件 hover 加 shadow-sm、焦点 outline 2px color-primary-focus
- 每日事件上限由 dayMaxEvents={true}（默认 5 条）收紧为 {3}，贴近 Apple Calendar 的月视图密度；
  溢出仍经「+N 更多」进入弹窗查看，行为不变

### 3.1 筛选与显示的口径一致性

### 4. 颜色筛选条

- 位置：工具条下方一行（约 40px），不做侧栏
- 「全部」+ 8 个颜色芯片（色点 + 中文名 + 当前视图范围内计数），支持多选
- 选中态用 tag-primary（color-info-bg 底 + color-info 字）；无事件的颜色芯片降透明度
- 未设置颜色的事件额外显示「未着色 N」提示（不作为可切换芯片）
- 偏好写入 localStorage key = calendar.activeColors，刷新后保持
- 筛选键取「显示色」而非原始存储值：未着色事件在日历上按默认蓝呈现，筛选键同样归入蓝色，
  保证「看到的即筛选所得」；编辑并保存这类事件会把颜色显式落库，顺带完成历史数据归一
- 联动：仅当筛选条选中单一颜色时，新建事件自动套用该颜色（经 CalendarEventModal 新增的可选 prop defaultColor 传入，向后兼容）

### 5. 事件弹窗 Apple 化

- datetime-local 原生控件替换为 antd DatePicker showTime（dayjs 值），提交仍序列化为 ISO 字符串，后端无感知；顺带修正了原先直接 slice(0,16) 截断 ISO 字符串导致编辑时显示 UTC 时区的隐患
- 容器 560 宽 + rounded-sm + shadow-md + padding 24；标题 heading-3；标签 caption-strong
- 输入控件高 36 + rounded-sm + border-primary，焦点 color-info 边框 + 光晕
- 颜色选择器：26px 圆点 + 选中双层环（内圆 + ink 外圈留白）+ 色名 tooltip + 当前色名文字
- footer：左侧危险文字按钮「删除此事件」（仅编辑模式），右侧「取消」（次级胶囊：canvas 底 + primary 字）与「保存」（primary 胶囊）

## 遇到的问题与解决

1. npm install 报 EPERM：~/.npm 缓存目录存在 root 属主文件（npm 历史 bug 所致），无法写入
   解决：使用 --cache ./.npm-cache 写入工作区内本地缓存完成安装，事后删除该目录，不改动全局配置
2. CSS Modules 类名传给 antd 组件报 TS2375（exactOptionalPropertyTypes: true）：Vite 的 CSSModuleClasses 为索引签名类型，noUncheckedIndexedAccess 下 styles.xxx 类型为 string | undefined，而 antd 的 className?: string 不接受 undefined
   解决：在 CalendarPage.tsx 与 CalendarEventModal.tsx 内各加一个 cx() 助手收敛为 string（仅包裹传给 antd 组件的类名，DOM 元素保持原样）
3. 事件颜色被 FullCalendar 以行内样式写入，普通 CSS 无法覆盖
   解决：.fc-event 相关规则使用 !important；并用 eventDidMount 注入 --cal-event-color 供 color-mix() 派生浅彩底与左色条
4. CalendarApi 无 getView() 方法（TS2339）
   解决：FullCalendar 6 中 view 是属性，改用 api.view
5. eventDidMount 参数隐式 any（EventInput 的 [extendedProp: string]: any 索引签名兜底）
   解决：显式标注 EventMountArg
6. CalendarColors.ts 索引访问报 TS2532 / TS2322
   解决：对 CALENDAR_COLORS[0] 加非空断言
7. --btn-active-scale token 的值本身已是 scale(0.95)，若再包一层 scale() 会得到非法值 scale(scale(0.95))
   解决：直接写 transform: var(--btn-active-scale)
8. start.sh 部署报 failed to update builder last activity time: ... operation not permitted（buildx 需写 ~/.docker/buildx/activity）
   解决：export DOCKER_CONFIG 指向工作区内 .docker-tmp（含从 ~/.docker 复制的 cli-plugins，且不带 config.json——
   config.json 里的 currentContext=desktop-linux 依赖 contexts 目录，复制过来会报 context not found），
   部署完成后删除 .docker-tmp
9. 首次部署后新 bundle 仍是旧 hash（JMnvm_8r）
   原因：frontend/Dockerfile 直接 COPY 本地 dist/，而 dist 是改动前构建的
   解决：本地重跑 npm run build 后再次 start.sh，bundle 更新为 5ga3xO4T

## 迭代 2（2026-09-08）首次上屏 UI 反馈修正

用户首次上屏反馈：标题缺失/过大、分段控件无滑块动画、FullCalendar 日数字错位、颜色筛选条不美观/透明度不当。均已修复并用无头 Chrome 复测。

### 1. 页级标题 + 小号周期标题

- 之前把周期标题做成超大 `h1._toolbarTitle`（heading-1 32px），既无页面标题又过大
- 改为与任务中心等页面一致的标准表头：`Title level={4}`「日程」+ 右侧操作组
- 周期标题降为 `heading-3`（20px / 600）secondary 色，紧跟页标题之后
- module.css：`.toolbar`/`.toolbarTitle`/`.rightGroup` → `.header`/`.headerLeft`/`.pageTitle`/`.monthLabel`/`.headerRight`

### 2. 分段控件滑块动画

- 之前逐个 button 高亮，无统一滑块
- 新增 `.segThumb`（canvas 底 + shadow-sm），用 `transform: translateX()` 跟随选中项平滑滑动（`--anim-normal` + `--anim-ease-in-out`）
- CalendarPage 内 `segRef` + `segThumb` state，effect 按选中项 getBoundingClientRect 计算位置，视图切换/尺寸变化时更新

### 3. FullCalendar 日数字错位（关键）

- 根因1：`.fc-daygrid-day-number` 未重置 box-sizing/padding，数字被多余内边距挤出
- 根因2（真正错位）：zh-cn locale 使日数字为「N日」（如 8日），而今天格是 28px 圆圈，二字溢出把「日」顶到圈外
- 修正：
  - number 加 `box-sizing: border-box; padding: 0 6px; min-width: 28px; height: 28px; font-variant-numeric: tabular-nums`
  - 新增 `dayCellContent={(arg) => String(arg.date.getDate())}` 只渲染纯数字，去掉「日」后缀，今天数字落在正圆内
  - 非本月日期不再叠加透明度（`.fc-day-other .fc-daygrid-day-top { opacity: .55 }` + number 只降色），避免文字过淡

### 4. 颜色筛选条重做

- 去掉 `.chipEmpty { opacity: .5 }`（透明度不当）；空计数仅用 text-tertiary 弱化数字，不整体降透明
- 容器由 canvas-parchment 改为 `canvas` + hairline + `shadow-sm`，更像干净工具面板
- 芯片高 30px，选中态 `color-info-bg` + `color-info`（tag-primary），圆点保持原色，间距与计数对齐更清爽
