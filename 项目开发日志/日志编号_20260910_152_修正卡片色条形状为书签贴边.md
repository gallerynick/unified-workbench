### 开发内容详述

#### 一、问题

日志 151 把「左边矩形、右边圆角」理解成了**卡片的剪影**，于是写了

```css
.card { border-radius: 0 var(--card-rounded) var(--card-rounded) 0; }
.accentBar { border-radius: 0 var(--card-rounded) var(--card-rounded) 0; }
```

结果整张卡片的左边被削成直角、右边圆角——剪影本身就是错的，色条再怎么
调都不对。用户实际想要的是：

> 在这个大的圆角矩形上的最左侧一点，有个像书签一样的那一条是有颜色的

即卡片本身是**完整圆角矩形**，色条是贴在它最左边缘的一条彩色书签。

#### 二、修正

```css
.card {
  border-radius: var(--card-rounded);   /* 四角恢复完整圆角 */
  border-left: none;                    /* 让色条直接成为左边缘 */
  overflow: hidden;
}

.accentBar {
  width: 6px;
  /* 不再自带圆角 */
}
```

关键点是色条**不再自带 border-radius**。靠 `.card` 的 `overflow: hidden`
配合卡片左圆角把色条的左上、左下角裁切掉，色条左端就**自然贴合卡片的
左圆角**；右端保持直线，与内容区衔接。

这样圆角只有一处来源（卡片自身），不会出现「色条圆角和卡片圆角对不齐」
的问题——上一版两处都写 `8px` 看似一致，但色条只有 6px 宽，8px 圆角会被
压成 3px 有效半径，实际和卡片圆角并不相等。

`border-left: none` 仍然保留：如果保留左边描边，色条左边会多出一条 1px
的描边线，破坏「色条即左边缘」的衔接感。

#### 三、颜色机制未变

色条颜色仍取自 `task.color`（调色板 key → design token），新建 / 编辑
弹窗选择后列表同步显示，本轮未改动。
