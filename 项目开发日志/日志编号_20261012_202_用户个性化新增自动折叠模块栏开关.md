### 开发内容详述

**需求**：用户个性化中添加「自动折叠模块栏」开关，点击模块后自动折叠侧边栏。

**设计**：偏好存入 `user.preferences`（JSONB），走既有 `GET/PUT /users/me/preferences`，换设备登录保持一致（与 `allow_multiple_logins` 同策略，不存前端本地）。

**1. 后端**

`user_preference.py`：
- `UserPreferenceUpdate` 新增 `auto_collapse_sidebar: bool | None = None`（不传保持原值）
- `UserPreferenceResponse` 新增 `auto_collapse_sidebar: bool = False`

`users.py`：
- GET：`prefs.get("auto_collapse_sidebar", False)`
- PUT：`if body.auto_collapse_sidebar is not None: prefs["auto_collapse_sidebar"] = ...`（复用 `flag_modified` 整列更新，注释说明不传保持原值）

**2. 前端**

`api/user-preferences.ts`：`UserPreferences` 与 `UpdateUserPreferencesRequest` 均新增 `auto_collapse_sidebar`。

`UserPersonalization.tsx`：新增第三个卡片「自动折叠模块栏」，用 antd `Switch`（checkedChildren 开启 / unCheckedChildren 关闭）+ 说明文字；加载时读 `res.data.auto_collapse_sidebar ?? false`，保存时随 `updateUserPreferences` 一并提交。

`MainLayout.tsx`：
- 新增 `autoCollapseSidebar` state，在既有 `getUserPreferences` 加载 effect 中读取
- Menu `onClick`：`navigate(key)` 后若 `autoCollapseSidebar` 为真则 `setCollapsed(true)`
- 仅叶子菜单项触发（子菜单标题走 `onOpenChange`，不触发折叠，符合「点击模块」语义）
