### 开发内容详述

**1. 「常用」降级为顶部常驻项**

原 `group:pinned` 分类被移除，改为独立的 `TOP_LEVEL_ITEMS`：
首页 / 通知中心 / 任务中心 / 日程日历。

渲染上，这 4 项单独用一个 Menu，位于所有类别之前，**不带类别头**：

- 展开态：顶部平铺，其后第一个类别头（「协作办公」+ 延伸细线）天然充当分隔，不需要额外横线
- 图标栏：顶部一组图标，其后每个类别之前补一条居中短横线

配置校验：顶部 4 项 + 4 个类别共 17 项 = 21 项，与改造前总数一致，无重复 key。

**2. 首页强制显示**

新增 `MANDATORY_ITEM_KEYS = ['/']`，在三处生效：

| 位置 | 行为 |
|------|------|
| `MainLayout` 的 `visibleSet` | 无论偏好如何都把强制项并入集合 |
| 个性化页勾选列表 | 首页复选框 `checked` + `disabled`，文案追加「（固定显示）」 |
| 保存载荷 | 写库前再做一次 `Set` 合并，防止异常状态把首页写没 |

加载侧同样做兼容：历史数据里若首页被取消勾选，读入时自动补回。

**3. 默认折叠状态调整**

原默认「只展开常用」，现顶部项已平铺，改为**所有类别默认折叠**（`ALL_CATEGORY_KEYS`）。
首屏因此是：4 个顶部项 + 4 个类别名 + 个人区/系统设置，比之前更短。

`.categorySection` 的 1px padding 与 Menu 背景透明化（日志 213 的修复）对顶部块同样生效，
顶部块复用了同一个类名，不会重新出现块间色带或右边缘断线。

### 遇到的问题与解决

- 问题：类别 map 改为在 Fragment 内渲染后，JSX 闭合错位（`})` 需变 `})}` 并补 `</>`）。
- 处理：按 tsc 报错逐处修正至 0 错误。

- 说明：localStorage 里可能残留旧的 `group:pinned` 折叠记录。该 key 已不对应任何类别，
  匹配不到即无副作用，未做迁移。
