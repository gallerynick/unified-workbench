### 开发内容详述

原实现用 `border-top-color` 只亮一边再旋转，视觉上是「一段线在滑块边上搅」。改为整流描边一起呼吸：

```css
.isLoading .thumb::before {
  inset: 0;
  border-radius: inherit;
  box-shadow: inset 0 0 0 2px var(--color-info);
  animation: thumbEdgeBreath 1.4s var(--anim-ease-in-out) infinite;
}
@keyframes thumbEdgeBreath {
  0%, 100% { opacity: 0.12; }
  50%      { opacity: 1; }
}
```

- 用 `box-shadow: inset` 而不是 `border`：滑块有 `overflow: hidden`，外发光会被裁掉，inset 阴影贴着内轮廓，整圈同时亮
- 起伏用 opacity，不改变尺寸，不触发重排
- 节奏 1.4s 一个呼吸周期，与扫光 1.2s 相互错开，观感不打架
- `prefers-reduced-motion` 下呼吸周期放慢到 2.8s

### 遇到的问题与解决
- 问题：上一轮修改未生效（构建产物仍是折返版）。
- 根因：替换用的字符串是 prettier 折行前的形态，实际文件已被 prettier 压成单行，replace 静默未命中。
- 解决：先读出当前实际内容再按精确文本替换，并核对构建产物 CSS 内已含新的 keyframes 名。
