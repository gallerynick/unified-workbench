### 开发内容详述

**1. 数据模型抽离**

原 `SIDEBAR_ITEMS` 扁平数组从 `MainLayout.tsx` 抽到 `config/sidebarConfig.ts`，改为 5 个领域分类：

| 分类 | 组 key | 项数 | 包含 |
|------|--------|------|------|
| 常用 | group:pinned | 4 | 首页 / 通知中心 / 任务中心 / 日程日历 |
| 协作办公 | group:collab | 6 | 公告通知 / 成员目录 / 联系人管理 / 投票决策 / 表单收集 / 会议记录 |
| 内容知识 | group:content | 3 | 笔记知识库 / 内容编辑 / 文件共享 |
| 项目管理 | group:project | 3 | 项目管理 / 密钥保险箱 / 提醒事项 |
| 资产运维 | group:ops | 5 | 物品管理 / 财务中心 / 拓扑结构 / 服务器管理 / 直播工作室 |

合计 21 项，与原扁平数组一一对应（已脚本校验无重复、无遗漏、与个人区 5 项无 key 冲突）。

组 key 一律用 `group:` 前缀，杜绝与真实路由重合导致 antd `selectedKeys`/`openKeys` 误判。

**2. 类别分隔形态（按用户新要求，非 Submenu）**

每个类别是一个自定义块：`<button class="categoryHeader">` 承担「横线 + 类别名 + 折叠箭头」，点击整组收起/展开。**不使用 antd Submenu**，因此没有缩进与子菜单弹层，视觉上是「分隔线 labelled by 类别名」。

三个类别块各是一个独立 `<Menu>`（非嵌套），保留 antd 原生的选中态/悬停态/主题 token，不必重写一套菜单样式。

**3. 分隔线层级（用户明确要求）**

新增两条组件级 token：

- `--sider-category-divider: 1px solid var(--border-tertiary)` → 类别之间，**淡**
- `--sider-section-divider: 1px solid var(--border-primary)` → 模块/设置之间，**深**

底部区块（个人区 + 系统设置）的 `ant-menu-item-divider` 通过 CSS 覆盖加深到 `--border-primary`，与类别淡线拉开层级。

**4. 侧栏显示项与「未显示」折叠桶**

- 偏好字段 `sidebar_visible_items: string[] | null`：`null` = 未设置（全部显示），空数组合法（用户全部取消勾选）
- 未勾选项不进各自分类；`sidebar_fold_unchecked` 开启时，底部（个人区之上）出现「未显示」分组收纳它们，可展开；关闭则完全不渲染该分组
- 个性化页提供分组勾选列表 + 「全部显示」/「仅保留首页」快捷；**禁止取消最后一项**（会让业务菜单区整个消失，属自伤型配置）

**5. 密度与 WebSocket 无关的即时同步**

`sidebar_density: 'compact' | 'comfortable'` 通过 ConfigProvider 的 `Menu.itemHeight`（32 / 40）生效。保存后派发 `sidebar-prefs-changed` 自定义事件，MainLayout 监听即时生效，无需刷新。

**6. 移动端 Drawer 同步**

原 Drawer 的 Menu 未接 `openKeys`，且与桌面共用旧的 `getMenuItems()`。本次改为与桌面共用同一套类别分块与折叠状态（`collapsedGroups`），并把 `openKeys` 传入底部系统设置菜单——否则分组后手机端打开抽屉看不到当前页所在分组。

**7. 顺带修复**

- `routeTitles.ts`：补 `/meetings`（会议记录）、`/settings/third-party`（第三方服务）；把历史错误的 `/stream` 改为真实路由 `/streaming`。此前这两页标题取不到值，`getRouteTitle` 返回空串，页面标题是空的。
- 侧栏动画清理超时原写死 1500ms，而延迟按 40ms × DOM 序号递增。分组后节点数上升到 38+，`40 × 42 = 1680ms` 已越过固定值，末尾几项会在动画开始前被清掉 delay（表现为「跳出来」）。改为 `max(1500, nodeCount × 40 + 400)`。
- 「自动折叠模块栏」改为只对一级菜单生效（`LEVEL_ONE_KEYS`）。分组后点二级项也收起侧栏会打断同级浏览。
- `selectedKey` 前缀匹配改用完整业务 key 集，并补 `/stream/watch/:id` → 高亮「直播工作室」（此前该页无任何菜单高亮）。

**8. 后端字段（JSONB，无迁移）**

`user_preferences` 是 JSONB 列，加字段不需要 Alembic 迁移。三个新字段沿用既有 `None` 哨兵模式：`None` = 不传保持原值，`[]` 是合法值。响应侧 `sidebar_visible_items` 默认 `null`（全部显示）、`sidebar_fold_unchecked` 默认 `false`、`sidebar_density` 默认 `comfortable`。

### 遇到的问题与解决

- 问题：并发会话反复改动 `MainLayout.tsx`，多次报 `file changed since it was read`。
- 解决方案：把 `read` 与 `edit` 放进同一次程序执行，令版本校验与写入之间无窗口期。

- 问题：批量编辑时 `users.py` 的响应构造片段在 GET 与 PUT 两处完全一致，`old_string` 匹配 2 次报错。
- 解决方案：改用 `replace_all: true`，两处同步加字段（已核验 108-110 与 154-156 两份响应均更新）。

- 问题：`SIDEBAR_CATEGORIES[0].items[0].key` 触发 TS2532（`noUncheckedIndexedAccess`）。
- 解决方案：改为字面量 `['/']`。

- 遗留：`assignMenuAnimDelays` 在折叠类别、改密度时仍会整体重跑一次。因 CSS 动画只在节点首次挂载时播放，重设 delay 不会重放动画，实际影响仅为展开某组后新节点延迟可能略偏；视觉上可接受，未进一步处理。
