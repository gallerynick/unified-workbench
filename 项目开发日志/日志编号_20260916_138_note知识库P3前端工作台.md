### 开发内容详述

**T3.2 三栏工作区 NoteWorkspace**

左 280px 侧栏（可折叠至 60px 图标栏）｜中弹性区（编辑器或图谱）｜右 320px 面板
（可折叠，Tabs 分「元信息」「反向链接」）。顶部工具条含：标题、新建、视图切换
（工作台 / 图谱）、图谱范围切换（全局 / 局部 depth=1）、左右折叠开关。
路由保持 /notes，LazyPage 包裹不变。

计划中工具条的搜索框改放在侧栏顶部：它与过滤结果同屏，交互路径更短，功能一致，
仅位置调整。

**T3.3 侧栏 NoteSidebar**

搜索 300ms debounce、分类下拉、标签多选（数据源 listNoteTags）、仅置顶开关、
树形/平铺切换（Segmented）。树形沿用 buildTree 逻辑 + draggable + onDrop 调
moveNote（后端拒绝自身/子节点下移动时提示并回滚列表）。条目含文件夹/文件图标、
置顶图钉、分类色块；平铺态 hover 显置顶与删除操作，删除有 Modal.confirm 二次确认
（含子笔记数量提示）。

偏离计划的一处：计划写搜索调 listNotes({search})，实际改用 listAllNotes + 前端过滤。
原因是后端 list_notes 在不传 parent_id 时只返回根笔记（根/子互斥），服务端搜索
结果无法构建树结构；受限于 20 人小团队与 <10 万条记录，前端过滤性能可接受。

**T3.4 编辑器 NoteEditor + 草稿 useNoteDraft**

标题无边框大字号输入 + 置顶 Switch + 保存按钮。正文复用 P2 全局化的
ContentEditor，注入 noteExtensions({ onNavigateNote })，minHeight 480。
底部状态条显示字数（遍历 Tiptap JSON 累加 text 节点）与草稿保存状态。

useNoteDraft 用 baseline 引用区分「载入」与「编辑」：打开笔记时同步调用
reset(noteId, title, body) 把当前值记为基线，之后 body/title 相对基线变化才排期
保存；切换 noteId 自动重置。否则打开任意笔记都会触发一次 state 变化并被误判为
用户编辑，凭空写出一条草稿。发布成功后 clear() 取消排队并删除服务端草稿。

旧版纯文本正文（只有 content 列）用 textToBody 包成单段 paragraph 载入，避免
老笔记打开后内容丢失。

**T3.5 元信息 NoteMetaPanel**

可编辑分类、标签、受限标签、父笔记（TreeSelect，排除自身及后代防环）、置顶
（Switch）；只读可见性、所有者、字数、创建/更新时间、父笔记跳转。

偏离计划：计划写「复用 VisibilitySetting 编辑可见性」，实际只做只读 Tag 展示。
原因是后端 NoteCreate/NoteUpdate schema 不含 visibility / restricted_users 字段，
提交会被 Pydantic extra=ignore 静默丢弃——写进去就是伪功能。可见性编辑需后端先补
schema，本次不碰。

**T3.6 反向链接 BacklinksPanel**

调 getBacklinks(noteId) 列被引用来源，点击跳转；空态用 Empty + 引导文案。

**T3.7 图谱 GraphView**

props 从 notes 数组改为后端 GraphData（nodes/links 已按可见性过滤），节点 degree
由 links 前端补算用于尺寸与 tooltip。新增全局图谱（getGlobalGraph）与局部图谱
（getGraph(id, depth)）两种入口，工具条 Segmented 切换；局部图谱未选笔记时禁用。
无出边的孤立节点用 Alert banner 显式说明，避免被误读为图谱加载失败。
交互参数保留 P2 设定（charge -400 / distanceMax 300 / link distance 80 /
strength 0.5 / hover 高亮邻居 / 分类 12 色板 / zoomToFit / warmupTicks 200）。
删除 notesToGraphData.ts（图谱数据源已迁到后端 note_link 表）。

**T3.8 收尾**

router.tsx 两处引用切到 NoteWorkspace；grep 确认 src 下 NoteManagement / NoteModal

### 遇到的问题与解决

- 问题：后端 list_notes 不传 parent_id 只返回根笔记，服务端搜索无法构建树
  解决方案：侧栏改用 listAllNotes + 前端过滤，计划偏离已在本文与实施计划中记录

- 问题：antd Tree 的 DataNode.children 在 exactOptionalPropertyTypes 下不能赋
  ParentTreeNode[] | undefined
  解决方案：父笔记树节点 children 改为恒为数组（空数组即叶子，rc-tree 按
  children.length 判叶），不再出现 undefined

- 问题：Switch 属性名写错为 uncheckedChildren
  解决方案：改为 unCheckedChildren（大写 C）

- 问题：mypy 报 note_draft.body 与 note_text 函数缺 dict 泛型参数（type-arg）
  解决方案：统一改为 dict[str, Any] 并补 typing.Any 导入；仓库存量 mypy 告警
  （no-untyped-def 等）属既有债，本次未扩大范围

- 问题：路由文件同时含并行开发的改动（lazyChunk / ErrorBoundary）
  解决方案：只抽取本次的 2 处 NoteManagement → NoteWorkspace 引用入库，
  并行改动保留在工作区随其自身提交落地

- 遗留问题 / 待办：
  1. 可见性编辑能力（后端需先补 NoteCreate/NoteUpdate 的 visibility 与
     restricted_users 字段）
  2. 表格（table / row / cell / header-row）与代码块语法高亮（lowlight），
     受零新增依赖约束明确延后
  3. 图片仅支持 URL 插入，无上传 API
  4. 服务端全文搜索未用上 pg_trgm 的 GIN 索引（当前是 ILIKE，正确但可优化）
