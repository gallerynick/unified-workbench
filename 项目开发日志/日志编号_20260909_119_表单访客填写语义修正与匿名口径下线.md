### 开发内容详述

**1. 语义拆分：可见性 与 未登录访问 是两个独立维度**

- 可见性（public / restricted）只回答「哪些工作台内人员可填」
- 「允许未登录填写」是独立开关：开启后未登录访客也可凭链接填写，提交者记为「访客」；关闭后仅登录用户可填
- 开关标签由「允许匿名提交」改为「允许未登录填写」，说明改为「开启后未登录访客也可通过链接填写，提交者记为「访客」；关闭后仅登录用户可填写」

**2. 未登录拦截：静默跳登录 → 页面内提示**

- request() 新增 skipAuthRedirect 选项：401 时不自动 window.location.href 跳登录页，只抛 HttpError，交由调用方就地处理。其余接口行为不变
- getFormPublic 透传该选项；FormFill 以 skipAuthRedirect=true 拉取表单，401 时渲染 Result（403「仅允许登录用户填写」/「该表单未开启「允许未登录填写」，请先登录后再提交」/「去登录」按钮）
- 未登录访问受限 / 私有表单仍是 404，不泄露资源存在性

**3. 「匿名」口径全栈下线 → 「访客」**

- 提交者展示名：后端回复列表与导出（xlsx / csv）统一改为「访客」
- 统计字段：anonymous_count → visitor_count（schema / service / 前端类型 / 统计页概览「访客回复」）
- 代码标识：allow_anonymous → allow_visitor；ANONYMOUS_SUBMIT_LIMIT/WINDOW → VISITOR_SUBMIT_LIMIT/WINDOW；_check_anonymous_submit_rate_limit → _check_visitor_submit_rate_limit
- 数据库物理列名保留 allow_anonymous（避免对线上库执行 ALTER），模型层用 mapped_column("allow_anonymous", ...) 显式映射到 allow_visitor，读写不受影响

**4. 门禁顺序保持「先可见性、再登录」**

- 顺序反了会把受限 / 私有表单对未登录者从 404 变成 401，泄露资源存在性。本轮改名后该顺序未变，已实测确认

**5. 外键删除问题回归确认**

- 「有回复的表单删不掉」的修复（日志 118：delete_form 先显式删回复再删表单 + 模型 FK 补 ondelete=CASCADE）本轮未改动，回归确认仍在位（app/services/form.py:203-205）
