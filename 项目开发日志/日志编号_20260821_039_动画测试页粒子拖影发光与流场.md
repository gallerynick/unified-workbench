### 开发内容详述

**拖影（运动模糊）：**
- 每帧计算全局最大速度 `maxSpeed`
- 速度越大 → 拖影填充 alpha 越小 → 旧帧残留越久 → 拖影越长
- 公式：`trailAlpha = MAX_TRAIL_ALPHA * (1 - speedNorm * 0.65)`，`speedNorm = min(1, maxSpeed / 900)`
- 速度范围 0-900px/s，拖影 alpha 从 0.32 降至 0.11

**发光：**
- 使用 Canvas 2D `shadowBlur` + `shadowColor`
- 速度越大 → `shadowBlur` 越大（最大 20px）
- `shadowColor` 使用粒子色，alpha 为 `p.alpha * 0.55`
- 每粒子绘制后重置 `shadowColor = 'transparent'`，避免叠加累积

**微失真：**
- 抖动幅度 = `DREAM_JITTER(0.7) + speedNorm * 2.5`
- 静止时 0.7px，高速时最大 3.2px

**汇聚后呼吸 + 流场：**
- 恢复 `FLOW_STRENGTH = 30` 的流场噪声
- 恢复 `DRIFT_DAMP = 0.94`
- 保留 `BREATH_AMP = 6` 的呼吸
- 流场公式：`flowAngle = sin(x*0.003 + t*0.1) * cos(y*0.004 - t*0.08) * π * 2`

### 遇到的问题与解决

- 解决方案：删除两个未使用常量，拖影改用动态 alpha 字符串
