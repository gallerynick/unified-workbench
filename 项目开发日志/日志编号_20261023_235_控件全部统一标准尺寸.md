### 开发目标
1. 全站表单类控件与按钮统一为默认档（32px）
2. 消除 size="small" / size="large" 在表单控件上的分级

### 涉及模块 / 文件
- 修改范围：frontend/src 下 58 个 .tsx 文件（脚本批量去除 size 属性 + 2 处手工定点）
- 典型文件：pages/Login.tsx、pages/streaming/StreamStudio.tsx、pages/meetings/MeetingRoom.tsx、components/NotificationBell.tsx 等

### 开发内容详述

**处理对象（控件类）**

Button、Input（含 Input.Password / Input.TextArea）、Select、InputNumber、Switch、Form 上的 `size="small"` / `size="large"` 全部移除，回到主题默认 `controlHeight: 32`。

统计：**191 处**由脚本移除（57 文件），另 **2 处**手工定点补齐（Login 的 `<Form size="large">`、StreamStudio 的测速按钮），合计 **193 处**。

**保留不动**

- Space / Spin / List / Descriptions / Card / Table / Steps / Tooltip / Collapse / Tabs / Progress / Badge / Tag 的 size —— 这些是排版间距或指示器尺寸，不是控件高度
- 测试页沙箱内 size="sm" / "lg" —— 用于演示尺寸档

**统一后的默认高度**

| 控件 | 高度 |
|------|------|
| 输入框 / 下拉 / 日期 / 数字输入 | 32 |
| 按钮（含图标按钮） | 32 |
| 开关 AppSwitch | 32（滑块 28） |
| 分段控件 Segmented | 32 |

### 遇到的问题与解决

- **问题**：脚本用"最近的 < 标签"判定所属组件，遇到 `<Form<LoginRequest>` 这种带类型参数的开标签、以及 `icon={<Xxx />} ... size="large"` 这种属性前有 JSX 的写法会误判，导致 Login 的 Form 与 StreamStudio 的按钮被漏掉。
- **解决**：改为对这 2 处做定点替换，并在完成后再跑一次全量 grep 复核。
- **严重问题（已修复）**：清理单引号写法时用了 `/  +/g` 压缩空白，把 MeetingRoom.tsx 的整份缩进压平（样式仍正确但格式全毁）。
- **修复**：对该文件执行 prettier --write 恢复标准缩进，tsc 复核通过。教训：不做全局空白压缩，只做定点替换。
