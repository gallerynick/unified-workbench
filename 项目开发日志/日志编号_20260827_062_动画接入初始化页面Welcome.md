### 开发内容详述

**1. TestPageAftermath.tsx — 新增 onComplete 回调**
- 组件签名：`AftermathAnimationSection({ onComplete })`，新增 `AftermathProps` 接口
- 新增 `completeRef` 防止重复触发
- 白屏阶段（`whitePhase >= 1.0`）时调用 `onComplete()`，用于衔接后续画面

**2. Welcome.tsx — 接入动画**
- 新增 `showAnimation` state（默认 true）
- 添加 `AftermathAnimationSection` import
- 在检查完初始化状态后：
  - 已初始化 → 保持原有"前往登录"按钮
  - 未初始化且 `showAnimation` → 渲染动画层，`onComplete={() => setShowAnimation(false)}`
  - 动画完成后 → 显示原有 4 步初始化流程（欢迎/创建管理员/应用设置/完成）

**3. 流程**
```
访问 /welcome（未初始化）
  → 播放动画（打字机→开始使用→过渡→白屏）
  → onComplete → 切换 showAnimation=false
  → 显示原有初始化 Steps（欢迎→创建管理员→应用设置→完成）
```
