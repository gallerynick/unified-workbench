### 开发内容详述

上一轮为了解决徽标出现后按钮变宽的问题，把数量做成了主色底色的胶囊徽标：
固定 17px 见方的圆角块、白色数字。占位恒定的机制本身是对的，但底色壳让
按钮里出现了一块面积不小的实心色块，和旁边「筛选」文字、箭头的轻量文字
风格不匹配，视觉上偏重。

本轮改为纯文本：

  删掉的：display: inline-flex / align-items: center / justify-content: center /
         height: 17px / border-radius: 胶囊 / background: 主色 / color: 反色
  保留的：width: 17px（固定宽度）、margin-left: 8px、overflow: hidden
  新增的：display: inline-block、text-align: center、color: var(--text-secondary)

两点必要说明：

1. width 必须保留。纯文本的宽度会随数字位数变化（1 位与 2 位相差约 6px），
   保留固定 17px 的宽度槽，按钮宽度才能在筛选前后恒定、也不因位数抖动。
2. display 必须从 inline-flex 换成 inline-block。inline 元素不生效 width，
   宽度槽会直接失效，上一轮的溢出问题会重现；inline-block 让 width 生效，
   同时 text-align: center 负责水平居中，不需要 flex 三件套。

颜色从主色底上的反色文字改为 var(--text-secondary)（浅色 #8c8c8c /
深色 #a6a6a6），与按钮内其他次要元素的分量一致；不再使用
var(--text-inverse) 与 var(--color-primary)。

### 遇到的问题与解决

- 问题：纯文本方案下 width 失效的隐患。
  原因：span 默认 display: inline，inline 元素的 width 被浏览器忽略，
  宽度槽一旦失效，按钮宽度会重新随数字位数变化。
  解决：显式声明 display: inline-block，宽度槽才真正生效。
  已在注释中写明原因，避免后续维护时误删。
