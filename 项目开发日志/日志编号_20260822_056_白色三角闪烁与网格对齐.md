### 开发内容详述

#### 1. CSS 改动 (TestPageAftermath.module.css)

**删除旧闪烁动画**：移除 `.flashing`/`flashWhite`/`.expanding`/`expandWhite`/`.done` 全部旧 CSS。

**whiteOverlay 改为格子尺寸**：
- 从 `width:100vw; height:100vh` 改为无固定尺寸（通过 inline style 设 `width/height = cellSize`）
- `background: transparent`（三角形 div 各自带白色背景）

**新增三角形 div**：
- `.triUpper`: `clip-path: polygon(0 0, 100% 0, 100% 100%)` — 右上三角（TL→TR→BR 对角线分隔）
- `.triLower`: `clip-path: polygon(0 0, 0 100%, 100% 100%)` — 左下三角（TL→BL→BR 对角线分隔）
- 两者合起来覆盖完整方格，对角线为 TL→BR

**canvas 加 transform-origin**：`transform-origin: center center` — 为 CSS scale 缩放做准备

#### 2. 时间常量 (TSX)

| 常量 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| SCATTER_DURATION | 6.0 | 4.0 | 总时长缩短 |
| GRID_RESTORE_START | 3.0 | 2.0 | 恢复开始提前 |
| GRID_RESTORE_DURATION | 3.0 | 2.0 | 恢复更快 |
| SCRAMBLE_END | 0.5 | 0.8 | 打乱阶段加长 |
| FLASH_DURATION | — | 1.5 | 新增：三角闪烁时长 |
| SCALE_DURATION | — | 0.8 | 新增：放大过渡时长 |

#### 3. 新增 refs/state

- `whitePhaseRef(0)`: 跟踪白色阶段（frame 循环可读）
- `whiteFlashStartRef(-1)`: 三角闪烁开始时间
- `whiteScaleStartRef(-1)`: 放大过渡开始时间
- `triUpperRef/triLowerRef`: 三角形 div refs（JS 驱动 opacity）
- `cellSize state(0)`: 格子像素尺寸 = H/16
- `scaleMax state(1)`: 放大倍数 = max(W/cs, H/cs)

#### 4. handleArrowClick 改动

新增 cellSize/scaleMax 计算：
- `cs = window.innerHeight / 16`（网格 freq=16，一格高度）
- `scaleMax = Math.max(W / cs, H / cs)`（放大到覆盖全屏）

#### 5. update() 打乱逻辑改动（更柔和连贯）

**阶段1 柔和打乱 (0 ~ SCRAMBLE_END=0.8s)**：
- intensity 从 `1 - linear` 改为 `Math.pow(1 - t/SCRAMBLE_END, 1.5)` — ease-out 衰减
- angle 从固定随机改为 `baseAngle + wobble`，wobble = `sin(t*6 + hash*2π) * 0.8` — 时间变化角度，粒子摇摆而非恒定推力
- force 从 `2.0+hash*3.0`（2-5）降为 `1.2+hash*1.8`（1.2-3.0）— 更温和

**阶段2 渐变 blend-in 方向流 (从 SCRAMBLE_END*0.5=0.4s 开始)**：
- `flowBlend = min(1, (t - 0.4) / 0.4)` — 0→1 渐变
- `p.x += stream.speed * dir * dt * sw * 3.0 * flowBlend` — 从 0 渐变到全速
- 与打乱阶段重叠 0.4s（0.4-0.8s），消除硬切换

#### 6. frame() 白色三角闪烁驱动

**删除旧 whitePhase useEffect**（1→2→3 定时器），改由 frame 循环驱动：

- 网格恢复完成时：`whiteFlashStartRef = now`, `whitePhaseRef = 1`, `setWhitePhase(1)`
- 闪烁阶段 (flashT < 1)：
  - `osc = sin(2π * 7 * flashT)` — 7 次振荡
  - `baseline = flashT` — 基线从 0→1 上升
  - `amp = 1 - flashT` — 振幅从 1→0 减小
  - `upperOp = (0.5 + 0.5*osc) * amp + baseline` — 上三角亮度
  - `lowerOp = (0.5 - 0.5*osc) * amp + baseline` — 下三角亮度（反相）
  - 通过 `triUpperRef.current.style.opacity` 直接设值
- 闪烁完成 (flashT >= 1)：两三角 opacity=1，`whiteScaleStartRef = now`, `setWhitePhase(2)`
- 放大完成 (scaleT >= 1)：`setWhitePhase(3)`

#### 7. JSX 改动

**canvas**：加 inline style `whitePhase >= 2 ? { transform: scale(scaleMax), transition: 'transform 0.8s ease-out' } : undefined`

**whiteOverlay**：
- 条件渲染改为 `whitePhase > 0 && cellSize > 0`
- inline style: `width: cellSize, height: cellSize`
- transform: `whitePhase >= 2 ? translate(-50%,-50%) scale(scaleMax) : translate(-50%,-50%)`
- transition: `whitePhase >= 2 ? 'transform 0.8s ease-out' : 'none'`
- 内含两个 div: `<div ref={triUpperRef} className={styles.triUpper} />` 和 `<div ref={triLowerRef} className={styles.triLower} />`
