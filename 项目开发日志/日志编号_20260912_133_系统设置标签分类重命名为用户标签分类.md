三处均为纯展示文案，改动不涉及：

- **路由 key**：仍为 `/settings/tags`，书签与深链不受影响
- **权限判定**：仍走 `isAdmin()` 守卫的同一分支，未改权限逻辑
- **后端与数据库**：后端 `grep 标签分类` 0 命中，标签表结构与 API 完全不动

改名语义：这些标签是绑在用户身上的「身份标签」（研发 / 设计 等），
用于内容可见范围的指定可见，加「用户」二字与 README 中「身份标签」表述对齐，
避免被理解成对内容 / 文档打标的通用标签体系。
