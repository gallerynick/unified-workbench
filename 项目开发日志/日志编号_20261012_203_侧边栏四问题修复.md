### 开发内容详述

**问题 ①：删除举例措辞**

个性化页「自动折叠模块栏」卡片说明原为"点击侧边栏的模块（如"首页"、"任务中心"）跳转时……"，删除举例，改为：
"开启后，点击侧边栏的模块跳转时，侧边栏会自动收起；关闭则保持展开状态不变。"

**问题 ②：自动折叠未生效 —— 根因：偏好变更不同步**

`MainLayout` 只在挂载 / `user` 变化时读取 `getUserPreferences()`，用户在个性化页改开关后，`MainLayout` 不知道新值 → 点击模块不折叠。

修复：沿用既有 `theme-changed` / `zoom-changed` 的事件广播模式——
- `UserPersonalization.tsx` 保存成功后在 `updateUserPreferences` 之后 `dispatchEvent(new CustomEvent('auto-collapse-changed', { detail: localAutoCollapse }))`
- `MainLayout.tsx` 新增 `useEffect` 监听 `auto-collapse-changed` 更新 `autoCollapseSidebar`

至此开关保存后**即时生效**，无需刷新或重新登录。同时修正"系统设置子项点击后不收起"（同因：偏好未同步导致全部点击都不折叠；换模块可折叠只是刷新后偏好恰好加载成功的表象）。

**问题 ③：`ul.ant-menu.ant-menu-root` 未撑满到底**

用户澄清：需要菜单根 `ul` 的白色背景延伸到侧边栏最底部。此前（日志 201 修订后）滚动区被改为 `flex: 0 1 auto`（收缩到内容高度）、容器底色 parchment，反而让菜单 ul 更不撑满。

修复（4 处）：
1. 滚动区恢复 `flex: 1`（撑满容器剩余高度）
2. `Sider` 高度 `auto` → `100%`（撑满滚动区）
3. `Menu` style 增加 `height: '100%'`（根 ul 撑满 Sider）
4. 容器底色改回 `var(--sider-bg)`（与菜单一致，消除过渡闪烁）

效果：`ul.ant-menu.ant-menu-root` 白色背景铺满整个侧边栏高度，延伸到最底部。

**问题 ④：清理上一轮错误修复的残留**

- 移除容器 `background: var(--canvas-parchment)`（改回 `--sider-bg`）
- 移除滚动区 `flex: 0 1 auto` 与其注释（恢复 `flex: 1`）
- 保留正确修复：折叠时 `openKeys` 非受控（`{...(collapsed ? {} : { openKeys })}`，解决点击无响应）；路由自动展开在折叠时跳过
