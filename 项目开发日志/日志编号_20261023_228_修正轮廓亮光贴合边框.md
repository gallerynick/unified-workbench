### 开发内容详述

**根因**

上一版用 `animation { transform: rotate(360deg) }` 旋转整个 `::before` 元素。该元素尺寸等于滑块（26×26）、内边距 2px 形成的环是**方形轮廓**；元素一旋转，方形环跟着转成斜方形，四角被滑块的 `overflow: hidden` 裁掉，视觉上就变成「一段光在滑块内部打转」，而不是沿边框走。

**修正**

改用 `@property` 注册角度变量，只转渐变角度、不转元素：

```css
@property --halo-angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

.isLoading .thumb::before {
  background: conic-gradient(from var(--halo-angle), transparent 0deg 200deg, var(--halo) 360deg);
  /* 2px 环形遮罩保持不变 */
  animation: thumbEdgeSpin 1.1s linear infinite;
}

@keyframes thumbEdgeSpin {
  to {
    --halo-angle: 360deg;
  }
}
```

环的位置由 `inset: 0` + `padding: 2px` + `border-radius: inherit` 固定贴着滑块外轮廓，动画只推动渐变角度，亮光沿这条固定的环跑动。

**验证**

无头浏览器读取 `::before` 计算样式：
- `--halo-angle` 随时间变化：207° → 327° → 71°（持续绕圈）
- `transform: none`（元素不再旋转，环不会歪）
- `mask-composite: exclude`（确实是 2px 环，不是实心块）
- 亮光色 rgb(29,29,31) = 浅色主题的 --ink，与蓝色轨道区分明确

### 遇到的问题与解决
- 问题：旋转伪元素导致环变成斜方块被裁，光看起来在滑块内部。
- 解决：转为「固定环 + 旋转渐变角度」，元素不动。
- 兼容性：@property 支持 Chrome 85+ / Safari 16.4+ / Firefox 128+，与项目浏览器基准（最新版 Chrome/Edge/Firefox）一致；不支持时退化为静态渐变环，不会破版。
