### 开发目标
1. 创建项目时可选项目负责人：后端 `ProjectCreate` 增加 `owner_id` 字段，`create_project` 校验指定用户存在并覆盖负责人；前端 `ProjectForm` 创建模式增加"项目负责人"下拉（不选默认创建者本人）
2. 项目详情页 9 个 Tab 去掉图标，并清理不再使用的图标 import

### 涉及模块 / 文件
- 模块：项目管理 / 后端 Schema + Service；前端类型 + 表单 + 详情页
- 修改文件：
  - `backend/app/schemas/project.py`：`ProjectCreate` 增加 `owner_id: uuid.UUID | None = None`（number 后、title 前）
  - `backend/app/services/project.py`：`create_project` 增加 owner_id 存在性校验与覆盖逻辑，并预加载 owner 关系
  - `frontend/src/types/project.ts`：`ProjectCreate` 接口增加 `owner_id?: string`
  - `frontend/src/pages/projects/ProjectForm.tsx`：创建模式新增"项目负责人" Select；`handleSubmit` create 分支透传 `owner_id`
  - `frontend/src/pages/projects/ProjectDetailPage.tsx`：删除 9 个 Tab 的 `icon` 属性与对应图标 import
- 无新增、无删除文件

### 开发内容详述
1. **后端 owner_id 支持**：`ProjectCreate` 增加 `owner_id` 字段；`create_project` 中当 `data.get("owner_id")` 非 None 时，先 `select(User).where(User.id == owner_id)` 校验用户存在，不存在返回 400"指定的项目负责人不存在"，存在则用其覆盖 owner_id 参数。`api/projects.py` 无需改动（`request.model_dump()` 已携带 owner_id）。
2. **async 懒加载问题修复**：`Project.owner` 关系为 `lazy="selectin"`，`create_project` 中 `db.flush()` 创建的新对象未预加载该关系，`ProjectResponse.model_validate()` 访问 `owner_name` 时触发 async 懒加载报 MissingGreenlet（500）。修复：校验时保存 `owner_user`，flush 后显式赋值 `project.owner = owner_user` 预挂载关系，避免序列化时再触发 IO。
3. **前端负责人选择**：`ProjectForm` 创建模式在"项目成员"上方新增 `Form.Item name="owner_id"`，复用既有 `userOptions`（listUsers 已拉取）；`handleSubmit` create 分支通过 `...(values.owner_id ? { owner_id: values.owner_id } : {})` 条件透传；edit 分支不动。
4. **Tab 去图标**：`ProjectDetailPage.tsx` 删除 9 个 Tab 的 `icon` 行与 import（InfoCircle/Team/LineChart/Bulb/CheckSquare/Message/History/FileText/Calendar Outlined），保留 ArrowLeftOutlined（返回）、ExportOutlined（导出）、SettingOutlined（权限设置）。

### 遇到的问题与解决
- 问题：指定 owner_id 创建项目返回 500，日志为 `owner_name` 属性提取 MissingGreenlet（async 下懒加载 `Project.owner` 关系）
- 解决方案：`create_project` 中校验用户存在时保存 `owner_user`，flush 后 `project.owner = owner_user` 预挂载，避免序列化触发异步 IO；默认场景（owner=创建者本人）因当前用户已在 session identity map 中可正常解析，不受影响
- 遗留问题 / 待办：`get_project` 可见性检查对他人 PRIVATE 项目返回 404，admin 无法直接删除 owner 为其他用户的 PRIVATE 项目（既有权限模型行为，本次不涉及）
