### 开发内容详述

**一、问题定位**

顶栏右侧按钮组此前三个「图标按钮」规格互不一致：

| 项 | 修改前 | 说明 |
|---|---|---|
| 手动锁定 | `type="text" size="small"` → 24px 高，图标 14px | antd small 按钮 |
| 暂停自动锁定 | `type="text" size="small"` → 24px 高，图标 14px | 同上 |
| 通知铃铛 | **裸** `<BellOutlined>` + `--text-heading-3-size` = 20px | **没有 Button 包裹** |
| 头像 | antd Avatar 默认 32px | — |

更关键的是 antd `Space` 的 `align` 默认值为 `start`（水平方向即 `align-items:
flex-start`，顶对齐），所以 24px 高的按钮、20px 的裸图标、32px 的头像三者**顶部对齐**，
视觉重心各不相同，看起来就是参差不齐。

**二、统一方案**

1. **新增 token** `--header-icon-size: 18px`（`token.css` 组件级 token — 顶栏小节），
   三个按钮共用，后续只需调一处。
2. **通知铃铛补 Button 外壳**：`<BellOutlined>` 裸图标改为
   `<Button type="text" aria-label="通知" icon={<BellOutlined />} />`，
   与另外两个按钮同规格；`Badge` 继续包在 Dropdown 与 Button 之间，角标位置不变。
3. **三个按钮统一 `size="middle"`**（即 antd 默认，32px 高，与 32px 头像等高），
   去掉原先的 `size="small"`；图标尺寸统一 `fontSize: 'var(--header-icon-size)'`。
4. **对齐**：外层 `<Space size="middle" align="center">`；头像与昵称的
   `<Space align="center" style={{ cursor: 'pointer' }}>`。
5. 头像显式 `size="default"`（32px，与 token `--avatar-size` 一致），不依赖 antd 默认值。

改后三个图标按钮均为 32×32 命中区 + 18px 图标，头像 32px，昵称文字 14px，
全部由 `align="center"` 垂直居中在同一基线上。

**三、深浅色与规范**

- 图标颜色仍继承按钮默认 `color`（`--ink`），暂停态保留 `--color-warning`
- 未使用任何 Emoji 图标
- 尺寸全部走 token，符合「统一使用 design token」要求

### 遇到的问题与解决
- **问题：`start.sh` 不会构建前端，忘记先 build 会静默部署旧产物**
  - 现象：本次首轮部署后，线上 HTML 指向的仍是上一轮的 JS/CSS 哈希，
    新增的 `header-icon-size` 在产物中完全不存在（grep 命中 0）。
  - 根因：`项目文件/frontend/Dockerfile` 采用「本地预构建产物」方案，
    第 11 行 `COPY dist /usr/share/nginx/html` 直接拷贝宿主机的
    `项目文件/frontend/dist/`；而 `项目文件/start.sh` 只做
    `dw_compose up -d --build`，**不执行** `npm run build`。
    因此若忘记在宿主先构建，镜像仍会成功构建，只是内容过期，且无任何报错。
  - 解决：本次补跑 `npx vite build` 后重新 `start.sh`，产物哈希更新为
    `index-v5qVCBU3.js` / `index-DZ76x9jG.css`，校验通过。
  - **建议（待确认是否要改）**：在 `start.sh` 中，当检测到前端源码比
    `dist/` 新时自动执行 `npm ci && npm run build`，或在 `dist` 缺失时强制构建，
    避免此类静默过期。本次未改动 `start.sh`，仅在此记录。
- **问题：验证脚本 grep 误报**
  - `grep -F "--header-icon-size:18px"` 因模式以 `--` 开头被当作选项，
    报 `unrecognized option`；需改为 `grep -F -e "--..."` 或 `grep -c -F -- "pattern"`。
  - 另产物压缩后 `--header-icon-size: 18px;` 冒号后带空格，
    用 `--header-icon-size:18px`（无空格）会漏判。
