### 开发内容详述

**整合原则**（用户明确要求）：
1. Phase 4 = Phase 1（网格凹面背景）+ Phase 2（丝绸流粒子）两层叠加,同时显示
2. 完整源码复制,不使用软链接,代码一模一样
3. 不涉及 Phase 3（粒子汇聚文字）的任何内容

**合并架构**：

```
TestPageAftermath.tsx
├── GRID_FS + GRID_VS   = Phase 1 着色器 100% 复制（含 hash/noise2/gridWire/色散/vignette）
├── VS_SOURCE+FS_SOURCE = Phase 2 粒子着色器 100% 复制
├── SPEED/TOTAL/streams/particles 创建 = Phase 2 原样复制（65流×350=22750）
├── update() = Phase 2 丝绸流逻辑原样复制（噪音波浪+鼠标扰流+三层亮度）
└── frame() 两通道渲染
    ├── Pass 1: 网格凹面背景（禁用混合，原着色器）
    └── Pass 2: 丝绸流粒子（加法混合 SRC_ALPHA/ONE，原着色器）
```

**关键决策**：

| 决策 | 原因 |
|------|------|
| 一个 WebGL 上下文两个 Program | 保证两层面板与独立页面渲染效果完全一致 |
| Pass 1 网格禁用混合、Pass 2 粒子启用加法混合 | 网格底色正常覆盖,粒子亮度叠加在上层 |
| 粒子 alpha 公式、大小、亮度全部沿用 Phase 2 | 用户要求"代码复制过去一模一样" |
| 无时间轴、无淡出、无汇聚 | 用户明确 Phase 4 不涉及 Phase 3 内容 |

**过程中的错误与修正**：
- 首版错误地把 Phase 3 汇聚文字逻辑、文字采样、时间轴（STREAM_END/CONVERGE/FADE）、黑色覆盖淡出通道一并加入 Phase 4,被用户指出（"哪里有说涉及到phase3的内容"）
- 修正：全部移除 Phase 3 内容,仅保留 Phase 1 + Phase 2 两层叠加

**v2 迭代 — 网格模糊**（用户要求 Phase 2 放最上层、Phase 1 加模糊）：

| 变更 | 原因 |
|------|------|
| Phase 2 粒子保持 Pass 2 加法混合（最上层） | 用户要求丝绸流清晰盖在网格上 |
| gridWire 内对 d = min(dX, dY) 做 3-tap box blur（±0.003 偏移） | 网格线条边缘柔和，降低视觉干扰 |

```glsl
// gridWire() 模糊
float d = min(abs(fract(fx * freq2) - 0.5), abs(fract(fy * freq2) - 0.5));
float eps = 0.003;
float w0 = smoothstep(0.035, 0.005, d);
float w1 = smoothstep(0.035, 0.005, d - eps);
float w2 = smoothstep(0.035, 0.005, d + eps);
return (w0 + w1 + w2) / 3.0;
```
