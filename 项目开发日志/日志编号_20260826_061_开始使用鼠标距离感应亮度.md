### 开发内容详述

**1. 鼠标距离感应亮度（hintGlow）**
- 监听 window mousemove，计算鼠标与箭头中心距离：
  - `maxDist = 300px` 感应范围
  - `glow = max(0, 1 - dist / maxDist)`
  - `opacity = 0.4 + glow * 0.6`（远离时低调可见，靠近时全亮）

**2. 性能优化（消除延迟）**
- 采用**直接写 DOM style**（`el.style.opacity`），不经过 React setState
- 移除 hintGlow state，避免每次 mousemove 触发组件重渲染
- CSS 过渡从 0.2s 缩短到 0.05s，鼠标移动亮度即时响应

**3. CSS 交互反馈**
- hover 时 `filter: brightness(1.2)` 额外提亮
- active（点击）时 `scale(0.96)` 按下反馈
- 保留点击触发衔接动画功能

### 遇到的问题与解决
- **问题**：setState 更新导致亮度响应有延迟
- **方案**：改用 ref 直接操作 DOM style，绕过 React 重渲染
