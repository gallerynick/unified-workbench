### 开发内容详述（最终定稿参数）

#### 1. 新增 u_vignette uniform
GRID_FS 补充暗角（vignette）uniform 控制，可在动画中平滑消失：
```glsl
float vignette = mix(1.0, 1.0 - smoothstep(0.3, 0.8, r2), u_vignette);
```

#### 2. 时间线最终参数（点击 t=0）

| 时间 | 环节 | 参数 |
|------|------|------|
| 0-0.35s | 文字快速消散 | phaseA = transT/0.35，textWeight 1→0 |
| 0.2-2.4s | 丝绸流被吸走 | phaseB，粒子获随机延迟+水平加速+缩小淡出 |
| 0-0.5s | 初始爆散 | 每个粒子随机方向速度脉冲，立即打散字型 |
| 1.0-3.0s | 压暗/暗角消失 | bandDarkenVal/vignetteVal = 1 - lerp(1.0,3.0) |
| 0-3.0s | 第一阶段提亮 | brightness = 1.0 + 1.8×lerp(0,3.0) |
| 0-5.5s | 网格加速 | flowSpeed = 1.0 + 17.0×pow(lerp(0,5.5), 2.5) |
| 3.5-5.0s | 曲面变平面 | concavity = 1 - lerp(3.5,5.0) |
| 4.8-6.3s | 梦幻白屏 | whitePhase = lerp(4.8,6.3)，whiteVal 与速度联动 |
| 4.5-6.0s | 白屏提亮 | brightness += 1.2×lerp(4.5,6.0) |

#### 3. 粒子飘散优化

### 遇到的问题与解决
- **字型可见**：phaseA 从 1.0s 缩短到 0.35s + 初始爆散脉冲 → 点击后立即看不到字型
- **粒子飘不出去**：加速度 0.6 被阻尼 0.92 抵消 → 提升到 0.7+2.6×gentle，点击后阻尼降为 0.97
- **网格左右摆**：sin 振荡 flow → 改 u_time×0.1×speed 单向持续移动
- **加速割裂**：0.5s 静止后突加速 → lerp 起点改 0.0 连续提速 + t^2.5 抹匀前段
- **暗角不消失**：vignette 硬编码 → 提取 u_vignette uniform
- **buildx 权限**：Docker BuildKit 活动文件写入失败 → DOCKER_BUILDKIT=0 legacy builder
