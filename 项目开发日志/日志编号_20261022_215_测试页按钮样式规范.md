### 开发内容详述

**1. 问题定位**

测试页「示例分区」用的是 antd 默认 Button，经项目主题后呈现为「白底 + 蓝描边 + 蓝字」；而现有输入框是「白底 + 中性灰描边 + 深色文字」，滑动选择框是「bg-tertiary 轨道 + canvas 滑块 + 选中色 color-info」。三者并排时按钮显得"浮"在表单之外，是当前风格不统一的根因。

**2. 基准取值（不新增色值，全部取自 token）**

| 项目 | 取值 | 来源 |
|------|------|------|
| 高度 | var(--input-height) 32px | 与输入框同高 |
| 圆角 | var(--rounded-sm) 8px | 与输入框、下拉、分段控件一致 |
| 描边 | var(--input-border) = 1px var(--border-primary) | 与输入框同色（浅色 #d9d9d9 / 深色 #434343） |
| 底色 | var(--input-bg) | 与输入框同底 |
| 文字 | var(--ink)，14px / 400 | var(--text-caption-*) |
| 悬停 | var(--bg-tertiary) | 沿用筛选芯片、列表项悬停 |
| 按下 | var(--btn-active-scale) scale(0.95) | 规范要求按压用缩放而非变色 |
| 焦点 | 2px var(--color-primary-focus)，offset 1px | 与既有自定义控件一致 |
| 选中 / 开启 | var(--color-info-bg) 底 + var(--color-info) 字 | 与分段控件滑块、ColorFilterBar.chipActive 同源 |
| 主行动 | var(--color-info) 实底 + var(--btn-primary-text) 字 | 与输入框焦点蓝同色，替代原 #0066cc 描边蓝 |

**3. 三类形态**

- **纯图标按钮**：正方形，宽 = 高（32/28/36），图标 14px。四个子态：轻量（ghost，无描边，用于工具栏与列表行内）、描边（需要被看见的独立操作）、按下（选中色）、禁用 / 加载。
- **开关型按钮**：aria-pressed 表达开 / 关，按下态只用底色区分（color-info-bg + color-info），不加边框与阴影；含图标开关、文字开关、互斥组三种用法。
- **带文字按钮**：默认（中性描边）、主行动（实底）、危险（描边 + 实底两级）、文本（无底无边）、禁用、加载、紧凑 / 默认 / 大三档尺寸。

**4. 分区结构（测试页内）**

基线对照条（Input + Select + Segmented + 按钮并排，用于目视校验同高同圆角）→ 1. 纯图标按钮 → 2. 开关型按钮 → 3. 带文字按钮 → 规格速查（dl 列表）→ 使用建议。分区自带页头与分组标题，单项页仍然零框架，符合《TestPage使用与开发文档》约束。

**5. 关键决策**

- **默认按钮不再用蓝色描边蓝字**：蓝描边把按钮从表单控件里"拔"了出来；改为与输入框同色的中性描边后，蓝色只保留给主行动与选中态，一屏的强调色数量从 3 类降到 2 类。
- **主行动用 color-info 而非品牌色 color-primary**：输入框焦点环、分段控件选中态都是 color-info，主按钮若用 #0066cc 会在同一屏出现两种蓝；统一到 color-info 后焦点与主行动是同一个蓝。
- **按下态只缩放不变色**：沿用规范「按压用 scale(0.95) 表达」。
- **危险操作分两级**：描边态用于常规删除入口，实底态只给不可逆确认，避免满屏红色。
- **实底按钮的悬停用 filter: brightness(0.92)**：不引入新的 hover 色 token，深浅色都能自适应。

### 遇到的问题与解决

- **问题**：文件沙箱初始为只读，写入被拒（`[sandbox: file access denied under read-only mode]`），按提示逐次升级到 workspace-write 仍被拒。
- **解决方案**：用户将文件策略切换为 danger-full-access 后正常写入；未做任何绕过。
- **问题**：写出的 JSX 里有一处全角空格 U+3000，被 ESLint `no-irregular-whitespace` 判为 error。
- **解决方案**：改为中文逗号分隔，`eslint src/pages/dev/` 复检只剩 TestPageAftermath / TestPageBackground 的历史遗留问题（本次未触碰）。
- **遗留问题 / 待办**：按钮尚未抽成共用组件、也未写入 antd 主题——本次只在测试页定样式，待用户确认后再推广。
