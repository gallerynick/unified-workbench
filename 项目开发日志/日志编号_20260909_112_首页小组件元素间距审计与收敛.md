### 开发内容详述

#### 一、元素与元素间距审计（实测，非估算）

antd 默认值通过阅读 node_modules/antd/es 组件样式源码 + 用 theme.getDesignToken() 实算派生 token 得出，避免凭印象判断。

外壳层（Home.module.css）：

| 元素对 | 实测 | 来源 | 判定 |
|---|---|---|---|
| 外框顶 → 拖拽手柄 | 4px | --spacing-xxs | 符合（4px 属规范允许的子基础值，用于紧凑排版微调） |
| 拖拽行 → 标题行 | 4px | --spacing-xxs | 符合 |
| 标题行 → 正文 | 8px | --spacing-xs | 符合 |
| 左右 → 内容 | 16px | --card-padding | 符合，与 {component.card} padding 16px 一致 |
| 正文底 → 外框底 | 16px | --card-padding | 符合 |
| 标题行高度 | 36px | 字面量 | **不符合** |

组件内部：

| 元素对 | 实测 | 来源 | 判定 |
|---|---|---|---|
| 图标 → 标题文字 | 8px | --spacing-xs（5 处） | 符合 |
| 列表项内：勾选框 → 文本 → 日期 | 8px | --spacing-xs（3 处） | 符合 |
| 列表项 → 列表项 | 12px | antd List 默认 itemPadding（paddingContentVertical） | 符合，恰等于 --spacing-sm |
| 快捷入口：按钮 → 按钮 | 8px | antd Space 默认 size=small = paddingXS | 符合 |
| 统计小卡 → 小卡 | 16px | gutter 字面量 [16, 16] | 值符合，写法不符合 |
| 统计小卡内边距 | 16px | 主题 Card.paddingLG | 符合 |

实算依据：antd 5.29.3 的 List.prepareComponentToken 中 itemPadding = paddingContentVertical 0（= 12px 0），且 itemPaddingSM（8px 16px）仅作用于 .ant-list-bordered.ant-list-sm，本项目列表无 bordered，故取 12px；Space 的 spaceGapSmallSize = paddingXS = 8px；Card 的 bodyPaddingSM = 12。

#### 二、4 项收敛

1. **min-height off-grid**：Home.module.css 的 .ant-card-head min-height 由 36px 改为 32px。36 既不在规范「结构性布局对齐至 8/12/16/20/24」列表，也不在任何 token 中（token 表为 4/8/12/17/24/32/48/80）。32px 为 controlHeight 语义高度，在对齐列表上。此值由 108 号日志引入，本轮自纠。

2. **Row gutter 硬编码**：StatsWidget 的 gutter={[16, 16]} 改为 const cardGutter: [string, string]，引用 var(--spacing-card-gap)。改造前已验证可行性：阅读 antd 源码确认 Row 对非数字 gutter 生成 calc(x / -2) 负 margin、Col 生成 calc(x / 2) padding，CSS calc 支持 var() 除以数字，与数字 gutter 等价。类型注解用 [string, string] 以匹配 antd 的 Gutter = number | string | undefined | Partial<Record<Breakpoint, number>>。

3. **陈旧 token**：token.css 的 --card-grid-gap 原为 var(--spacing-sm)（12px），在 110 号日志修正规范 L388 后与规范（{spacing.card-gap} 16px）冲突。改为 var(--spacing-card-gap)。

4. **死 token 删除**：token.css 的 --card-grid（repeat(auto-fill, minmax(300px, 1fr))）零处使用——首页实际用固定 repeat(2, 1fr)。已删除，并在 --card-grid-gap 注释中记录删除原由。

#### 三、审计中记录但未处置的一项

列表项 12px 与快捷入口按钮 8px 来自 antd 默认派生值（paddingContentVertical / paddingXS），恰好等于我们的 --spacing-sm / --spacing-xs，属**巧合对齐**而非主动遵守。若 antd 未来改动派生规则则会漂移，我们当前无约束手段。本轮未做显式覆盖，仅在此备案。

### 遇到的问题与解决

- 问题：首次把说明注释写成 JSX 注释 {/* ... */} 直接放在 return 内 <Row> 之前，TS 报「JSX expressions must have one parent element」。
- 解决方案：JSX 注释不能位于 return 的根元素之前，改为模块级 const + JS 块注释。

- 问题：const cardGutter = [...] as const 报类型错误——readonly 元组无法赋给 antd 的可变 [Gutter, Gutter]。
- 解决方案：改用显式类型注解 const cardGutter: [string, string]。
