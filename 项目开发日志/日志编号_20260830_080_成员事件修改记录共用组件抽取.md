### 开发内容详述

#### 1. MemberModal（pages/projects/components/MemberModal.tsx）
- **Props**：project / open / editingMember（非空=编辑）/ existingMembers / isOwner（负责人同步成员权限用）/ onClose / onSaved
- **内部自洽**：加载用户列表；新建可选用户自动排除负责人与已加入（含历史）成员；职务 AutoComplete 预设+自由填写；新建支持多选批量添加，负责人自动同步项目 member_ids
- 移除成员/拉回/权限设置等操作保留在 Tab 内（不属于表单弹窗）

#### 2. EventModal（pages/projects/components/EventModal.tsx + EventModal.module.css）
- **Props**：project / open / editingEvent / existingEvents（编号用）/ onClose / onSaved
- **移交动态表单**：event_type=handover 时动态渲染移交方/承接方/监督方/交接类型/交接日期/过渡期/四维度能力检查/资产清单/签字状态，逻辑与样式原样保留
- details 键值对附加字段、EVT-项目编号-序号 自动编号均内聚在组件

#### 3. ChangeModal（pages/projects/components/ChangeModal.tsx）
- **Props**：project / open / editingChange / existingChanges（编号用）/ canApproveChange（新增 prop，保留原 Tab 的状态权限控制）/ onClose / onSaved
- **主/次分类级联**：Form.useWatch 实现大类切换重置小类、other 时小类自由填写+详情必填
- 编号规则 CHG-项目编号-序号、日期格式 YYYY-MM-DDTHH:mm:ss 原样保留

#### 4. 三个 Tab 改造
- 各自删除内联 Modal JSX、form 状态、handleCreate/handleSubmit（或对应）逻辑、编号生成、以及随之不再使用的 import
- 保留列表/筛选/权限/删除（或移除）等 Tab 职责逻辑；底部渲染对应共用组件（onSaved 刷新列表）

### 遇到的问题与解决
- 问题 1：ChangeModal 需要原 Tab 的权限控制（canApproveChange 决定状态选项与提交校验）
  - 解决方案：作为 prop 传入，行为与文案原样保留
- 问题 2：exactOptionalPropertyTypes 下编辑回填显式传 undefined 报 TS2379
  - 解决方案：改为条件展开 `...(cond ? { f: v } : {})`（与 TodoModal/MeetingModal/ProposalModal 一致）
- 问题 3：子代理并行抽取 EventModal/ChangeModal 时，ChangeModal 子代理中途遇到并行任务（EventModal 抽取中）文件报错
  - 解决方案：EventModal 由主代理内联完成；并行任务收敛后 tsc 全量通过
- 问题 4：删除内联 Modal 后大量未使用 import（Form/Modal/Select/AutoComplete/dayjs/编号前缀/常量等）
  - 解决方案：tsc strict 模式逐一清理
