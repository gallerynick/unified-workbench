### 开发内容详述

#### 一、两处形态差异

| 项 | 日志 153 的任务选择器 | 日程事件弹窗 |
|---|---|---|
| 单元形态 | 带文字的方卡片（1px 描边 + 8px 圆角），圆点与文字并排 | 纯圆点（26×26），无文字 |
| 名称提示 | 文字常驻在卡片内 | Tooltip 悬浮提示，选中名常驻在行尾 |
| 悬浮反馈 | border-color 变化 + scale(1.02) | 仅背景色变化 |
| 选中反馈 | 蓝描边 + 蓝底 | 墨色描边 + 内点微缩（16→14px） |
| 表单项标签 | 「标记颜色」 | 「颜色」 |

#### 二、对齐实现

**样式**：`TaskModal.module.css` 的色板区块整体替换为
`CalendarEventModal.module.css` 的 `.colorRow` 系列，逐字节一致——
用 `diff` 抽取两边非空、非注释的行做比对，结果为空。

**结构**：

```
colorRow
├─ Tooltip × N
│   └─ button (26×26, 2px 透明描边, 圆形)
│       └─ colorInner (16×16, 圆形, 取色)
└─ colorName  ← 当前选中色名的常驻文字
```

交互反馈沿用日程的实现：

- 悬浮：`background: var(--bg-tertiary)`，不动描边也不缩放
- 按下：`transform: var(--btn-active-scale)`
- 焦点：`outline: 2px solid var(--color-primary-focus)` + `outline-offset: 2px`
- 选中：`border-color: var(--ink)`，同时 `.colorInner` 由 16px 收到 14px，
  形成「双层环」的选中态

整个区块无 box-shadow，仍符合浮窗规范。

**TSX**：引入 `Tooltip` 与 `taskColorLabel`，选中名通过
`taskColorLabel(value)` 从调色板反查中文名，与日程用 `colorName()` 的做法
对称。表单项标签改为「颜色」。无障碍保留 `aria-label` 与 `aria-pressed`。
