### 开发内容详述

#### 1. 共用组件 TodoModal（pages/projects/components/TodoModal.tsx）
- **Props**：
  - `project`：所属项目（编号生成用）
  - `open` / `onClose`：显隐控制
  - `editingTodo`：非空=编辑模式，null=新建（两处当前只用新建，但组件同时支持编辑，供后续复用）
  - `existingTodos`：项目现有待办（用于生成下一个编号）
  - `initialProposalId`：新建时预关联的提案 id（提案详情页传当前提案）
  - `onSaved`：保存成功回调（父组件刷新列表）
- **内部自洽**：打开时加载执行人（listUsers）与关联提案（listProjectProposals）选项；表单含标题/描述/优先级/执行人/截止日期/关联提案；编号生成 `buildTodoNumber`（TOD-项目编号-序号）内聚在组件中
- **消息提示**：新建「待办已创建」/编辑「待办已更新」，成功后 onClose + onSaved

#### 2. TodoTaskTab 改造
- 删除：内联 Modal JSX、`form`/`submitting` 状态、`handleSubmit`（含 create/update 逻辑）、`buildTodoNumber`、相关 import（Form/DatePicker/Select/Modal/createProjectTodo/updateProjectTodo 等）
- 保留：`modalVisible`/`editingTodo` 状态与打开/关闭/刷新回调，底部渲染 `<TodoModal project existingTodos onClose onSaved />`

#### 3. 提案详情页改造
- 删除：`createTodoForm`/`createTodoSubmitting` 状态、`buildTodoNumber`、`openCreateTodo`/`submitCreateTodo`、自建「新建待办并关联」Modal JSX、相关 import（createProjectTodo/TODO_PRIORITY_OPTIONS）
- 改为：`<TodoModal project open existingTodos={todos} initialProposalId={proposal?.id} onClose onSaved={fetchProposal} />`，创建后自动关联当前提案并刷新

#### 4. 模式意义（用户发起）
- 用户指出共用组件应推广到各处，而非仅「新建待办/新建交流」两处。本次以 TodoModal 为首个样板确立模式：
  - 项目模块共用组件放 `pages/projects/components/`
  - 组件自洽（数据加载/编号/校验/提交内聚），调用方只传最小 props
  - 后续可推广：交流新建 Modal（MeetingModal）、提案新建 Modal、成员/事件表单等

### 遇到的问题与解决
- 问题 1：exactOptionalPropertyTypes 下 `setFieldsValue` 显式传 `undefined` 报 TS2379
  - 解决方案：改为条件展开 `...(cond ? { field: value } : {})`
- 问题 2：编辑模式回填 `due_date` 需转 Dayjs 对象
  - 解决方案：`dayjs(editingTodo.due_date)` 并补 dayjs import
- 问题 3：TodoTaskTab 删除 Modal 后大量未使用 import（tsc TS6133/TS6196）
  - 解决方案：逐一清理（Form/DatePicker/Select/Modal/TextArea/Dayjs 类型/createProjectTodo/updateProjectTodo/TODO_PRIORITY_OPTIONS/buildTodoNumber 等）
- 问题 4：模板字符串嵌套反引号导致 edit 解析失败
  - 解决方案：改用数组 join("\n") 传递 old_string/new_string
