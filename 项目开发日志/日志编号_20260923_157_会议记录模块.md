### 开发内容详述

#### 1. 数据模型

**meeting_record（会议记录主表）**
- 会议编号 MTG-YYYYMMDD-NNN 格式，当天自增
- 状态机：not_started → recording → paused → processing → completed
- 可见性：private / public / restricted（支持用户 + 标签双重限定）
- 分离状态：diarization_status（pending/done/failed）
- 纪要状态：minutes_status（pending/done/failed）

**meeting_transcript_segment（转录句子表）**
- 序号 seq 递增
- 文本 text（含标点）
- 音频时间戳 audio_start_ms / audio_end_ms
- 说话人 speaker（会后填充）

**meeting_minutes（AI 纪要表）**
- 总结 summary
- 重点要点 key_points（JSONB 数组）
- 待办事项 todos（JSONB 数组，含 content + source_quote）
- 模型标记 model_used

**system_config（系统配置表）**
- 扩展为完整结构：id + config_key + config_value + description + updated_by + timestamps
- 支持 ai_provider 和 asr_config 两个配置键

#### 2. 后端 API

**会议记录 API（14 个端点）**
- POST /meetings - 创建会议
- GET /meetings - 列表（分页 + status 筛选）
- GET /meetings/{id} - 详情
- PATCH /meetings/{id} - 更新
- DELETE /meetings/{id} - 删除
- POST /meetings/{id}/start - 开始转录
- POST /meetings/{id}/pause - 暂停转录
- POST /meetings/{id}/resume - 恢复转录
- POST /meetings/{id}/end - 结束会议（触发会后处理）
- GET /meetings/{id}/transcript - 转录句子
- GET /meetings/{id}/audio - 下载音频
- GET /meetings/{id}/minutes - 获取纪要
- POST /meetings/{id}/minutes/review - 确认纪要审核
- POST /meetings/{id}/export - 导出（transcript/audio/minutes）

**第三方服务配置 API（5 个端点）**
- GET /config/third-party - 获取配置
- PUT /config/third-party - 更新配置
- POST /config/third-party/ai/test - 测试 AI 连接
- POST /config/third-party/asr/test - 测试 ASR 服务
- POST /config/third-party/asr/reload - 重载 ASR 模型

#### 3. 服务层

**meeting_record.py**
- 可见性检查：_check_visibility() 支持 private/public/restricted
- 会议编号生成：MTG-YYYYMMDD-NNN 当天自增
- 状态流转控制：not_started → recording → paused → processing → completed

**third_party_config.py**
- 基于 SystemConfig 的键值存储
- 默认配置内置（Ollama / 本地 ASR）
- 支持本地/在线双模式切换

**asr_engine.py**
- FunASR AutoModel 封装
- Paraformer-zh + ct-punc + fsmn-vad 模型组合
- 支持音频文件和数组转录

**speaker_diarization.py**
- CAM++ 说话人分离模型
- 返回带说话人标签的转录段落

**meeting_processor.py**
- 会后处理流程：说话人分离 → AI 纪要生成
- 时间戳匹配说话人标签
- 格式化转录内容供 AI 使用

**ai_provider.py**
- OpenAI 兼容接口客户端
- 支持本地 Ollama 和在线 OpenAI
- JSON 格式输出纪要（summary + key_points + todos）

### 遇到的问题与解决

1. **Python 代码写入语法错误**：工具在写入包含类型注解的 Python 代码时出现语法错误
   - 解决：使用 bash cat heredoc 方式写入文件

2. **前端 API 模板字符串问题**：TypeScript 模板字符串中的特殊字符导致解析错误
   - 解决：使用字符串拼接替代模板字符串

3. **SystemConfig 模型扩展**：原模型只有 key + value 两个字段
   - 解决：创建迁移 050 扩展表结构，添加 id、config_key、config_value、description、updated_by、timestamps
