### 开发内容详述

**1. 后端 TOTP 验证器名称动态化（two_factor.py）**
- 移除模块级常量 ISSUER = "一站式工作台"，改为 DEFAULT_ISSUER 仅作为回退值
- 新增 async def get_app_name(db)：从 system_config 表读取 custom_config.app_name，未设置时返回 DEFAULT_ISSUER
- build_otpauth_uri(secret, account, issuer_name=None)：新增 issuer_name 可选参数，为空时使用默认值
- create_pending_device()：生成二维码前调用 get_app_name(db) 获取当前应用名称，传入 build_otpauth_uri
- 效果：用户在设置页修改应用名称后，新绑定的 TOTP 设备在验证器中显示新名称；已绑定的设备不受影响（issuer 在扫码时写入 otpauth:// URI，属于历史值）

**2. 后端测试通知标题动态化（system.py）**
- test_notification 端点新增从 custom_config 读取 app_name 的逻辑
- title 从硬编码 "一站式工作台 - 测试通知" 改为 f"{app_name} - 测试通知"
- 效果：测试通知渠道时，飞书/钉钉/企微/邮件标题显示当前应用名称

**3. 后端 Swagger/OpenAPI 标题动态化（main.py）**
- lifespan 中在 create_initial_admin 之后读取 custom_config.app_name
- 若 app_name 非空，设置 app.title = app_name（覆盖 FastAPI 构造时的 settings.APP_NAME 默认值）
- 效果：访问 /api/v1/docs 时，Swagger UI 标题显示当前应用名称

**4. 前端初始化向导（Welcome.tsx）——未修改**
- 初始化向导在首次设置时运行，此时 custom_config 尚未写入数据库，appName 始终为默认值"一站式工作台"
- 保持硬编码"欢迎使用一站式工作台"，避免引入不必要的状态依赖

**5. 前端页面标题闪烁消除（index.html）**
- 在 <title> 标签后添加内联 <script>，在 React 挂载前从 localStorage 的 custom_app_settings 读取 name 并设置 document.title
- 效果：页面加载瞬间即显示正确标题，避免 React 挂载前的短暂闪烁
- 优先级链：内联脚本(localStorage 快速缓存) → useCustomization(React 挂载后从后端拉取) → document.title 最终更新

**6. 文档更新**
- `项目文件/frontend/CUSTOMIZATION.md`：新增「应用名称同步说明」章节，列出各位置同步方式、配置优先级链、TOTP 验证器特别说明
- `项目架构/配置管理体系.md`：在「典型键」表中补充 custom_config 条目及其用途

### 数据流总览（修改后）

```
用户修改应用名称
    │
    ▼
设置页 → PUT /api/v1/system/custom-config → system_config 表 (custom_config)
    │
    ├── 前端各页面 → useCustomization() → GET /api/v1/system/custom-config → document.title / 各组件
    │
    ├── TOTP 绑定 → create_pending_device → get_app_name(db) → build_otpauth_uri(issuer_name) → 二维码
    │
    ├── 测试通知 → test_notification → get_config(custom_config) → channel.send(title=f"{app_name} - 测试通知")
    │
    └── 服务启动 → lifespan → get_config(custom_config) → app.title = app_name → Swagger UI
```

### 遇到的问题与解决
- 问题：Python 代码中字符串含双引号，run_code JSON 模板中难以转义
  - 解决方案：使用单引号或转义处理，通过 edit 工具精确替换
- 问题：two_factor.py 中 get_app_name 函数定义后缺少空行，与后续常量注释粘连
  - 解决方案：补充两个空行，符合 PEP8 顶层定义间距规范
- 说明：index.html 内联脚本仅读取 localStorage，不请求后端 API（避免阻塞渲染）。若管理员在其他浏览器修改了名称，当前浏览器 localStorage 可能滞后，但 React 挂载后 useCustomization 会从后端拉取并覆盖，最终一致
