### 开发目标
将侧边栏菜单飞入动画从"手动维护 nth-child 延迟规则"改为"JS 动态按 DOM 顺序分配延迟"，
使所有侧边栏菜单项（含未来新增项）自动包含在动画中，无需每次补充规则。

### 开发内容详述

**原方案（有缺陷）**
CSS 中按 `.sidebar-entered .ant-menu-item:nth-child(N)` 手动枚举 25 条延迟规则，
新增菜单项（如设备终端/安全设置/系统设置）不在规则内，需人工补 nth-child(26+)，
维护成本高且易遗漏。

**新方案（通用）**
1. CSS 只保留基础动画：
   - 初始态：opacity 0 + translateX(-16px)
   - 飞入：`menuItemFlyIn 300ms ease-out forwards`（模糊+位移+淡入）
2. MainLayout.tsx 新增 `assignMenuAnimDelays(container)`：
   - sidebarEntered 触发后，JS 遍历容器内所有
     `.ant-menu-item, .ant-menu-submenu > .ant-menu-submenu-title`
   - 按 DOM 顺序动态设置 `animationDelay = i * 40ms`
   - 新增菜单项自动获得延迟，无需任何 CSS 维护
3. `clearMenuAnimDelays(container)`：动画完成后（1.5s）清理内联延迟，避免残留
4. 折叠/展开切换（collapsed 变化）时重新分配延迟

**兼容性**
- 移除全部 nth-child CSS 规则（无回归，动画效果一致）
- submenu 用 `.ant-menu-submenu > .ant-menu-submenu-title` 准确定位
