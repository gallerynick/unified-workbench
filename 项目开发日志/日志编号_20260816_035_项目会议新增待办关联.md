### 遇到的问题与解决
- 问题：`docker exec unified-workbench-backend-1 alembic upgrade head` 直接执行失败，报 `ModuleNotFoundError: No module named 'app'`
- 原因：alembic 命令默认不在 `/app` 下执行且未设置 PYTHONPATH
- 解决方案：`docker exec ... bash -c "export PYTHONPATH=/app && cd /app && alembic upgrade head"`
