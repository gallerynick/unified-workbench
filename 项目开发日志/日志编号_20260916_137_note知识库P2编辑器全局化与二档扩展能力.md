#### 3. 双链与笔记内嵌（T2.3 / T2.4）
WikiLink：inline + atom 节点，点击经 editor.extensionStorage.wikilink?.onNavigate 回调跳转，计入图谱边。NoteEmbed：block + atom 节点，折叠态显示标题与摘要，展开态以只读 ContentEditor 渲染目标 body；目标 403 时渲染无权限占位卡片，不泄露任何目标内容。模块级 embedCache 避免同一目标笔记多处内嵌重复请求。

**1 层嵌套硬限的实现方式**：展开时注入的 extensions 为 NoteEmbedStub（无 NodeView、renderHTML 输出静态标题行的降级形态），而非 NoteEmbed 本身。原因是 ProseMirror 对未注册节点会直接丢弃——若无降级形态，二级内嵌的内容会凭空消失而非优雅降级。

#### 4. 斜杠菜单与 [[ 补全（T2.6）
14 条命令分 5 组（段落与标题 / 内容块 / 列表 / 提示块 / 插入），支持关键词过滤（中英混排）、↑↓ 选择、回车确认、Esc 与点击外部关闭，触发文本与查询在命令执行前统一 deleteRange 清除。

两处对计划的偏离（已同步记录到计划文档）：

#### 5. 扩展集装配与占位符（T2.7）
noteExtensions({ onNavigateNote, isEmbedded, placeholder }) 返回完整扩展数组：WikiLink（按需 configure onNavigate）→ NoteEmbed / NoteEmbedStub（按 isEmbedded 二选一）→ Callout → TaskList → TaskItem → Highlight → NoteImage → EditorPlaceholder。

EditorPlaceholder 用 @tiptap/pm/state 的 Plugin + Decoration.widget(side: -1) 实现，仅在文档为空段落时渲染。**关键发现**：现有 ContentEditor.module.css 完全没有 placeholder 样式（data-placeholder 属性传了但无 ::before 规则），content 模块的空态占位此前实际不生效。因此 base 扩展集保持逐字不变，placeholder 由调用方按需注入，既修好 note 的占位又不改变 content 的现状。

### 遇到的问题与解决

1. **Tiptap 3 API 与文档差异**：无 nodeAttribute（属性直接写默认值对象）；def 已从 NodeConfig 移除；commands.lift() 签名变为 lift(typeOrName, attributes?)。均按 3.31.3 实测修正。
2. **Commands 模块增广的返回类型写错**：写成 ReturnValue（且不存在的标识符），实为接口泛型名 ReturnType。
3. **Commands.taskList 命名空间已被占用**：@tiptap/extension-list 的 d.ts 已声明 taskList，手写 TaskList/TaskItem/TaskItemView 三个文件全部删除，改为直接引入官方子路径导出。
4. **Extension[] 类型太窄**：noteExtensions 返回 Extension[] 导致 Node/Mark 赋值报错（addCommands 的 this 类型冲突），改用 @tiptap/core 的 Extensions。
5. **EditorEvents 不含 keydown**：Tiptap 3 的事件表只有 transaction / focus / blur / update 等，键盘拦截改为监听 editor.view.dom 的 keydown。
6. **exactOptionalPropertyTypes + noUncheckedIndexedAccess 的双重压力**：CSS Module 索引签名取值是 string | undefined，传给 antd 组件的 className 需 ?? '' 兜底；字符串索引同理，改用 charAt()。
7. **@ant-design/icons 图标名不存在**：TextOutlined、HqOutlined、HorizontalRuleOutlined、ParagraphOutlined 均不存在（前者是 FileTextOutlined 的子串，此前 grep 计数被误判为存在）。改用 AlignLeftOutlined / FontSizeOutlined / LineOutlined。
8. **生成代码时的转义塌缩**：脚本用模板字符串承载 TS 内容时，\s 与 \/ 会被层间转义吞掉，导致正则静默变成字面量 /s、//（ImageInsertModal 的 URL 校验因此失效）。规避方式：内容一律用双引号数组 join，正则只写无转义形态；URL 校验改为 startsWith + indexOf 的纯字符串判断。
9. **拼写错误反复出现**：ReturnValue 误写成 ReturnVal ue 多次，其中一次因 tsc 通过（无文件可检查）造成误判——**tsc 通过不等于文件存在，每次写盘后必须 ls 验证**。
10. **无前端图片上传接口**：src/api/ 下无 upload 能力，图片仅支持按 URL 插入，并在弹窗内明示说明；上传能力待后端补齐后加选项。
