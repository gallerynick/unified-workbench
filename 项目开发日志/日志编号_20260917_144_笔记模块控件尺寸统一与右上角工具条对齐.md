### 开发内容详述

**一、根因**

右上角工具条一行内混用了两种尺寸：面板显示按钮（默认 32px）、视图切换
Segmented（size="small"，24px）、新建笔记按钮（默认 32px）。中间的 Segmented
比两侧按钮矮 8px，同一行里明显不齐。同一组件在同一行内出现两种尺寸，
就是视觉不统一的直接来源。

**二、确立的尺寸规则**

  - 页面级工具条、面板主控件 → 默认尺寸（32px）
  - 窄侧栏成组控件、列表行内动作、提示框内次级动作 → small（24px）
  - 硬约束：同一行 / 同一组内的控件必须同尺寸

**三、改动**

NoteWorkspace.tsx（4 处）
  1. 视图切换 Segmented 去掉 size="small" → 默认尺寸，与左右两个 Button
     同为 32px，右上角一行三控件同高
  2. 面板显示按钮补 DownOutlined → 与侧栏「筛选」按钮一样带下拉箭头，
     两个 Dropdown 触发器用同一种方式表达「点开会展开菜单」；原先只有
     一个图标，看起来像不可点的装饰
  3. 图谱范围 Segmented 去掉 size="small" → 与页面头部同一个组件在同一个
     视图下尺寸一致。原先顶部是默认、画布浮层是 small，同一组件同屏两种大小
  4. 右侧面板 Tabs 去掉 size="small" → 全仓库其余 8 处 Tabs 全部是默认尺寸
     （TaskManagement、TemplateManagement、FinanceManagement、
     AnnouncementManagement、ProjectDetailPage、ProposalDetailPage、
     MeetingDetailPage、TodoDetailPage），此处是唯一偏离；且其下方面板内容
     用的都是默认尺寸输入控件

NoteMetaPanel.tsx（1 处）
  置顶 Switch 的 checkedChildren 与 unCheckedChildren 都渲染 PushpinOutlined，
  两种状态图标完全相同，图标纯装饰、还把开关撑宽。删掉这两个 children，
  状态回归由轨道颜色与滑块位置表达；同时移除不再使用的 PushpinOutlined 引入。

**四、改造后的尺寸分布**

  默认尺寸（32px）：页面头部三个控件、图谱范围切换、右侧面板 Tabs、
    元信息面板的 Switch / Select / TreeSelect / Input / 保存按钮、
    编辑器标题输入与置顶/取消/保存三个操作按钮
  small（24px）：侧栏筛选按钮与视图切换（同一行、同尺寸）、
    树形节点行内 MoreOutlined、平铺行置顶/删除、草稿提示内恢复/丢弃、
    元信息只读信息折叠区、保存指示 Spin
