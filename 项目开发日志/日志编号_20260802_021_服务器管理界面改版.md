### 开发内容详述

#### ServerManagement.tsx — 卡片网格
- 移除 Table / ColumnsType / formatDateTime（原创建时间列废弃）
- 使用 antd `Card` + CSS Grid（沿用 AnnouncementManagement 的 cardGrid 模式），每张卡片：
  - title：服务器名称（自定义 button，点击跳转详情）
  - extra：状态 Tag（运行中/维护中/已退役）
  - body：用途、IP 地址（单行省略）、server_type Tag、deploy_status Tag
  - meta 行：系统数、维护人员数（`maintainer_ids.length`）
  - actions 底部：EyeOutlined(详情) / EditOutlined(编辑) / DeleteOutlined(删除)，均带 Tooltip
- 卡片悬停阴影上浮：`box-shadow: var(--shadow-lg)` + `translateY(-2px)`，过渡用 `--anim-normal`
- 顶部保留状态 Select + 搜索 Input.Search + 新建按钮；底部保留 antd `Pagination`（含 sizeChanger / quickJumper / showTotal）
- 空数据展示 antd `Empty`；加载中 `Spin` 包裹网格
- 系统数：SINGLE 由 `system_id` 判定 0/1；MULTI 列表接口不返回计数，按页对 MULTI 服务器调用 `getServerSystems(id)` 并行补充（每页最多 10 个请求，失败兜底 0）

#### ServerFormModal.tsx — 移除端口 / 单系统字段
- 删除 `port` Form.Item（含 InputNumber、Row、Col 导入清理），IP 字段改为整行
- 新增 `Form.useWatch` 监听 `server_type` 与 `name`；`mode === 'create' && server_type === 'SINGLE'` 时显示：
  - 「系统名称」Input，placeholder 动态为 `默认为 {服务器名称}-系统`
  - 「系统描述」TextArea，placeholder「可选，系统用途说明」
- 提交时 `system_name` / `system_description` 仅在存在时写入 payload，随 createServer 发送（后端 ServerCreate 已支持，service 层默认命名为 `f"{server.name}-系统"`）
- 编辑模式 server_type 保持 disabled；系统信息字段不展示（后端 ServerUpdate 不支持 system_name/system_description，系统在详情页维护）
- IP 校验（IPv4/IPv6 正则）与其他字段原样保留

#### types/server.ts
- ServerFormValues 新增可选字段 `system_name?: string` / `system_description?: string`（ServerFormValues 仅被服务器表单与 api/servers 引用，改动安全）

### 遇到的问题与解决
- 问题：编辑 ServerFormModal 前发现 `types/server.ts` 中 ServerFormValues 已无 `port` 字段（此前改动遗留），原 `values.port` 引用构成 TS 错误
  - 解决方案：本次一并移除表单中全部 port 引用，tsc -b 校验通过
- 问题：`ServerManagement.module.css` 中 `:global(.ant-card-body)` 被编辑器内置 CSS 校验器提示 unknown pseudo-class
  - 解决方案：确认项目无 stylelint 配置、仓库已有 6 处同款写法，属于编辑器误报；保留（`tsc -b` 不处理 CSS）
