### 开发内容详述

#### 后端实现

1. **数据模型**：`UserWebAuthnCredential` 存储用户已注册的 WebAuthn 凭据，包含 credential_id（唯一索引）、public_key（COSE 格式）、counter（防重放）、transports 等字段。

2. **服务层**：`webauthn_service.py` 实现核心逻辑：
   - `generate_registration_options`：生成注册配置（challenge、rp、user、pubKeyCredParams）
   - `verify_registration_and_store`：验证 attestation 并存储凭据
   - `generate_authentication_options`：生成验证配置（allowCredentials 列表）
   - `verify_authentication`：验证签名并更新计数器
   - 支持 EC2（P-256/P-384/P-521）、OKP（Ed25519）、RSA 三种密钥类型

3. **API 路由**：`webauthn.py` 提供 8 个端点：
   - `POST /register/start`：发起注册
   - `POST /register/finish`：完成注册
   - `GET /credentials`：列出凭据
   - `POST /credentials/{id}/remove`：删除凭据
   - `POST /authenticate/start`：发起验证（锁定页）
   - `POST /authenticate/start-login`：发起验证（登录页，使用 pending_token）
   - `POST /authenticate/check-login`：检查是否有凭据
   - `POST /verify-lock`：锁定页验证
   - `POST /verify-login`：登录页验证

### 遇到的问题与解决

1. **webauthn 库 API 变更**：
   - 问题：`webauthn.helpers` 没有 `generate_registration_options` 等函数
   - 解决：手动构造 `PublicKeyCredentialCreationOptions` 并使用 `options_to_json_dict()`

2. **COSEAlgorithmIdentifier 枚举值**：
   - 问题：`COSEAlgorithmIdentifier.ES256` 不存在
   - 解决：使用 `ECDSA_SHA_256`

3. **COSEKTY/COSECRV 导入路径**：
   - 问题：`from webauthn.helpers.structs import COSEKTY` 失败
   - 解决：`from webauthn.helpers.cose import COSEKTY, COSECRV`

4. **COSECRV 枚举值**：
   - 问题：`COSECRV.SECP256R1` 不存在
   - 解决：使用 `COSECRV.P256`、`COSECRV.P384`、`COSECRV.P521`、`COSECRV.ED25519`

5. **cryptography 库导入**：
   - 问题：`RSAPublicNumber` 不存在
   - 解决：使用 `RSAPublicNumbers`

6. **EllipticCurvePublicKey.from_encoded_point 参数**：
   - 问题：传入 3 个参数（curve, x, y）
   - 解决：构造点字节 `b'\x04' + x + y`，传入 2 个参数

7. **ResponseValidationError**：
   - 问题：`verify_login_endpoint` 返回 `LoginResponse` 但 `response_model` 是 `UnifiedResponse[dict]`
   - 解决：调用 `tokens.dict()` 转换为 dict
