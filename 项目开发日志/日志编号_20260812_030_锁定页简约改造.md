### 开发内容详述
1. **LockPage.tsx**：
   - 新增 `showInput` state（默认 false）与受控 `password` state；移除 Form 包裹（删除 LockFormValues 接口与 Form import）。
   - 渲染顺序：Avatar(80px) → 名字(Title) → 大锁图标（`<button>` + LockOutlined，64px，可点击）→ "已锁定"(Text secondary) → 密码输入区。
   - 锁图标 `onClick` → `setShowInput(true)`；密码输入区始终渲染，通过 `.expanded` class 切换展开（max-height 0→200px + opacity 过渡）。`useRef<InputRef>` + useEffect 在展开时 `focus()` 密码框（autoFocus 无法在已挂载元素上二次触发）。
   - `handleUnlock` 逻辑不变：`POST /auth/verify-password` → `code===0 && data.valid===true` 时 setDissolving(true) → 250ms 后 `sessionStorage.setItem('workbench_just_unlocked','1')` + `unlock()` + 依据 `workbench_lock_return` 回跳 `window.location.href`；密码错误 `message.error`，输入区保持展开态可继续尝试。
   - 空密码提交时 `message.warning('请输入密码')` 拦截；回车（onPressEnter）与解锁按钮均触发 handleUnlock。
2. **LockPage.module.css**：
   - `.lockIcon`：inline-flex、64px、cursor pointer、color var(--text-secondary)、hover 变 var(--color-info) + scale(1.06)、transition 200ms（按钮原生样式已 reset：无边框/背景/padding）。
   - `.inputArea`：max-width 360px、flex column + gap、overflow hidden、max-height 0→opacity 0、transition max-height 300ms + opacity 200ms；`.expanded`：max-height 200px + opacity 1。
   - `.unlockBtn`：width 100%（配合 Button block 全宽）。
   - 删除 `.form`/`.submitItem`；保留 avatar/title/subtitle + dissolving + lockPageFadeIn；enterElement stagger 保持 4 元素 0/60/120/180ms。

关键决策：
- 输入区常驻 DOM + class 切换（而非条件渲染），保证 max-height 过渡动画可播放；密码错误后保持展开态便于重试。
- 锁图标用语义化 `<button>` + aria-label="解锁"，可访问性优于 div 点击。
- 全部样式引用 design token（--text-secondary/--color-info/--spacing-*/--ink 等），深浅色自动适配。

### 遇到的问题与解决
- 问题：输入区常驻 DOM 时 `autoFocus` 不会在 showInput 变 true 时触发聚焦。
  - 解决方案：`useRef<InputRef>` + useEffect 监听 showInput 调 `focus()`。
- 问题：antd Input.Password 的 affix-wrapper 是 `<span>`，用 `closest('div')` 定位 inputArea 会误命中容器。
  - 解决方案（仅验证阶段）：改按 class 包含 `inputArea` 向上遍历定位，浏览器验证用 computed style 而非结构猜测。
- 遗留问题：无。
