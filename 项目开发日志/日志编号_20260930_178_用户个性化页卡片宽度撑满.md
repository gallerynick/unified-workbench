### 开发内容详述

**根因**：`.container` 上多了一条 `max-width: 800px;`。

两张卡片（`div.ant-card.ant-card-bordered` 与其下方那张）都在这个容器内，容器被限制在 800px 宽，卡片只能撑到容器的 800px，右侧留下空白。用户看到的「其中一张卡片和下面那张都没撑满」是同一个原因的两处表现，不是两个独立缺陷。

**修复**：删除该行，使 `.container` 回到与其他模块完全相同的形态：

```css
.container {
  display: flex;
  flex-direction: column;
  gap: var(--spacing-card-gap);
}
```

**一致性核对**：横扫 `pages/settings/` 下 8 个模块的 `.container`，修复前只有 `UserPersonalization.module.css` 含 `max-width`，其余 7 个（Profile / NotificationConfig / DevicesPage / CustomizationSettings / SiteSettings / DataManagement / BackupManagement）均无。修复后 8 个模块的 `.container` 声明逐字一致。

**未做的调整**：该页 `.header` 相比其他模块少了 `justify-content: space-between` 与 `gap`。本次只处理宽度问题，未顺手改标题栏对齐——那是另一处视觉差异，用户未提出，且本页标题栏内只有一个标题、没有右侧操作按钮，加不加 `space-between` 效果相同。留待后续若该页增加操作按钮时一并处理。

### 遇到的问题与解决

- 问题：横扫对比时首轮循环命令因 `$f` 被包在单引号内未展开，8 个文件全部输出为空。
- 解决方案：改为在 JS 侧将文件名直接插值进命令字符串后重试，正常取得对比结果。
