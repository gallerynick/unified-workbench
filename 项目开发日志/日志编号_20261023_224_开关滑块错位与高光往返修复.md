### 开发内容详述

**1. 错位根因**

上一版给加载态写了 `.isLoading .thumb { position: relative }`，覆盖了滑块原本的 `position: absolute` —— 滑块脱离绝对定位后回到文档流，位置与尺寸基准全变，表现就是错位。修正为只加 `overflow: hidden`，保持 `position: absolute; top/left: var(--sw-inset)` 不动。

**2. 改成真正的来回扫**

原写法靠 `animation-direction: alternate` 实现回扫，在部分组合下观感只往一个方向。改为单条 keyframes 显式往返：

```css
@keyframes thumbSweep {
  0%   { transform: translateX(-120%); }
  50%  { transform: translateX(120%); }
  100% { transform: translateX(-120%); }
}
animation: thumbSweep 1.6s var(--anim-ease-in-out) infinite;
```

0.8s 单程，往返一次 1.6s。

**3. 提高可见度**

| 项 | 之前 | 现在 |
|----|------|------|
| 高光色（浅色） | var(--border-secondary) #f0f0f0 | **var(--text-secondary) #8c8c8c** |
| 高光色（深色） | 同色 | **var(--text-tertiary)**，另加深色专用覆写 |
| 带宽 | 半幅（25%→75%） | **整幅渐变（0%→100%）**，带心占 50% |
| 不透明度 | 1（色本身太浅） | 浅色 0.55 / 深色 0.7 |
