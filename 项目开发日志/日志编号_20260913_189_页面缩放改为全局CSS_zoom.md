## 开发内容详述

### 缩放机制改造

原实现在 MainLayout 根容器上用 `transform: scale(zoomScale)` + 反向补偿 `width/height`，有两个问题：

1. **浮窗不跟随缩放**：AntD 的 Modal / Drawer / Popover / Dropdown / message / notification 默认 portal 到 `document.body`，不在 MainLayout 子树内，缩放对其无效
2. **布局测量被破坏**：`transform: scale` 不影响 `offsetWidth` / `clientWidth`（返回未缩放值），但 `getBoundingClientRect()` 返回缩放后的视觉值，两个单位混用导致 FullCalendar 表格与滚动区错位

改用 CSS `zoom` 后，上述问题均消除：

- **布局时缩放**：`zoom` 改变元素的布局尺寸，`offsetWidth` / `clientWidth` / `getBoundingClientRect()` 均返回缩放后的值，单位统一
- **浮窗自动跟随**：`html { zoom }` 作用于整个文档子树，portal 到 body 的浮窗自然包含在内
- **不破坏 fixed 定位**：`transform` 会创建新的包含块，导致 `position: fixed` 的 Modal mask 错位；`zoom` 不创建包含块
- **接近浏览器原生缩放**：`html { zoom }` 的效果等价于视口缩放，内容占满视口，不会出现 body zoom 那种"内容缩小但视口不变"的空白

### usePageZoom Hook 设计

- **引用计数**：`activeCount` 管理同时挂载的组件数（工作台 + 锁定页），避免互相清除
- **路由切换防闪烁**：组件卸载时 `activeCount--`，归零后延迟一个 `setTimeout(0)` 清空 zoom；若新组件在此窗口内挂载则取消清理（工作台 <-> 锁定页切换不闪）
- **偏好读取**：挂载时异步读取 `getUserPreferences()` 的 `page_zoom` 字段并应用
- **事件监听**：监听个性化页面保存设置时派发的 `zoom-changed` 事件
- **CSS 变量下发**：应用 zoom 时同步设置 `--zoom-scale` CSS 变量到 `:root`，供使用 `100vh` 的页面（如锁定页）做高度补偿

### 锁定页纳入缩放

LockPage 是顶层独立路由（不在 MainLayout 子树内），原设计未包含缩放。现在通过调用 `usePageZoom()` 将其纳入，与工作台保持一致。

### CalendarPage 补偿逻辑移除

原补偿逻辑（约 80 行）在 `transform: scale` 下是必要的：FullCalendar 用 `getBoundingClientRect()` 量 scroller 取到视觉尺寸，却当作布局尺寸写进 sync-table，导致错位。补偿方案是用 `clientWidth` / `clientHeight`（不受 transform 影响）重新测量，下发 CSS 变量覆盖。

改用 `zoom` 后，两个单位一致，FullCalendar 内部布局自洽，补偿不再需要。删除内容：

- scroller 测量 effect（`--cal-grid-h` / `--cal-grid-w` 下发）
- 切视图补测 effect（`measureRef` + 双 rAF）
- `CalendarPage.module.css` 中 `sync-table` 宽高 `!important` 覆盖

`--avail` effect 保留（用于面板高度计算），仅更新注释说明 `offsetHeight` 在 zoom 下的行为。

### 缩放档位扩展

ZOOM_OPTIONS 从 3 档（90 / 95 / 100）扩展为 5 档（90 / 95 / 100 / 105 / 110），支持放大场景。

## 遇到的问题与解决

1. **路由切换闪烁**：MainLayout 卸载 -> LockPage 挂载之间，`activeCount` 短暂归零会导致 zoom 被清空再恢复。解决：延迟一个 `setTimeout(0)` 清空，新组件挂载时取消清理
2. **useMemo 导入未使用**：移除 `zoomScale = useMemo(` 后检查确认 `useMemo` 仍有其他使用（selectedKey），无需改导入
3. **105/110 保存失败**：后端 Pydantic `page_zoom` 正则仅允许 `100|95|90`，前端新增的 105/110 被验证拒绝。解决：扩展正则为 `^(90|95|100|105|110)$`
4. **锁定页底部未覆盖底色**：`html { zoom: 0.9 }` 下 `.container` 的 `min-height: 100vh` 在布局坐标系中为 100vh，渲染缩放后仅覆盖 90% 视口，底部露出 body 的 `--canvas` 底色（与 LockPage 的 `--canvas-parchment` 不同色）。解决：在 `usePageZoom` 中同步下发 `--zoom-scale` CSS 变量到 `:root`，LockPage 改用 `min-height: calc(100vh / var(--zoom-scale, 1))` 补偿。未缩放时变量不存在，回退为 1，不影响登录页等独立页面
