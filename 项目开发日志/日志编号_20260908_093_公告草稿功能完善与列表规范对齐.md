### 开发内容详述

#### 1. 草稿功能完善（核心）

草稿功能完成度原本约 70%：后端模型 is_published 列、Pydantic Schema 三处字段、create/update 写入逻辑均已存在，前端类型与 Tag 渲染也齐备。唯一卡点：

- 后端 services/announcement.py:15 硬编码 where(Announcement.is_published == True)，草稿永远被过滤掉，前端「草稿」Tag 分支为死代码
- 前端 AnnouncementModal 新建模式不渲染「发布状态」Switch，createAnnouncement 调用不传 is_published，用户无法从 UI 创建草稿

本次修复：

后端——list_announcements 过滤逻辑改为按视图分流：

    if owner_id is not None:
        # 创建者视图（「我创建的」）：包含草稿
        query = query.where(Announcement.owner_id == owner_id)
    else:
        # 公开视图（「全部」）：仅已发布
        query = query.where(Announcement.is_published == True)

语义：管理员在「我创建的」可见自己的草稿；所有成员在「全部」只见已发布公告。

前端 Modal——「发布状态」Switch 去掉 editingAnnouncement && 门控，新建/编辑均渲染；createAnnouncement 调用补传 is_published: published；新建默认 published=true 保持既有行为。

#### 2. Switch 图标移除

AnnouncementModal 第 139-140 行原本使用 checkedChildren 内嵌 EyeOutlined/EyeInvisibleOutlined 图标，是全项目 14 处 Switch 中唯一在 children 内放图标的实现（其余 13 处均为纯文本：必填/可选、全天/非全天、置顶/普通、启用/禁用、开启/关闭）。

移除 EyeOutlined/EyeInvisibleOutlined 导入与 JSX 中的图标节点，改为纯文本 checkedChildren="已发布"/unCheckedChildren="草稿"，与全项目范式一致。UI 规范定义的 switch 组件仅含 width/height/backgroundColor/activeBackground/rounded 五项属性，无 children/图标规格。

#### 4. 非管理员门控

后端 create_announcement_endpoint 要求 require_admin，但前端无 admin 判断，非管理员点击「发布公告」直接 403。同理「我创建的」标签页对非管理员必然空列表。

修复：
- 「发布公告」按钮加 userIsAdmin 条件渲染
- Tabs 组件加 userIsAdmin 条件渲染（非管理员直接看已发布列表，不显示标签页）
- canManage 逻辑不变（owner_id 匹配或 admin），因仅 admin 可创建，owner 恒为 admin

#### 5. 权限说明文案修正

原文案存在两处不准确：
- 「草稿状态的公告仅创建者和管理员可见」——原文案暗示草稿可见，实际后端已过滤，草稿不可见。草稿功能修复后，改为「草稿仅创建者在『我创建的』标签页可见」
- 「公告创建者和管理员可以编辑、删除自己创建的公告」——因仅 admin 可创建，「创建者」恒为 admin，第二句冗余。改为「管理员可以编辑和删除所有公告；普通成员仅可查看已发布的公告」

### 追加修订：草稿交互模式从 Switch 改为动作按钮

#### 修订背景
初版实现使用 Switch 切换「已发布/草稿」状态，用户反馈不符合操作语义——发布/保存草稿是提交动作，不是状态切换开关。

#### 修订内容

AnnouncementModal.tsx 改动：
1. 删除「发布状态」Switch 表单项（原 editingAnnouncement 门控后的第 134-141 行）
2. 删除 published state 变量与 useEffect 中的 setPublished 调用
3. handleSubmit 改为接受 isPublished 参数，两个按钮分别调用 handleSubmit(false) / handleSubmit(true)
4. Modal 改用自定义 footer：取消 / 保存草稿 / 发布（三个动作按钮）
5. 去掉 onOk / okText / cancelText / confirmLoading props

#### 交互变化

| 之前 | 现在 |
|---|---|
| 表单内 Switch 切换已发布/草稿 | 表单底部三个动作按钮 |
| 底部：取消 + 发布/保存（单按钮） | 底部：取消 + 保存草稿 + 发布（双动作） |
| is_published 由 Switch 状态决定 | is_published 由点击的按钮决定 |
