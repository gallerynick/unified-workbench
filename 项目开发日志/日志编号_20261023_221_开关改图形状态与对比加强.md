### 开发内容详述

**1. 图形代替字母**

- 通（开）：竖线 0.2em × 0.9em，圆角 4px
- 断（关）：圆环 0.8em，描边 0.14em
- 均用 em 定义，随尺寸档自动缩放（紧凑 12px / 默认 14px / 大 14px）

**2. 图形位置：轨道上、滑块之后**

- 轨道内两个绝对定位图形槽位，各占一半宽度（.glyph 宽 50%），z-index 0
- 滑块 z-index 1，滑过去把其中一侧盖住
- 开时滑块在右（27~53），左侧（0~28）露出竖线；关时滑块在左（3~29），右侧（28~56）露出圆环
- 滑块内部保持完全空白（只在加载时放转圈图标）

**3. 对比度加强**

- 关：轨道 var(--border-primary)（#d9d9d9，与输入框描边同色），白底上清晰可见
- 开：轨道 var(--color-info)（#1677ff，与输入框焦点蓝同色）
- 图形配色：开启侧 var(--btn-primary-text) 白，关闭侧 var(--ink-muted-80)
- 这样「底色 / 位置 / 图形」三层信号叠加，不再依赖单一维度

**4. 分区结构**

基线对照（输入框 / 下拉 / 滑动选择框 / 开关 / 按钮）→ 1. 两态对比 → 2. 尺寸 → 3. 轨道内容（无内容 / 图形 / 文字）→ 4. 状态 → 5. 设置行 → 6. 与按钮并排 → 规格速查 → 使用建议
