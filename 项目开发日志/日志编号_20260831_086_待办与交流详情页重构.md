### 开发内容详述

**1. 待办详情页（TodoDetailPage）重构**
- 「待办详情」Tab 由 Descriptions 单表格改为：状态流转 Steps（pending→in_progress→completed，依据待办状态字段）+ 定义列表（编号/标题/状态/优先级/创建人/执行人/截止日期/关联提案/创建时间/更新时间）+ 描述段落区块
- 描述保持纯文本，不引入富文本：待办描述属任务备注性质，富文本收益低，与提案「文档式描述」定位不同
- 「关联内容」Tab 关联项由单行改为 .linkedContent 上下分层：首行编号+标题（可点击跳转），次行元信息（提案显示状态 Tag、优先级 Tag、执行人；交流显示发言人、内容 60 字摘要）
- 关联提案由 UUID 展示改为提案编号链接，可跳转提案详情页
- 「待办操作」Tab（仅 todos 非只读权限可见）：状态操作（当前状态、分状态推进按钮、切换状态 Select，回退或跳级二次确认）+ 其他操作（编辑、删除）
- 新增编辑入口，复用共用组件 TodoModal（编辑模式）；新增「新建并关联交流」，复用 MeetingModal 的 initialTodoId

**2. 交流详情页（MeetingDetailPage）重构**
- 「交流详情」Tab 由 Descriptions 单表格改为定义列表 + 段落区块（交流正文、备注）
- 不做状态流转 Steps：交流后端 schema 无 status 字段，无流转可展示
- 内容保持「标题+正文」纯文本结构：既有数据按该格式落库，富文本会破坏解析
- 编辑由 60 行内联 Form 改为复用共用组件 MeetingModal，删除内联表单
- 修复「关联提案」显示原始 UUID 的问题，改为提案编号链接；「关联待办」同样改为编号链接
- 关联内容元信息行同待办页范式；保留页头编辑/删除按钮，未加操作 Tab（无状态流转需求）

**3. MeetingModal 扩展正文字段**
- 新增「正文」表单项（TextArea，5000 字）：原表单只编辑标题部分、正文由 splitTitleContent 保留，改为详情页复用后正文编辑能力会丢失，故补齐
- 编辑模式回填标题与正文；提交时正文为空则不写入分隔符
- 新建模式正文可选；交流记录 Tab 新建表单因此多一个可选字段，向后兼容
- 内容拆分工具 splitTitleContent 导出复用，供交流详情页调用，避免第 2 份副本

**4. 颜色映射集中化**
- constants/project.ts 新增 PRIORITY_COLOR、PROPOSAL_STATUS_COLOR、TODO_STATUS_COLOR、TODO_STATUS_LABEL
- ProposalDetailPage.tsx 删除本地 PRIORITY_COLOR / STATUS_COLOR / TODO_STATUS_COLOR / TODO_STATUS_LABEL 定义，改为导入
- ProposalTab.tsx 删除本地 PRIORITY_COLOR / STATUS_COLOR 定义（与常量值完全一致），改为导入
- TodoTaskTab.tsx 的 PRIORITY_COLOR 值与常量不同（P2 为 gold、P3 为 default），属既有颜色不一致，本次未改动，避免超出范围改变看板视觉表现

**5. 样式**
- 两个详情页 module.css 补充 .linkedContent 与详情 Tab 样式（.tabContent / .definitionList / .defItem / .defLabel / .defValue / .textBlock / .textLabel / .textBody），全部引用全局 Design Token，深浅色自动适配；.definitionList 在小屏降为单列

### 遇到的问题与解决
- 问题：MeetingModal 原本不编辑正文，交流详情页改用该组件后正文无法编辑
  - 解决方案：MeetingModal 增加「正文」表单项并回填提交；导出 splitTitleContent 供详情页复用
- 问题：拟为「新建并关联」对称实现提案与待办方向，但后端 ProjectTodoCreate / ProjectProposalCreate 无 meeting_id 字段，ProposalModal 无 initialTodoId、TodoModal 无 initialMeetingId，无法直接落库
  - 解决方案：只在后端支持的方向实现——待办详情页「新建并关联」仅交流（MeetingModal initialTodoId 已有支持）；交流详情页关联提案/待办仅提供「添加已有」。后端双向关联支持列为待办
- 问题：run_code 内联模板字符串嵌套反引号导致解析失败
  - 解决方案：写入的文件内容统一用模板字符串承载，其中的字面反引号转义为 `
- 问题：Ant Design 的 Paragraph 属于 Typography 而非 antd 顶层导出，直接 import 报 TS2305
  - 解决方案：从 Typography 解构 Paragraph
- 问题：Select 的 mode 不接受 "single"（TS2322）
  - 解决方案：移除该属性，默认即单选
- 遗留问题 / 待办：TodoTaskTab 的 PRIORITY_COLOR 与常量不一致，需产品确认以哪套为准后统一；后端交流-提案-待办双向关联（meeting_id 字段）未支持
