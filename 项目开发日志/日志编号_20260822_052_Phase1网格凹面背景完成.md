### 开发内容详述

**最终规格**（用户逐轮确认）：
- 底色：纯黑 `#000`
- 网格形态：凹面（内凹），非凸面
- 网格密度：16 格/单位，仅粗网格，无细网格
- 网格颜色：淡白色（0.35 亮度）
- 移动：正弦缓慢往复，稳定无跳变
- 边缘效果：边缘渐暗（vignette）、边缘 noise 失真、透镜色散（RGB 径向偏移）
- 中心效果：无失真、无色散、网格稳定

**最终着色器架构**：

```
gridWire(vec2 sc, float flow, float edgeFactor, float t)
  ├─ 凹面缩放: scale = 1.0 / (1.0 + k * r2), k=1.5
  ├─ 流动偏移: fx = sc.x * scale + flow
  ├─ 边缘失真: noise2(sc*4.0 + u_time) * 0.015 * edgeFactor
  └─ 网格检测: smoothstep(0.035, 0.005, min(dX, dY)), freq=16.0

main()
  ├─ flow = sin(mod(u_time*0.05, 2π)) * 0.2
  ├─ edgeFactor = smoothstep(0.05, 0.4, r2)
  ├─ ca = smoothstep(0.1, 0.5, r2) * 0.015  // 透镜色散
  ├─ dir = normalize(sc + 0.001)              // 径向方向
  ├─ wireR = gridWire(sc + dir * ca, ...)     // R 通道径向外偏
  ├─ wireG = gridWire(sc, ...)                // G 通道居中
  ├─ wireB = gridWire(sc - dir * ca, ...)     // B 通道径向内偏
  ├─ vignette = 1.0 - smoothstep(0.3, 0.8, r2)
  └─ col.rgb = 0.35 * wire{RGB} * vignette
```

**关键技术决策**：

| 决策 | 原因 |
|------|------|
| 凹面公式从迭代式 `x = sc.x*(D-k*r2w)/D` 改为 `scale = 1/(1+k*r2)` | 迭代式在 k 较大时边缘出现符号翻转（负值），`1/(1+k*r2)` 恒为正，安全且凹面更强 |
| 流动从 `fract(u_time*0.02)` 改为 `sin(mod(u_time*0.05, 2π))*0.2` | fract 有周期跳变（0.99→0.0），sin 平滑无跳变；mod 2π 确保 sin 参数始终在精度范围内 |
| 精度从 `mediump` 改为 `highp` | mediump（16位）下大数 sin/fract 精度丢失导致线条闪烁 |
| 色散从 fx 水平偏移改为 sc 径向偏移后重算网格 | fx 偏移产生三根平行线（不真实），sc 径向偏移后重算整个网格模拟真实透镜色差 |
| 失真加 edgeFactor 门控 | 中心无失真保持稳定，边缘失真增加真实感 |

### 遇到的问题与解决
- 问题：线条闪烁（多轮修复后仍存在）
- 根因：`precision mediump float`（16位浮点）下 `sin`/`fract` 大参数精度极差
- 解决方案：`precision highp float`（32位）+ `sin(mod(u_time*0.05, 6.28318))` 双保险

- 问题：色散呈现三根分离线（不真实）
- 根因：旧方案在网格参数空间 fx 上做水平偏移，仅偏移参数不重算网格
- 解决方案：在屏幕空间 sc 上做径向偏移后调用 `gridWire()` 重算整个网格（含凹面缩放+失真）

- 问题：网格过密时细网格干扰视觉
- 解决方案：删除 freq1=20 的细网格，仅保留 freq2=16 的粗网格

- 遗留问题：无

### 最终优化（v3 — 用户反馈后）

**用户反馈**：中心凹面已出现，但四周仍拱起；需要稳定移动、纯凹面、边缘变暗、更密集网格、删除小网格。

**根因**：噪声失真（noise2 × edgeFactor）在边缘最强，造成拱起扭曲；色散（R/G/B 径向偏移）在边缘产生三根分离线。

**变更**：

| 项目 | v2 | v3 |
|------|-----|-----|
| 凹面强度 k | 1.5 | 2.5 |
| 网格密度 freq | 16.0 | 20.0 |
| 网格层数 | 1 层 | 1 层 |
| 网格 smoothstep | (0.035, 0.005) | (0.03, 0.005) |
| 流动 | sin(mod(u_time×0.05, 2π))×0.2 | sin(u_time×0.3)×0.12 |
| 边缘失真 | noise2 × edgeFactor | **删除** |
| 色散 | R/G/B 径向偏移 | **删除** |
| 暗角 | smoothstep(0.3, 0.8, r2) | smoothstep(0.25, 0.7, r2) |
| 暗角范围 | 中心 70% 无暗 | 中心 40% 无暗 |

**最终着色器**（v3，极简版）：

```
main()
  ├─ flow = sin(u_time * 0.3) * 0.12          // 稳定有界振荡
  ├─ scale = 1.0 / (1.0 + k * r2), k = 2.5   // 凹面，恒正
  ├─ fx = sc.x * scale + flow
  ├─ fy = sc.y * scale + flow * 0.5
  ├─ wire = smoothstep(0.03, 0.005, min(dX, dY)), freq = 20.0
  ├─ col = vec3(0.35) * wire
  └─ col *= (1.0 - smoothstep(0.25, 0.7, r2))  // 暗角
```
