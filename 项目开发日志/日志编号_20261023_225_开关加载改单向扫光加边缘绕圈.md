### 开发内容详述

**1. 单向扫光**

```css
@keyframes thumbSweep {
  0%   { transform: translateX(-130%); }
  100% { transform: translateX(130%); }
}
animation: thumbSweep 1.2s linear infinite;
```

去掉 `alternate` 与 50% 折返，每轮从左侧重新开始，节奏改线性以保证匀速掠过。

**2. 边缘绕圈亮**

```css
.isLoading .thumb::before {
  border: 2px solid transparent;
  border-top-color: var(--color-info);
  border-radius: inherit;
  animation: thumbEdge 0.9s linear infinite;
}
@keyframes thumbEdge { to { transform: rotate(360deg); } }
```

只亮一边的 2px 边框作为「亮点」，整圈旋转，形成亮点绕滑块边缘跑动的效果；用 `border-radius: inherit` 保证与滑块圆角贴合。z-index 放在扫光之上。

**3. 层次**

`::after` 扫光 z-index 1，`::before` 边缘亮 z-index 2，均被滑块 `overflow: hidden` 裁在内部；滑块本身仍为 `position: absolute`，未触碰定位基准。

### 遇到的问题与解决
- 问题：往返扫动不符合要求。
- 解决：改为 0% → 100% 单程 + `infinite`，不做折返。
- 加载动效仍需与 `prefers-reduced-motion` 兼容：扫光 2.6s、边缘 2s。
