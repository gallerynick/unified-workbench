### 开发内容详述

**1. 组件化**

新增 `@/components/AppSwitch`，API 与 antd Switch 对齐（checked / defaultChecked / onChange / disabled / loading / size / className / style / id / name），额外接受 checkedChildren/unCheckedChildren —— 开关内不再渲染文字，这两个属性仅在没有 aria-label 时用于兜底无障碍名称。因此替换方式是「换 import、不改 JSX」，Form.Item 的 valuePropName="checked" 绑定不受影响。

支持的尺寸：sm 44×24 / md 56×32（默认）/ lg 68×38，同时兼容 antd 的 small / middle / large 写法。

**2. 视觉实现**

- 轨道：关 = --switch-track-off（--border-primary）/ 开 = --switch-track-on（--color-info），圆角 --switch-radius（8px）
- 滑块：--switch-thumb-bg（--canvas）+ --switch-thumb-shadow，圆角 --switch-thumb-radius（5px），四周留 --switch-inset（3px）
- 状态图形：轨道上两个绝对定位槽位各占一半（z-index 0），滑块 z-index 1 滑过遮挡；通=竖线、断=圆环
- 加载：滑块内单向扫光 1.4s + 描边亮光绕行 2s（@property 注册 --app-switch-halo，只转渐变角度）；轨道图形降 35%
- 禁用：整体 opacity --switch-disabled-opacity（0.45）+ 去投影 + 滑块上淡锁（LockOutlined 12px / --ink-muted-48 / opacity 0.55）

**3. token.css**

新增按钮族：--btn-radius / --btn-height / --btn-bg / --btn-border / --btn-text / --btn-hover-bg / --btn-selected-bg / --btn-selected-text；--btn-primary-rounded 由 pill 改 sm，--btn-primary-bg 由 color-primary 改 color-info。
新增开关族：--switch-width/height/thumb-size/inset/radius/thumb-radius/track-off/track-on/thumb-bg/thumb-shadow/glyph-on/glyph-off/halo/三档尺寸/disabled-opacity；深色块内覆写 --switch-halo 为 body-on-dark。

**4. 基定文档**

按钮：button-primary / -focus / -active、button-hero 的 rounded 改 {rounded.sm}；button-secondary-pill 更名 button-secondary 并改中性描边；主行动底色改 {colors.color-info}；圆角阶梯表、设计准则、触达尺寸、模态框引用同步。
开关：YAML 补齐三档尺寸、滑块、图形、加载、禁用与圆角；正文重写为「关=输入框描边色 / 开=焦点蓝 / 滑块恒白 / I-O 图形画在轨道上」，并明确禁止文字开关。

### 遇到的问题与解决

- **问题**：批量替换后用脚本重建的 antd import 变成超长单行，prettier 报格式不符。
- **解决**：写脚本只对超过 100 字符的 antd import 行按项目风格折行（7 个文件），不对整文件跑 prettier，避免污染他人未提交改动。
- **问题**：仓库里原本就有大量未提交改动（api/ hooks/ types/ meetings/ 等）。
- **解决**：本次只改与开关/按钮相关的文件，未对这些 WIP 文件做任何格式化。
- **遗留**：直接替换后，原来靠 checkedChildren 显示「启用/禁用」「开/关」的开关文案消失，改为 I/O 图形——这是「统一且禁止文字开关」的直接结果，若某处仍需文字提示需在行内补说明。
