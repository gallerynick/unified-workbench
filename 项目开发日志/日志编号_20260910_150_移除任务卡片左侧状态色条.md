### 开发内容详述

上一轮（日志 149）为便于扫读给卡片加了左侧 3px 状态色条，颜色随状态切换：

| 状态 | 取色 |
|---|---|
| 待办 | `--text-tertiary`（#bfbfbf 浅灰） |
| 进行中 | `--color-info`（蓝） |
| 已完成 | `--color-success`（绿） |
| 已取消 | `--color-error`（红） |

问题在于新建任务默认就是「待办」，也就是列表里绝大多数卡片左侧都是同一条
浅灰竖条。它没有色彩差异，看起来不是状态标识，而是卡片底下的灰底从左边
露了出来——观感像渲染缺陷。

处理：整条移除。

- 删掉 `TaskCard` 里的 `<div className={styles.accentBar} />` 节点，以及
  为它拼接的 `status-${task.status}` 类名（该类名仅服务于色条取色，已无用途）
- CSS 删除 `.accentBar` 定义与 4 条 `status-xxx .accentBar` 取色规则，
  同时清掉 `.card` 上仅为色条服务的 `position: relative` / `display: flex` /
  `overflow: hidden`，以及 `.cardBody` 上对应的 `flex: 1` / `min-width: 0`
  （色条已不存在，这些约束都多余了）

状态信息**没有丢失**：内联的状态选择器（`待办 / 进行中 / 已完成 / 已取消`）
带 antd 状态色，一眼可读，色条本就与之重复。

### 遇到的问题与解决
- 问题：色条移除后 `.card` 上遗留 `position: relative` / `overflow: hidden`
  等已无用约束
  解决方案：一并清理，卡片回到纯 block + 圆角描边的最简结构
- 遗留问题：无
