### 开发内容详述

**1. 现状问题**

全站 32 处 `<Switch />` 走 antd 默认样式：开启轨道取 `colorPrimary` = #0066cc（品牌蓝），关闭轨道为半透明黑，握把白。而输入框焦点、分段控件选中、主按钮都是 `--color-info` = #1677ff。同一个界面里出现两种蓝，且关闭态的"半透明黑"与输入框的实色描边不是一套语言——这就是开关显得"和输入框不搭"的原因。

**2. 新规格（全部取 token）**

| 项 | 取值 |
|----|------|
| 轨道（关） | var(--border-primary)，即输入框描边色（浅 #d9d9d9 / 深 #434343） |
| 轨道（开） | var(--color-info)，即输入框焦点蓝（浅 #1677ff / 深 #1668dc） |
| 握把 | var(--body-on-dark) 恒为白 + var(--shadow-sm) |
| 轨道圆角 | var(--rounded-pill) 全胶囊；握把 var(--rounded-circular) |
| 尺寸 | 默认 44×22（--switch-width/--switch-height）、紧凑 32×18、大 52×26 |
| 握把直径 | 轨道高 − 4px，内缩 2px |
| 位移 | translateX(轨道宽 − 握把 − 4px)，var(--anim-normal) ease-in-out |
| 悬停 | filter: brightness(0.96)，不改底色 |
| 焦点 | 2px var(--color-primary-focus)，offset 2px |
| 禁用（关） | 轨道 var(--bg-tertiary) + 内发丝线 var(--border-secondary)，握把去投影 |
| 禁用（开） | 轨道保持 var(--color-info) + opacity 0.45 |
| 加载 | 握把内 12px 转圈图标，控件 pointer-events: none |

**3. 实现要点**

- 自建 `Switch` 子组件用 `<button role="switch" aria-checked>`，键盘空格/回车原生可用，无障碍语义完整；不用 antd Switch 以便完全控制轨道/握把的 token 取值。
- 尺寸通过 CSS 自定义属性 `--switch-w/--switch-h/--switch-thumb/--switch-inset` 逐档覆盖，位移用 `calc()` 推导，避免硬编码三种位移值。
- 握把颜色关键决策：最初取 `var(--canvas)`，实测深色主题下握把变成 #141414，与 #434343 轨道几乎同色、视觉上"消失"；改取 `var(--body-on-dark)`（两种主题下均为白）后深浅一致。
- 分区内容：基线对照条（输入框 / 下拉 / 开关 / 按钮并排）→ 基础形态 → 尺寸 → 状态（禁用两态 + 加载两态）→ 设置行（调试模式 / 维护模式 / 闲置自动锁定三条真实文案）→ 规格速查 → 使用建议。

### 遇到的问题与解决

- **问题**：深色模式握把取 --canvas 变近黑，与轨道同色，开关看起来像"没有握把"。
- **解决方案**：握把改用 --body-on-dark，并用计算样式复测两侧：深色 off 轨道 rgb(67,67,67) / 握把 rgb(255,255,255)。
- **问题**：修改 CSS 后 edit 报 `file changed since it was read`——prettier --write 重写过该文件。
- **解决方案**：重新 read 后再 edit，未强改。
- **遗留 / 待办**：尚未写入 `ThemeContext` 的 Switch 组件 token，32 处存量 Switch 仍是旧样式，待用户确认后统一替换。
