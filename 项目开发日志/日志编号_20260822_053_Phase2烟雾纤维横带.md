### 开发内容详述

**方案迭代**（三版）：

1. **第一版（已废弃）**：WebGL fragment shader + domain warping + fbm 噪声纹理
   - 用户反馈：noise 纹理无法表现离散粒子的纤维感

2. **第二版（已废弃）**：WebGL 粒子系统 — 100 纤维 × 60 粒子 = 6000
   - 粒子沿 noise1d 纤维路径流动，age 触发瓦解，瓦解后随机漂移+衰减+重生
   - 用户反馈："换个思路，使用粒子构成一种类似星环那种的感觉，然后是平行的"

3. **第三版（当前）**：WebGL 星环粒子系统 — 28 环 × 280 粒子 = 7840

**星环系统架构**：
```
Ring（环参数）
  ├─ radiusX: 0.2 ~ 1.3（线性 + noise 扰动）
  ├─ radiusY: radiusX × 0.1（扁椭圆，微仰角）
  ├─ speed: 0.08 / √(radiusX+0.3) × 随机正负（Kepler 式，内快外慢）
  ├─ phase: 0 ~ 2π（初始角度偏移）
  └─ gap: noise > 0.72 → radiusX=0（Cassini 缝，部分环留空）

Particle（粒子参数）
  ├─ ringIdx: 所属环索引
  ├─ angle: 当前轨道角度（随时间递增）
  ├─ angularVel: 0.8 ~ 1.2（个体速度差异）
  ├─ brightness: 亮星 0.25~0.40（12%）/ 暗星 0.06~0.12（88%）
  ├─ size: 亮星 2.5~4.5px / 暗星 1.0~2.2px
  └─ twinkle: 随机相位，sin(t×2+phase)×0.3 闪烁

Update（每帧）
  ├─ angle += ring.speed × particle.angularVel × dt
  ├─ x = ring.radiusX × cos(angle + ring.phase)
  ├─ y = ring.radiusY × sin(angle + ring.phase)
  ├─ density = noise1d(angle×3 + ring.phase + t×0.05)
  └─ alpha = brightness × density × twinkle
```

**渲染**：
- `gl.POINTS` + additive blending（`gl.SRC_ALPHA, gl.ONE`）
- 圆形软粒子：`discard` r > 0.25，`smoothstep(0.25, 0.0, r)` 软边
- CPU 更新粒子位置 → `gl.bufferData(DYNAMIC_DRAW)` 每帧上传

### 遇到的问题与解决
- 问题：TypeScript 严格模式报 `WelcomeAnimationSection` 未使用（TS6133）
- 解决方案：移除未使用导入
- 问题：TypeScript `noUncheckedIndexedAccess` 报 `particles[i]` / `rings[ri]` possibly undefined（TS18048）
- 解决方案：添加非空断言 `!`（索引在循环内保证有效）
