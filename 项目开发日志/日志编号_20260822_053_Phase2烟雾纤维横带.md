### 开发内容详述

**参考素材**：用户提供 3 张烟雾摄影参考图，核心视觉关键词：粒子构成的纤维状带 → 瓦解成烟雾

**参考图分析**：
| 维度 | 描述 |
|------|------|
| 形态 | 水平横带，居中纵向分布 |
| 构成 | 大量粒子组成纤维状带（非 noise 纹理） |
| 瓦解 | 部分纤维瓦解成散落粒子，类似烟 |
| 密度 | 非均匀 — 纤维密集区（亮）+ 瓦解弥漫区（暗） |
| 色调 | 纯灰度 |

**方案迭代**：

1. **第一版（已废弃）**：WebGL fragment shader + domain warping + fbm 噪声纹理
   - 用户反馈："不是这样子的，它是由很多很多的粒子构成的纤维状带，然后再瓦解成粒子类似烟"
   - noise 纹理无法表现离散粒子的纤维感和瓦解过程

2. **第二版（当前）**：WebGL 粒子系统（`gl.POINTS`）

**粒子系统架构**：
```
100 纤维 × 60 粒子 = 6000 粒子

Fiber（纤维）
  ├─ baseY: -0.22 ~ +0.22（横带范围内）
  ├─ amp: 0.008 ~ 0.033（路径振幅）
  ├─ freq: 3.0 ~ 11.0（路径频率）
  └─ phase: 0 ~ 100（路径相位）

Particle（粒子生命周期）
  ├─ 纤维态 (breakaway < 0.5)
  │   ├─ 跟随 noise1d 纤维路径
  │   ├─ 横向流动 flowSpeed = 0.04 + noise(t)
  │   └─ 亮 alpha = 0.14 * life
  ├─ 瓦解触发
  │   ├─ age > breakTime（0.5~5.5s 随机）
  │   └─ 空间 dissolve > 0.65（noise1d 区域性瓦解）
  ├─ 瓦解态 (breakaway ≥ 0.5)
  │   ├─ 自由漂移（随机游走 + 轻微上飘）
  │   ├─ 速度衰减 offX/Y *= 0.98
  │   └─ 暗 alpha = 0.08 * life
  ├─ 生命衰减 life -= dt * 0.18
  └─ 重生 (life ≤ 0 或 x > 1.3)
      └─ 左侧重生，分配新纤维
```

**渲染**：
- `gl.POINTS` + additive blending（`gl.SRC_ALPHA, gl.ONE`）
- 圆形软粒子：`discard` r > 0.25，`smoothstep(0.25, 0.0, r)` 软边
- 粒径 1.5~3.5px
- CPU 更新粒子状态 → `gl.bufferData(DYNAMIC_DRAW)` 每帧上传

### 遇到的问题与解决
- 问题：TypeScript 严格模式报 `WelcomeAnimationSection` 未使用（TS6133）
- 解决方案：移除未使用导入
- 问题：TypeScript `noUncheckedIndexedAccess` 报 `particles[i]` / `fibers[fi]` possibly undefined（TS18048）
- 解决方案：添加非空断言 `!`（索引在循环内保证有效）
