### 开发内容详述

**参考素材**：用户提供 3 张烟雾摄影参考图，核心视觉关键词：烟雾纤维横带（smoke fiber band）

**参考图分析**：
| 维度 | 描述 |
|------|------|
| 形态 | 水平横带，居中纵向分布 |
| 纹理 | 纤维状/网状白色细丝，交织在深色团块中 |
| 密度 | 非均匀 — 浓密暗团 + 半透明弥漫区 + 高亮白线 |
| 边缘 | 横带上下柔边融入纯黑 |
| 色调 | 纯灰度 |
| 动态 | 横向流动感 + 涡旋扰动 |

**实现方案：WebGL fragment shader**

核心技术：
1. **fbm（5 层 fractal brownian motion）** — 多倍频噪声叠加产生湍流基底
2. **Domain warping（双层域扭曲）** — Inigo Quilez 风格，用噪声位移坐标后再采样噪声，产生漩涡纤维
3. **横向拉伸** — `vec2 p = vec2(uv.x * 3.0, uv.y * 8.0)` 拉伸 x 产生水平纤维走向
4. **横带遮罩** — `smoothstep` 上下柔边限制为水平横带
5. **低频密度场** — `fbm(uv * 1.5)` 控制明暗团块分布
6. **阈值化亮线** — `smoothstep(0.45, 0.65, f)` 从噪声中提取高亮纤维
7. **时间动画** — `u_time * 0.03` 慢速横向漂移

**着色器架构**：
```
main()
  ├─ bandMask = smoothstep(0.22, 0.38, y) * smoothstep(0.78, 0.62, y)
  ├─ p = uv 横向拉伸 (x*3, y*8)
  ├─ density = fbm(uv*1.5 + t*0.4)     // 低频密度
  ├─ q = fbm(p+t), fbm(p+offset+t)   // 第一层域扭曲
  ├─ f = fbm(p + 4.0*q)              // 第二层域扭曲
  ├─ base = f * 0.3                   // 暗区基底
  ├─ bright = smoothstep(0.45, 0.65, f)  // 亮纤维
  └─ smoke = (base + bright*0.7) * density * bandMask
```
