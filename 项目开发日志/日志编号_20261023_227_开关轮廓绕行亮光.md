### 开发内容详述

**1. 轮廓绕行亮光**

用「环形遮罩 + 旋转的 conic-gradient」做出只存在于描边上的亮光带：

```css
.isLoading .thumb::before {
  inset: 0;
  border-radius: inherit;
  padding: 2px;                       /* 只保留 2px 边框区域 */
  background: conic-gradient(from 0deg, transparent 0deg 200deg, var(--halo) 360deg);
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor;
  mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  mask-composite: exclude;
  animation: thumbEdgeSpin 1.1s linear infinite;
}
```

200°~360° 之间是透明度渐增的「尾巴」，360°/0° 处是最亮的头部，整体旋转 1.1s 一圈，读作亮光沿轮廓跑动，而不是整圈一起呼吸、也不是一段硬边框在转。

**2. 亮光配色与轨道区分**

| 主题 | 滑块底色 | 亮光色 |
|------|---------|--------|
| 浅色 | 白 | **var(--ink)**（近黑） |
| 深色 | 近黑 | **var(--body-on-dark)**（白） |

刻意不用 --color-info：开启态轨道本身就是蓝色，亮光再用蓝色会与轨道糊成一片，正是用户反馈的问题。

**3. 遮罩占位色说明**

mask 里的 #000 仅为不透明占位（遮罩只看 alpha），不参与界面配色，已在注释中标明。

### 遇到的问题与解决
- 问题：上一版整圈 inset 阴影呼吸，蓝色与蓝色轨道相邻，无法区分；且不是用户要的「转圈」。
- 解决：改为 conic-gradient 环形遮罩绕行，亮光改用与轨道对比最强的 ink／白。
- 兼容性：mask-composite: exclude + -webkit-mask-composite: xor，覆盖 Chrome/Edge/Firefox/Safari 15.4+，与项目浏览器基准一致。
