### 开发内容详述

**1. 饼图不闭环（两处根因）**

- 后端 option_counts 会把所有声明选项（含 0 票）都返回；recharts 的 paddingAngle 在每个扇区两侧各留空隙，0 票扇区把「全部投同一项」渲染成一圈带缺口的环
- 即使把 paddingAngle 归零也救不了：recharts 扇形走 SVG 的 A 弧命令，而 A 画不出整圆——360 度时起点与终点重合，路径退化为一条线（recharts Sector.js 源码注释里就写着这条）
- 解法：饼图只取 count > 0 的选项；只剩一片时改用原生 SVG circle（stroke 环形）渲染，保证闭环，并附图例与「N（100%）」计数。左侧计数柱状图保留全部选项，0 票依旧可见

**2. allow_anonymous 从死字段变真实门禁**

- 排查结果：该字段在 models / schemas 里存了、在 public 接口里序列化了，但 submit_form_response 与 get_form_public 从未读过——未登录访问任何表单都放行，只按可见性判
- 语义（与需求一致）：默认必须登录；只有开启 allow_anonymous 才允许未登录填写，提交者记为「匿名」
- 门禁顺序是关键：必须先判可见性、再判登录。顺序反了会把受限 / 私有表单对未登录者从 404 变成 401，泄露资源存在性
- 匿名防刷：登录身份有「一人一次」约束，匿名没有身份可查，补 IP 维度频控（Redis，10 次 / 10 分钟，Redis 不可用时降级放行，与既有登录频控策略一致）
- IP 取值：nginx 用 remote_addr 写了 X-Real-IP（客户端无法伪造），优先取它；直连 uvicorn 时退回 request.client.host

**3. request() 的 401 行为**

- 原逻辑 401 && token 才跳登录页——从未登录过的用户拿到 401 只会得到一个 HttpError，没有任何重定向
- 改为 401 一律尝试跳转，但登录页自身不自跳（避免在 /login 上 window.location.href 造成循环刷新）
- FormFill 补 needLogin 态：401 时不显示「表单不存在」（!formData 单独也会触发 404 视图，光跳过 setNotFound 不够）

**4. delete_form 外键冲突（有回复的表单删不掉）**

- form_response.form_id 的 FK 未配 ondelete=CASCADE，db.delete(form) 直接撞外键约束；而前端删除弹窗文案却写着「已提交的回复会一并删除」
- 解法：delete_form 先显式 delete() 该表单的全部回复再删表单（覆盖存量库，无需 Alembic 迁移）；同时在模型 FK 上补 ondelete=CASCADE，让 create_all 新建的库天生正确

**5. 已删除用户的提交者显示**

- 原来 respondent_id 有值但在 names 映射里查不到时回落成「匿名」，把「身份已删除」和「匿名提交」混为一谈
- 列表接口与导出（xlsx / csv）统一改为：respondent_id is None 显示「匿名」；有值但查不到显示「已删除用户」

**6. 依赖安全**

- 清理前 npm audit --omit=dev：30 个（1 high + 29 moderate）

### 遇到的问题与解决

- 问题：初版把「未登录门禁」写在可见性判断之前，实测发现受限 / 私有表单对未登录者返回 401 而非 404，泄露存在性
  解决：调整为「先可见性、再登录」；临时插入表单实测四种形态：受限 404 / 私有 404 / 公开且禁匿名 401 / 公开且允许匿名 200，测完即删
- 问题：初版以为 paddingAngle 归零就能闭环，读 recharts 源码才发现 SVG A 弧本身画不了整圆
  解决：单一片场景改用原生 circle
- 问题：升级 @tiptap 时 npm peer dependency 冲突（starter-kit 3.27.0 把 core 钉死在 3.27.0）
  解决：先 uninstall 全部 @tiptap 包，再整体 install 到 3.31.3
- 问题：psql 执行 select id from user 报 column id does not exist——user 是 PostgreSQL 保留字，被解析成 user() 函数
  解决：写成 from "user"
- 遗留问题：react-router 剩余 2 个 moderate 需 6.30.4 升到 7.17.1+，跨大版本，未擅自升级，待用户确认
