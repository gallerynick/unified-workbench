### 开发内容详述

**整合原则**（用户明确要求）：
1. 完整源码复制，不使用软链接
2. 保留所有特性、效果、算法
3. 保证整合前后效果完全一致
4. Phase 1、Phase 2、Phase 3 源码一个字符不改

**三层整合架构**：

```
TestPageAftermath.tsx
├── GRID_FS          = Phase 1 确认版着色器 100% 复制（含 hash/noise2/gridWire 全部函数）
├── VS_SOURCE+FS_SOURCE = Phase 2/3 粒子着色器 100% 复制
├── OVERLAY_FS       = 整合层新增：全屏黑色覆盖通道（alpha 驱动淡出）
├── sampleTextParticles() = Phase 3 文字像素采样 100% 复制
├── streams/particles 创建 = Phase 2/3 原样复制
├── update() 丝绸流逻辑 = Phase 2 原样；汇聚逻辑 = Phase 3 原样
└── frame() 三通道渲染
    ├── Pass 1: 网格凹面背景（原着色器，无淡出修改）
    ├── Pass 2: 黑色覆盖层（blendFunc SRC_ALPHA/ONE_MINUS_SRC_ALPHA）
    └── Pass 3: 粒子（blendFunc SRC_ALPHA/ONE 加法混合）
```

**时间轴**：

| 阶段 | 时间 | 显示内容 |
|------|------|---------|
| 丝绸流 | 0-3s | Phase 1 网格 + Phase 2 丝绸流粒子（完整效果） |
| 汇聚 | 3-5s | 粒子飞入形成 UNIFIED WORKBENCH 文字 |
| 定型 | 5-7s | 黑色覆盖 alpha 0→1，Phase 1 网格与 Phase 2 残余淡出，Phase 3 文字定型保持 |

**关键决策**：

| 决策 | 原因 |
|------|------|
| 用独立 OVERLAY_FS 黑色覆盖通道实现淡出，而非修改 GRID_FS | 用户要求 Phase 1 源码一个字符不改，淡出必须由整合层驱动 |
| Pass 顺序：网格 → 覆盖 → 粒子 | 覆盖层压在网格之上实现网格淡出；粒子在覆盖层之上加法绘制，保证文字永不因覆盖变暗 |
| 覆盖层 blendFunc 用 ONE_MINUS_SRC_ALPHA | 黑色半透明覆盖（非加法），alpha 从 0 线性升到 1，网格平滑隐去 |
| 粒子始终加法混合（SRC_ALPHA/ONE） | 与 Phase 2/3 独立页面渲染方式完全一致 |
| 淡出后粒子仍在黑底上绘制 | 文字保持全亮，与覆盖层无关 |

**存在的问题与解决**：
- TypeScript 报错：`linkProgram()` 返回 `WebGLProgram | null`，闭包内无法向上收窄 → 用 `const gProg: WebGLProgram = gridProg` 三级断言并在 null 守卫后别名引用
- LSP 误报：`useEffect` 嵌套函数 hook 警告（与 Phase 1/2/3 相同，忽略）
