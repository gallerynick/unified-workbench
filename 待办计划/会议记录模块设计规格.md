## 一、模块概述

### 1.1 定位

「会议记录」是独立顶层侧边栏模块，与项目管理无关联。提供基于本地 AI 的会议转录与纪要生成功能。

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 实时转录 | 会议进行中，音频实时转写为文本，按句分行显示 |
| 会后说话人分离 | 会议结束后，自动识别不同说话人并标注 |
| AI 纪要生成 | 基于转录内容，自动生成总结、重点摘要、待办事项 |
| 纪要审核 | AI 生成纪要标记为草稿，用户确认后生效 |
| 导出 | 支持导出转录文本、音频文件、纪要内容 |

### 1.3 技术架构

**两阶段架构：**

```
阶段 1：实时转录（会议进行中）
┌─────────────────────────────────────────────────────┐
│  客户端: getUserMedia → AudioWorklet → PCM → WebSocket │
│                                                       │
│  服务端: WebSocket → VAD → Paraformer + ct-punc →    │
│          按句输出 → WebSocket 推送到客户端              │
│                                                       │
│  存储: 保存转录句子(seq, text, audio_start_ms)         │
│        保存音频分片到 WAV 文件                          │
└─────────────────────────────────────────────────────┘

阶段 2：会后处理（会议结束后，后台异步）
┌─────────────────────────────────────────────────────┐
│  服务端: 加载完整音频 →                              │
│          CAM++ 说话人分离 →                           │
│          匹配说话人到转录句子 →                        │
│          Qwen3.5-4B AI 纪要生成 →                       │
│          保存纪要(summary, key_points, todos)         │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  全局第三方服务配置（所有模块共享）                   │
│                                                       │
│  AI 提供商: Qwen3.5-4B (Ollama)                      │
│  语音识别: Paraformer + ct-punc + CAM++              │
│  配置位置: 系统设置 → 第三方服务                       │
│  数据表: system_config                               │
│  API: /config/third-party                            │
└─────────────────────────────────────────────────────┘
```

## 二、数据模型

### 2.1 meeting_record（会议主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| number | VARCHAR(50) | 会议编号 `MTG-YYYYMMDD-NNN` |
| title | VARCHAR(500) | 会议标题 |
| owner_id | UUID | 创建者 ID（FK → users） |
| visibility | VARCHAR(20) | 可见性：`private` / `public` / `restricted`（默认 private） |
| restricted_users | JSONB | 指定可见用户 ID 列表 |
| restricted_tags | JSONB | 指定可见标签 ID 列表 |
| status | VARCHAR(20) | 状态：`not_started` / `recording` / `paused` / `processing` / `completed` |
| paused_reason | VARCHAR(20) | 暂停原因：`manual` / `client_left` |
| started_at | TIMESTAMPTZ | 开始时间 |
| ended_at | TIMESTAMPTZ | 结束时间 |
| duration_seconds | INTEGER | 累计转录时长（秒） |
| audio_file_path | VARCHAR(500) | 音频文件路径 |
| diarization_status | VARCHAR(20) | 说话人分离状态：`pending` / `done` / `failed` |
| minutes_status | VARCHAR(20) | 纪要生成状态：`pending` / `done` / `failed` |
| minutes_reviewed | BOOLEAN | 纪要是否已审核（默认 false） |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

### 2.2 meeting_transcript_segment（转录句子表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| meeting_id | UUID | 会议 ID（FK → meeting_record, CASCADE） |
| seq | INTEGER | 序号（按转录顺序） |
| text | TEXT | 句子文本（含标点，由 ct-punc 添加） |
| audio_start_ms | INTEGER | 音频起始时间戳（毫秒） |
| audio_end_ms | INTEGER | 音频结束时间戳（毫秒） |
| speaker | VARCHAR(50) | 说话人标签（实时阶段为 NULL，会后 CAM++ 填充，如 `说话人1`、`说话人2`） |
| created_at | TIMESTAMPTZ | 创建时间 |

### 2.3 meeting_minutes（AI 纪要表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| meeting_id | UUID | 会议 ID（FK → meeting_record, UNIQUE, CASCADE） |
| summary | TEXT | 总结 |
| key_points | JSONB | 重点摘要数组 |
| todos | JSONB | 待办事项数组 `[{content, source_quote}]` |
| model_used | VARCHAR(100) | 生成时用的模型名 |
| generated_at | TIMESTAMPTZ | 生成时间 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

### 2.4 system_config（系统配置表）

**说明：** 全局配置表，存储第三方服务配置。所有模块共享，不绑定特定业务实体。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| config_key | VARCHAR(100) | 配置键（如 `ai_provider`, `asr_config`） |
| config_value | JSONB | 配置值（JSON 格式） |
| description | VARCHAR(500) | 配置说明 |
| updated_by | UUID | 最后更新者 ID（FK → users） |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

**配置说明：**

每个服务类型都支持两种模式：
- `local` - 本地模型（离线，数据不出内网）
- `online` - 在线服务（云端 API，需要 API Key）

**默认配置示例：**

```json

// config_key = 'asr_config'

{
```

## 三、状态机

```
not_started ──开始──→ recording ──暂停──→ paused
                         │                   │
                         │←──────恢复─────────┘
                         │
                    结束会议
                         ↓
                     processing ──处理完成──→ completed
                    (说话人分离 + AI 纪要)     (终态，可导出)
```

### 状态转换规则

| 当前状态 | 触发事件 | 下一状态 | 说明 |
|----------|----------|----------|------|
| not_started | 开始转录 | recording | 用户点击「开始」 |
| recording | 暂停转录 | paused | 用户点击「暂停」 |
| recording | 客户端断开 | paused | 自动暂停，`paused_reason = 'client_left'` |
| paused | 恢复转录 | recording | 用户点击「恢复」 |
| recording | 结束会议 | processing | 用户点击「结束」 |
| paused | 结束会议 | processing | 用户点击「结束」 |
| processing | 处理完成 | completed | 后台任务完成 |
| processing | 处理失败 | completed | 后台任务失败（标记失败状态） |

### completed 状态说明

- 终态，无任何出边
- UI 上「开始转录」按钮永久禁用
- 可导出转录、音频、纪要
- 可查看说话人标注和 AI 纪要

## 四、API 设计

### 4.1 REST API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /meetings | 创建会议 |
| GET | /meetings | 会议列表（分页） |
| GET | /meetings/{id} | 会议详情 |
| PATCH | /meetings/{id} | 更新会议（标题、可见性） |
| DELETE | /meetings/{id} | 删除会议 |
| POST | /meetings/{id}/start | 开始转录 |
| POST | /meetings/{id}/pause | 暂停转录 |
| POST | /meetings/{id}/resume | 恢复转录 |
| POST | /meetings/{id}/end | 结束会议（触发会后处理） |
| GET | /meetings/{id}/transcript | 获取转录句子 |
| GET | /meetings/{id}/audio | 下载音频文件 |
| GET | /meetings/{id}/minutes | 获取纪要 |
| POST | /meetings/{id}/minutes/review | 确认纪要审核 |
| POST | /meetings/{id}/export | 导出（转录/音频/纪要） |

### 4.1.1 全局配置 API（所有模块共享）

**说明：** 第三方服务配置是全局的，所有模块（会议、未来的文档处理、图片识别等）都可以使用。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /config/third-party | 获取所有第三方服务配置 |
| PUT | /config/third-party | 更新第三方服务配置 |
| POST | /config/third-party/ai/test | 测试 AI 服务连接 |
| POST | /config/third-party/asr/test | 测试语音识别服务 |
| POST | /config/third-party/asr/reload | 重载 ASR 模型 |

## 五、UI 设计

### 5.1 设计规范遵循

**严格遵循《项目基定/UI设计规范.md》：**

| 规范项 | 应用 |
|--------|------|
| 设计 Token | 所有颜色/间距/圆角使用 `token.css` 中的 `var(--token-name)` |
| 主色 | `var(--color-primary)` (#0066cc) 用于所有交互元素 |
| 字体 | `system-ui` 字体族，正文 `typography.body-sm` (14px/400/1.5) |
| 圆角 | 卡片 `var(--rounded-sm)` (8px)，按钮 `var(--rounded-pill)` |
| 间距 | `var(--spacing-xs)` (8px) / `var(--spacing-sm)` (12px) / `var(--spacing-md)` (17px) |
| 状态色 | 成功 `var(--color-success)`，警告 `var(--color-warning)`，错误 `var(--color-error)`，信息 `var(--color-info)` |
| 深色模式 | 所有颜色 token 自动适配深色模式 |
| 图标 | `@ant-design/icons`，禁止 emoji |
| 无障碍 | 语义化 HTML，键盘导航，焦点指示 |

### 6.2 实时音频预处理流水线（services/audio_preprocessor.py）

**参考 `live_paraformer.py` 实现，这是实时转录的核心。**

#### 预处理流程

```
麦克风音频 (16kHz PCM16)
    ↓
[1] 高通滤波 (HPF)
    - 截止频率: 80 Hz
    - 目的: 去除低频噪声（空调、电流声）
    - 方法: butter(N=2) + filtfilt
    ↓
[2] 降噪处理
    - 降噪强度: 0.8
    - 目的: 减少环境噪声，保留人声
    - 方法: noisereduce.reduce_noise(stationary=True)
    ↓
[3] VAD 语音活动检测
    - 阈值: 0.006 (RMS)
    - 目的: 区分语音和静音
    - 方法: 计算 RMS，与阈值比较
    ↓
[4] 缓冲管理
    - 最小语音时长: 0.3 秒
    - 静音超时: 1.5 秒
    - 目的: 积累语音，静音时触发转录
    ↓
[5] 语音检测
    - 检测到语音 → 重置静音计时器，继续积累
    - 检测到静音 → 增加静音计时器
    - 静音超时 + 有语音 → 触发转录
    ↓
[6] 转录
    - 发送缓冲音频到 ASR 引擎
    - 返回转录文本
```

#### 实现代码

```python
import numpy as np
from scipy.signal import butter, filtfilt
import noisereduce as nr
import soundfile as sf
import tempfile
import os
import threading
from typing import Optional

class RealTimeAudioPreprocessor:
    """实时音频预处理器 - 参考 live_paraformer.py"""
    
    SAMPLE_RATE = 16000
    HPF_CUTOFF = 80
    NOISE_REDUCTION = 0.8
    VAD_THRESHOLD = 0.006
    SILENCE_TIMEOUT = 1.5
    MIN_SPEECH_DURATION = 0.3
    
    def __init__(self, on_transcription: callable = None):
        self.on_transcription = on_transcription  # 转录完成回调
        self.speech_buffer = []
        self.has_speech = False
        self.silence_timer = 0.0
        self.is_processing = False
        self.lock = threading.Lock()
        
    def process_audio_chunk(self, audio: np.ndarray, chunk_duration: float):
        """处理一个音频块
        
        Args:
            audio: float32 numpy array, shape (samples,)
            chunk_duration: 音频块持续时间（秒）
        """
        with self.lock:
            # 1. 高通滤波
            audio = self._highpass_filter(audio)
            
            # 2. 降噪
            if len(audio) > self.SAMPLE_RATE * 0.1:
                audio = self._reduce_noise(audio)
            
            # 3. VAD 检测
            is_speech = self._detect_speech(audio)
            
            # 4. 缓冲管理
            if is_speech:
                # 有语音，积累到缓冲
                self.has_speech = True
                self.speech_buffer.append(audio.copy())
                self.silence_timer = 0.0
            elif self.has_speech:
                # 静音，但之前有语音，继续积累并计时
                self.speech_buffer.append(audio.copy())
                self.silence_timer += chunk_duration
                
                # 静音超时，触发转录
                if self.silence_timer >= self.SILENCE_TIMEOUT:
                    self._trigger_transcription()
    
    def _highpass_filter(self, audio: np.ndarray) -> np.ndarray:
        """高通滤波 - 去除低频噪声"""
        if len(audio) < 10:
            return audio
        
        nyquist = self.SAMPLE_RATE / 2
        normalised = self.HPF_CUTOFF / nyquist
        b, a = butter(N=2, Wn=normalised, btype='high')
        
        try:
            return filtfilt(b, a, audio)
        except:
            return audio
    
    def _reduce_noise(self, audio: np.ndarray) -> np.ndarray:
        """降噪 - 减少环境噪声"""
        if len(audio) < self.SAMPLE_RATE * 0.1:
            return audio
        
        try:
            return nr.reduce_noise(
                y=audio,
                sr=self.SAMPLE_RATE,
                stationary=True,
                prop_decrease=self.NOISE_REDUCTION,
            )
        except:
            return audio
    
    def _detect_speech(self, audio: np.ndarray) -> bool:
        """VAD - 检测语音活动"""
        rms = np.sqrt(np.mean(audio ** 2))
        return rms > self.VAD_THRESHOLD
    
    def _trigger_transcription(self):
        """触发转录"""
        if not self.speech_buffer or self.is_processing:
            return
        
        # 检查最小语音时长
        total_duration = sum(len(chunk) / self.SAMPLE_RATE for chunk in self.speech_buffer)
        if total_duration < self.MIN_SPEECH_DURATION:
            self.speech_buffer.clear()
            return
        
        self.is_processing = True
        
        # 合并音频块
        full_audio = np.concatenate(self.speech_buffer)
        start_time_ms = int(total_duration * 1000)
        
        # 清空缓冲
        self.speech_buffer = []
        self.has_speech = False
        self.silence_timer = 0.0
        
        # 保存到临时文件
        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
            sf.write(f.name, full_audio, self.SAMPLE_RATE)
            tmp_path = f.name
        
        try:
            # 调用 ASR 转录
            text = self.asr_engine.transcribe(tmp_path)
            
            # 回调
            if self.on_transcription:
                self.on_transcription({
                    'text': text,
                    'audio_start_ms': 0,  # 需要从 session 获取
                    'audio_end_ms': start_time_ms,
                })
        finally:
            os.unlink(tmp_path)
            self.is_processing = False
```

```python
class CAMSpeakerDiarizer:
    def __init__(self):
        from funasr import AutoModel
        self.model = AutoModel(
            model="campplus",
            vad_model="fsmn-vad",
            spk_model="cam++",
            disable_update=True,
        )
    
    def diarize(self, audio_path: str) -> list[dict]:
        """返回 [{speaker: '说话人1', start_ms, end_ms}, ...]"""
        results = self.model.generate(input=audio_path)
        speakers = []
        speaker_count = 0
        seen_speakers = {}
        for seg in results.get("sentence_info", []):
            spk_id = seg.get("spk", 0)
            if spk_id not in seen_speakers:
                speaker_count += 1
                seen_speakers[spk_id] = speaker_count
            speakers.append({
                "speaker": f"说话人{seen_speakers[spk_id]}",
                "start_ms": seg.get("start", 0),
                "end_ms": seg.get("end", 0),
            })
        return speakers
```

### 6.7 并发策略

**单 worker + 队列：**

```python
class ASRQueue:
    def __init__(self, max_workers=1):
        self.queue = asyncio.Queue()
        self.workers = [asyncio.create_task(self._worker(i)) for i in range(max_workers)]
    
    async def _worker(self, worker_id):
        while True:
            task = await self.queue.get()
            result = await task.process()
            task.complete(result)
    
    async def submit(self, meeting_id, audio_segment):
        task = ASRTask(meeting_id, audio_segment)
        await self.queue.put(task)
        return task
```

- 同时只处理 1 个会议的音频
- 其余会议排队等待
- 前端通过 WebSocket `queue_update` 消息显示排队位置
- 单 worker 串行，避免 CPU 过载

```ts
  const [isRecording, setIsRecording] = useState(false);
  
  async function start() {
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: {
        sampleRate: 16000,
        channelCount: 1,
        echoCancellation: true,
        noiseSuppression: true,

    processor.connect(audioContext.destination);
    
    setIsRecording(true);
  }
  
  function stop() {
    // 停止音频采集
  }
  
  return { isRecording, start, stop };
```
