## 一、背景与目标

### 现状（代码事实）

- 侧边栏数据源：frontend/src/layouts/MainLayout.tsx 的 SIDEBAR_ITEMS（21 项业务菜单，扁平数组）+ getMenuItems() 附加个人区 5 项、管理员「系统设置」二级子菜单（9 项）
- getMenuItems() 被两处共用：侧边栏 Sider（552 行）与移动端 Drawer 菜单（611 行），重构必须同时适配两种形态
- 用户个性化页：frontend/src/pages/settings/UserPersonalization.tsx 现有 3 张卡片（主题设置 / 页面缩放 80-120 五档 / 自动折叠模块栏 Switch），数据存后端 user_preferences JSONB（auto_collapse_sidebar 字段已存在）
- 侧边栏动画：assignMenuAnimDelays 按 DOM 顺序分配飞入延迟，重构后菜单层级变化需回归验证

### 目标

1. 侧边栏业务菜单按领域分组为二级菜单，界面简洁、避免 21 项平铺臃肿
2. 保留用户常用项常驻展示，剩余项收进折叠入口，点击展开
3. 用户个性化页新增设置项，与侧边栏重构联动
4. 深浅色模式、无 Emoji、design token 引用等 UI 规范不回归

## 六·补、2026-10-22 设计变更（用户补充，优先于前文默认方案）

前文第二节的默认方案在实施前被用户补充修订，**以下为准**：

### 1. 类别分隔形态（取代原「收进『全部』二级子菜单」）

- **最终形态**：类别名小字 + 右侧延伸的极淡细线（「标题 + 收尾线」），**不是通栏分隔线**
  - 原因：通栏横线既压重，又与底部「模块 / 设置」的结构分隔线互相混淆（2026-10-22 二次修正）
- 类别可折叠：点击该行整组收起/展开；箭头常态隐藏，收起态强制显示以保留状态可读性
- **不使用系统设置那种 antd Submenu 形态**（不缩进、无子菜单弹层）
- 两类线的区分口径：
  | | 类别标记 | 模块/设置分隔线 |
  |---|---|---|
  | 文字 | 有（类别名） | 无 |
  | 起止 | 从类别名之后起，右侧留 16px | 通栏 |
  | 颜色 | `--divider-soft`（#f0f0f0） | `--border-primary`（#d9d9d9） |
- 迭代过程中新增的两个 token（`--sider-category-divider`、`--sider-section-divider`）最终未被使用，已删除，避免死配置

### 2. 侧栏显示项可配置（新增需求）

- 用户个性化页可勾选要显示的模块；未勾选的不在侧栏显示
- 至少保留一项（全部取消会让业务菜单区消失，属自伤型配置）

### 3. ~~「折叠未显示项」开关~~（2026-10-22 晚已按用户要求彻底删除）

- 该功能曾实现为「未勾选项收进侧栏底部『未显示』折叠桶 + 个性化页开关」
- 用户判断其增加理解成本与视觉噪声，**连代码、字段、数据库残留键一并删除**
- 现行行为：**未勾选的项目就是不在侧栏显示**，要找回在个性化页重新勾选

### 4. 附带决策（实施时定）

- 会议记录归入「协作办公」（原默认在内容知识）
- 系统设置 11 项本期不分组

- 「自动折叠模块栏」只对一级菜单生效（分组后层级变深，点二级也收起会打断浏览）
