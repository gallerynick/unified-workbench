## 一、提案详情页范式（参照物，log 075/076）

| # | 要素 | 实现要点 |
|---|------|---------|
| 1 | 展示重构 | `Descriptions bordered` → 定义列表 renderDefItem（.defItem/.defLabel/.defValue）+ 段落区块 renderDescriptionBlock（.textBlock/.textLabel/.textBody） |
| 2 | 状态流转 | `Steps size="small" current={index}`，rejected 时 status="error"（条件展开） |
| 3 | 关联内容增强 | .linkedContent 上下分层（编号标题行 + 元信息行）；断开用 Modal.confirm；「添加已有」+「新建并关联」双入口 |
| 4 | 共用组件复用 | 底部挂 ProposalModal / TodoModal / MeetingModal，编辑与新建均走组件 |
| 5 | 操作 Tab | 状态操作 + 其他操作（编辑/删除），带说明文字，仅管理者可见 |

**范式红线**（踩过的坑，本轮同样遵守）：
- 条件返回 if (!x) return null 之后**不得出现 hook**（React error #310）
- exactOptionalPropertyTypes 下可选属性用条件展开，不显式传 undefined
- 无 Emoji 图标（@ant-design/icons）、design token、简体中文

## 二、各模块适配决策（依据自身设计功能，不强行统一）

| 要素 | 待办（TodoDetailPage） | 交流（MeetingDetailPage） | 理由 |
|------|----------------------|--------------------------|------|
| 展示重构 | 做 | 做 | 两页都是 Descriptions 单表格，痛点相同 |
| 状态 Steps | 做：3 步（pending→in_progress→completed） | 不做 | 交流无状态字段（后端 schema 无 status） |
| 富文本 | 保持纯文本 | 保持纯文本 | 待办描述是任务备注（短文本，富文本收益低）；交流 content 有「标题+正文」结构约定，富文本会破坏 |
| 编辑入口 | 新增（TodoModal edit） | 改用 MeetingModal（删内联 Form） | 待办页原本无编辑入口；交流页 60 行内联 Form 与共用组件重复 |
| 操作 Tab | 做：状态操作 + 编辑/删除 | 不做，保留页头编辑/删除按钮 | 交流无状态流转，不需要操作 Tab |
| 关联内容增强 | 做 | 做 | 两页关联项都只显编号+标题，信息量不足 |
| 新建并关联 | 仅「新建交流」（MeetingModal initialTodoId） | 仅「添加已有」 | 后端 ProjectTodoCreate/ProjectProposalCreate 无 meeting_id，ProposalModal/TodoModal 无 initialMeetingId，该方向无法直接落库 |
| 删除 | 新增（deleteProjectTodo 已存在） | 已有 | |

## 三、附带修复的两个 bug

1. **MeetingDetailPage 显示原始 UUID**：「关联提案 ID」项直接渲染 meeting.proposal_id → 改为显示提案编号并可点击跳转提案详情页
2. **断开关联无二次确认**：两页的 handleDisconnect* 直接执行 → 改为 Modal.confirm（危险按钮），与提案页一致

## 四、共用组件补充

- **MeetingModal 增加「正文」字段**：现表单只编辑标题部分（splitTitleContent 保留 body），正文只能在详情页改。详情页改用 MeetingModal 后会丢失正文编辑能力 → MeetingModal 新增 body 表单项（新建可选、编辑回填），与「标题+正文」设计一致。影响 MeetingRecordTab（新增一个可选字段，向后兼容）
- **constants/project.ts 新增** PRIORITY_COLOR、PROPOSAL_STATUS_COLOR、TODO_STATUS_COLOR、TODO_STATUS_LABEL：这四个映射目前只在 ProposalDetailPage 内定义，本轮要在 3 个页面复用，避免第 3 份副本；同步删掉 ProposalDetailPage 的本地定义
