# 工作台锁定页改造（idle 退出登录 → 锁屏）

## 目标

把"5 分钟无操作退出登录"改为"5 分钟无操作锁定工作台"。锁定后显示锁屏页（头像+名称+密码解锁），所有工作台地址重定向到锁屏页，直到输入密码解锁。右上角通知铃旁边新增手动锁定按钮。

## 架构设计

### 新组件：LockContext (`contexts/LockContext.tsx`)

```tsx
// 状态：isLocked (sessionStorage 持久化)
// API：lock() — 设 isLocked=true，存 sessionStorage
// API：unlock() — 设 isLocked=false，清 sessionStorage
// Provider 包裹 App 根组件
```

### 改造 1：useIdleTimer

`handleLogout` → `handleLock`：不再清 token 退出，改为调用 LockContext.lock()。

### 改造 2：MainLayout

- useEffect：监测 `isLocked`，为 true 时 `navigate('/lock')`
- 手动锁定按钮：LockOutlined type=text size=small，`onClick={lock}`，Tooltip="手动锁定工作台"
- 现有 idleToggle：文案改为 "空闲 5 分钟自动锁定"/"已暂停自动锁定"

### 新页面：LockPage (`pages/LockPage.tsx` + `.module.css`)

- 路由 `/lock`（公开，在 AuthGuard 外）
- UI：纵向居中卡片 → 大头像(80px) → 名称(用户名) → 密码输入框 → 解锁按钮
- 调用 `/auth/verify-password`（POST body `{password}`，header Bearer token）
- 成功：`unlock()` → `navigate(-1)`（若无前页则 navigate('/')）

### 改造 3：router.tsx

- 添加 `/lock` 路由（公开，L67 /welcome 同级）
- **重定向守卫**：LockGuard 组件（或直接用 useEffect），在 AuthGuard 子路由检查 isLocked → Navigate to /lock
- LockPage 本身 lock 后不重定向（避免循环）

### 重定向策略

采用 **LockGuard 组件** 包装 AuthGuard children：

```tsx
// router.tsx
import LockGuard from '@/components/LockGuard';

{
  element: <AuthGuard />,
  children: [{
    element: <LockGuard />,  // 检查 isLocked，重定向到 /lock
    children: [{
      path: '/',
      element: <MainLayout />,
      children: [...],
    }],
  }],
}
```

LockGuard 用 `useLockContext()` 获取 isLocked，若 true 则 `<Navigate to="/lock" replace />`。
